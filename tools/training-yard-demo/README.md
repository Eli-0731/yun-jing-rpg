# 青溪公共演武區：獨立 PWA 本機展示

執行 `npm ci` 後 `npm start`，在 `http://127.0.0.1:4178` 開啟橫向 PWA 展示。此開發伺服器僅綁定 loopback，手機不能直接連到電腦的 localhost；要在手機安裝與驗收，需由核心組部署至可存取的 HTTPS 網址。展示載入本組六個獨立 GLB，從村口眼高 1.7 m 視角走過石坡、進入棚下，靠近木樁按 E 或觸控「互動」。WASD／方向鍵移動、拖曳轉向；橫向觸控使用螢幕按鍵。模型以米為尺度，角色圓形步行代理避免穿過柱、木樁、石頭及架子。

`manifest.webmanifest` 設定橫向獨立視窗與安裝圖示；`sw.js` 快取頁面、Three.js 模組及六件 GLB。首次連線並完成快取後，可斷網重開這個展示。這是本組獨立 PWA 樣片，尚未嵌入主遊戲 PWA 或部署到手機可存取的站台。更新模型或頁面時須變更 service worker 的 `VERSION`，讓舊快取被清理。

氣勁木樁提供三輪引氣呼吸：在提示到達節奏點時按住，吐氣時放開。身法木樁提供六次左右交替格擋：每次按下、放開，避免長按連續命中。兩者失誤可重試；凡骨身分禁用引氣，但可直接選武技。結果只在本機記憶體，重新整理後重置。展示不呼叫 API、不增加正式修為或獎勵，也不寫背包或持久化檔。

`npm test` 跑節奏引擎的七項測試，涵蓋成功循環、凡骨規則、長按／重複鍵防刷、超時、失誤重試、時間基準與結果快照。另以真實瀏覽器驗證六件 GLB 載入、村口至棚下步行、靠近互動、凡骨引氣禁用、武技可選及結束後重試；桌面 1280×720 與橫向 844×390 的實際畫面保存在 `../../art/previews/qingxi-training-yard-v1/`。這是瀏覽器視窗檢查，不等於真手機效能或觸控硬體驗證。

主線原始碼已有 `POST /actions` 的 `practice-basic`（qi/body）服務端流程，含權限、冷卻和發獎；本展示尚未接線。核心組把它接入遊戲 PWA 時應使用正式認證與 requestId，讓服務端決定所有進度與獎勵。前端節奏得分只作 UI 回饋，不直接兌換修為。主遊戲 PWA 接線、手機安裝與 FPS 均尚未驗證。

模型、材質、來源與建置步驟見 `../../art/source/qingxi-training-yard-v1/README.md`；正式碰撞代理建議在 `../../art/exports/qingxi-training-yard-v1/collision-proxies.json`。作者：Johnnnny0823 委託；Codex 實作與驗證。
