## 玩法

從石製避雨龕（A09，安全點）出發，可以先在藤靶（A12）試招、爬上觀察台（A10）看清動線，再穿過受損竹柵（A08）與掛布警示架（A11）的缺口，沿著有爪印的兔徑（A07）走向林間凹地（A02）。山兔有五個看得出來的狀態：

| 狀態 | 看到／聽到 | 玩家該做什麼 |
|---|---|---|
| 警戒 | 兔子從洞裡起身、轉向你，踏地「咚咚」聲 | 躲到圓石（A04）或立岩（A05）後面擋住視線，或站穩準備 |
| 預備 | 壓低身子後蹬、刨土聲、地面出現刨痕，約 0.85 秒 | 往側面閃避，或面向牠按住格擋 |
| 衝刺 | 快速直衝，方向在預備結束時鎖定 | 已經太晚改方向；閃避無敵時間可以穿過去 |
| 硬直 | 落地失衡、左右搖晃 | 靠近出手：左鍵／J 攻擊、Q 試招 |
| 撤退 | 跑回洞裡 | 你到安全點、走遠、躲起來，或把牠驅離 |

- 引牠衝向石頭、樹樁或倒木，撞上去的硬直最長。
- **劍・看破綻**：硬直中試招 2 點傷害。**體・穩架**：按下格擋後 0.18 秒內接到為穩架，失衡最久。**法**列為下一版，按鈕停用。
- 連按防禦會「架勢散亂」；分頁切走或斷線時，兔子立即撤退、不扣血。
- 倒地或按 R 都回安全點重來，不損失任何東西。右上可關閉狀態提示，只靠動作與聲音判斷。
- 觀察台：走到梯子旁按 E 爬上去，視角拉高、可俯瞰兔徑與凹地；在台上山兔碰不到你，再按 E 下來。
- 藤靶：靠近後攻擊或試招會自動轉向藤靶；累計 8 點後換成破損外皮（A12 第二狀態），R 回安全點會換回完整外皮。

操作：WASD 移動（以鏡頭為準）、拖曳轉視角、空白鍵閃避、右鍵或 K 按住格擋、左鍵或 J 攻擊、Q 試招、E 互動（觀察台）、R 回安全點。觸控：左側搖桿，右側「閃避／格擋（按住）／攻擊／試招／互動」。鏡頭遇到牆或屋頂會自動拉近，不會被擋住。

規則、參數、狀態圖與將來伺服器要驗證的輸入：[CONTRACT.md](CONTRACT.md)。

## 檔案

- `encounter.mjs`：純規則（固定步長，可重播），`encounter.test.mjs` 17 項測試。
- `app.mjs`：three.js 場景、第三人稱越肩鏡頭、替身、山兔動畫與提示；`audio.mjs`：合成音效（改寫自演武區展示）。
- `server.mjs`：本機靜態伺服器，固定允許清單；`/assets/` 讀本包 GLB，`/rabbit/` 唯讀讀取山兔 v003。
- `capture.mjs`：用真 Chromium 以真按鍵玩一輪並截圖；`record.mjs`：錄下即時實玩 WebM，再以 `art/source/qingxi-encounter-a/encode_video.py`（Blender 內建 FFmpeg）轉成 H.264 MP4。兩者都需要另外安裝 `playwright-core`，不是本包依賴。
