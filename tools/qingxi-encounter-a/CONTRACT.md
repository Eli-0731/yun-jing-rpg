# 林地山兔遭遇：參數、狀態圖與未來伺服器驗證契約

本頁說明 `encounter.mjs` 的規則，以及將來接入正式遊戲時，**區域程序（D2）**應驗證的輸入與結果。展示頁不呼叫任何 API、不寫掉落、不發靈石；瀏覽器的結果永遠不能直接變成正式資產。

## 狀態圖

```text
idle（洞內）──看見玩家（7.5 m 內、視線未被 A04/A05/倒木擋住）──▶ alert 警戒：豎耳、踏地聲
alert ──玩家 5 m 內且持續被看見 1.1 s──▶ windup 預備：壓低後蹬、刨土聲、地面出現刨痕（0.85 s；剩 1 血時 0.64 s，下限 0.6 s）
windup ──預備結束時鎖定方向──▶ charge 衝刺：9.5 m/s，最遠 5 m
charge ──撞到玩家：閃避無敵／格擋／受擊──┐
charge ──衝滿 5 m──▶ stagger 硬直 1.3 s     │
charge ──撞上障礙（石、樹樁、倒木）──▶ stagger 2.2 s
被格擋 ──▶ stagger 1.9 s（劍）/ 1.9 s（體）；精準格擋（按下後 0.18 s 內接到）──▶ 劍 1.9 s / 體 2.6 s
stagger 結束 ──▶ alert（再來一輪）
任何時候：玩家到安全點（A09 避雨龕或在 A10 觀察台上）／離洞 13 m 以上／看不見玩家 3 s／分頁隱藏或斷線 ──▶ retreat 撤退回洞 ──▶ idle（冷卻 2.5 s）
兔子 0 血 ──▶ retreat（驅離，展示不做死亡掉落）；玩家 0 血 ──▶ 兔子撤退，玩家回安全點重來，不扣任何東西
```

## 玩家動作（固定步長 1/60 s）

| 動作 | 參數 | 規則 |
|---|---|---|
| 移動 | 3.2 m/s；格擋或出手時 ×0.35 | 由輸入方向與牆體碰撞決定位置 |
| 閃避 | 0.32 s 衝 2.6 m，前 0.26 s 無敵，冷卻 0.75 s | 站著不動時往後跳；出手中不能閃 |
| 格擋（按住） | 正面 108° 內有效；按下 0.18 s 內接到為精準 | 1.5 s 內按超過 4 次 → 架勢散亂 1.2 s，不能格擋 |
| 攻擊 | 出手 0.18 s 後判定，距離 1.55 m、正面 81° | 只在兔子硬直時命中；警戒中出手會被閃開並逼牠進入預備 |
| 試招・劍「看破綻」 | 同攻擊 | 硬直中造成 2 點 |
| 試招・體「穩架」 | 精準格擋的硬直加長到 2.6 s，普通格擋破綻也較長 | 體式的 Q 為普通攻擊 |
| 試招・法 | — | 下一版，介面上停用，規則會拒絕建立 |

藤靶（A12）：在攻擊距離與角度內的出手一律算命中，試招 2 點、一般 1 點，累計 8 點換破損外皮；不影響山兔。

碰撞半徑：玩家 0.35 m、兔子 0.38 m。動畫事件點：預備起點（踏地／刨土音效＋刨痕淡入）、鎖定方向（預備結束）、命中判定（衝刺中兩者距離 < 0.73 m）、攻擊判定（出手後 0.18 s）。

## 將來的伺服器驗證（未實作）

正式掉落沿用既有內部端點 `POST /v1/internal/hunt/death`（見 `docs/qingxi-hunt-integration.md`），只能由區域程序在驗證後呼叫。客戶端最多送出**輸入**，不能送結果：

```json
{
  "requestId": "UUID",
  "encounterId": "spawnId（區域程序在兔子出生時產生）",
  "inputs": [
    { "t": 1234, "move": [0.0, 1.0] },
    { "t": 1400, "dodge": true },
    { "t": 1650, "block": true },
    { "t": 1900, "attack": "technique" }
  ]
}
```

區域程序以伺服器時間與同一套固定步長規則重播，檢查：移動速度與牆體、閃避冷卻與無敵時間、格擋次數（防連按）、攻擊距離／角度／是否在硬直窗口、流派是否已學會；命中與兔子血量只由伺服器狀態決定。兔子 0 血時，區域程序依既有契約送 `deathId`，掉落由 API 依 `packages/content/hunting.json` 計算。重送相同 `requestId` 回原結果；玩家斷線時兔子撤退且不結算。

本展示的 `encounter.mjs` 可作為重播規則的參考實作，但目前只在瀏覽器執行，**沒有**伺服器端版本，也沒有接 `hunt/death`。
