## 一、一句話

**《承天》**：天裂了，一直有人在獨自承天。你從青溪的一個新人開始修仙，一路揭開這片土地的秘密，最後和所有人一起承天。

| 名稱 | 是什麼 |
|---|---|
| 承天 | 遊戲名稱。主線就是「天裂了，誰在撐著天」 |
| 不周 | 世界：一片大陸，分成很多地區（名字取自「不周山」，意思是有缺口的世界） |
| 鼇極 | 新手所在的地區，青溪村就在這裡 |
| 雲境 | 天缺正下方、雲最高處的地方，最後才去得了 |

## 二、世界觀（最早的版本為主）

### 天缺與代天大陣
- 很久以前天裂了（天缺）。先人立了一座看不見的「**代天大陣**」，代替天道撐住天。
- 大陣撐了上千年，開始撐不住了。靈脈一處一處地裂，青溪的溪水停了。

### 真相分層（越後面越深，一環扣一環）

| 層 | 玩家一開始以為 | 其實 | 什麼時候揭開 |
|---|---|---|---|
| 1 | 溪水停了，是水路壞了 | 溪底的靈脈在變弱；水路的陣基其實是「縫脈陣」 | 新手篇（青溪） |
| 2 | 三百年前「斷脈之年」靈脈斷了，各宗合力縫好 | 縫是縫了，代價是把邊陲的靈氣引去撐住中心，邊陲從此慢慢枯 | 新手篇後段到入宗 |
| 3 | 有人在挖古樹、拆縫脈陣，是壞人 | 拆陣的是被犧牲的邊陲人，只想拿回自己土地的靈氣 | 入宗以後 |
| 4 | 天劫是對修士的考驗 | 天劫是大陣在篩選飛升的人；世界的靈氣有限 | 宗門篇中段 |
| 最後 | 世界要靠大陣撐 | 七個道統原本是同一條道，天裂後才各自抓住一塊、互相看不起。最後是七道重新合一，大家一起承天 | 終章 |

### 沒有真正的壞人
- 每個道統都藏著秘密，做的事從自己的角度都是為世界好（見第四節）。
- 好人可能做著很冷酷的事；被當成邪道的，可能正在替世界擋傷口。

### 長線的謎（一直出現、很久不解釋）
- **斷章**：歷史被撕掉了同一段，沒人記得。
- **鴻篆**：刻在石碑上的上古文字，要大家交流才拼得出來。
- **缺月**：像缺了一角的月亮的記號，出現在古物和某些人身上。

### 關鍵人物（名字暫定）
| 人物 | 新手期看到的 | 之後揭開的 |
|---|---|---|
| 季遠（新手領地的前房客） | 留下一封信：「待我測過資質，便回來」 | 測資時身上浮出缺月，之後出走，加入拆陣的邊陲人。不是壞人，是迷路的人；救他的方法是讓他知道有人一直在等他 |
| 茶亭老人 | 說「青溪這幾天不對勁」，身邊有個不准打開的漆盒 | 三百年前斷脈時就在場，一直在等一個約好要回來的人 |
| 沈岳、柳知微 | 來青溪的兩位師父 | 各自知道一部分真相 |

## 三、故事怎麼講

1. **完全不交代**：沒有開場旁白，不說未來。玩家一步一步自己發現世界怎麼了。
2. **一環扣一環**：每開放一個地區，才揭開那一環，不提早爆雷。
3. **每個故事都要感人**：照《感人故事研究》的十一個原因與檢查表寫，例如：
   - 先一起生活，離別才有重量；
   - 有人默默一個人扛；
   - 犧牲留下傳承、留下春天。
4. **取名三層法**：表面好聽，裡面藏一個典故，典故暗示主線。

### 犧牲不一定是死（師父與重要角色的故事）
- 重大事件（例如師父出事）放在**個人的宗門主線**裡，每個人走到那一章才發生；還沒走到的人看到的師父還在。
- 犧牲有很多種：
  - 失去修為（還在，再也不能出手）；
  - 失去記憶（要重新認識你）；
  - 化成陣靈（在天樞旁感覺得到他）；
  - 閉死關（最後才出關）；
  - 背罪離宗（之後重逢）。
- **真正的死亡要克制**：可以分散在不同的人身上，但整個遊戲的次數要少，才有力量；玩家也不會一直少掉角色。
- **會讓人心碎的不一定是師父**：

  | 角色 | 和玩家的關係 | 失去時的感覺 |
  |---|---|---|
  | 宗主 | 遠遠的，一直撐著整個宗門 | 原來一直是他在扛 |
  | 鎮山長老 | 平常只是守山門、掃地的老人 | 最不起眼的人守著最重要的東西 |
  | 師兄 | 照顧你、罩著你 | 那個總說「有我在」的人不在了 |
  | 師姊 | 嚴格又溫柔 | 她留下的筆記每一頁都在叮嚀你 |
  | 師妹 | 比你晚入門，跟在你後面 | 這次換你沒保護好她，或是她為你長大了 |
  | 路上的 NPC 好友 | 大世界旅途中結識，一起走過一段路 | 沒有宗門牽絆，純粹是朋友 |

- **同行好友系統**：在大世界的旅途中遇到一些 NPC，和你同行一段路（一起採藥、過夜、打靈獸、聊天、互相幫忙）。他們有自己的目標與故事，分開後在世界某處還會重逢。先一起生活過，之後的重要時刻才有重量。

## 四、宗門：七個道統、十四個宗門

### 道統是大派系，宗門是分支

| 道統 | 宗門（暫名） | 道統的秘密與故事 |
|---|---|---|
| 法道 | 太玄道院（雷）、寒漪宮（冰水）、赤霄門（火） | 太玄道院守著大陣，天劫是他們在篩人（第 4 層） |
| 劍道 | 問劍山、斷水門 | 三百年前問劍山祖師一劍斬斷靈脈止住天缺，史書寫成「斬妖」。劍道因此分裂：問劍山背負那一劍，斷水門認為劍不該斬向大地而出走 |
| 體道 | 玄岳宗、金剛寺 | 玄岳宗「守山者不問山」，世代守的山其實是一根撐天的柱子 |
| 丹道 | 丹霞谷（救人）、百毒谷（用毒） | 同一個源頭兩種走法；丹霞谷藏著能養靈脈的母種 |
| 器陣道 | 天工門（煉器、傀儡）、雲篆派（符籙、陣法） | 天工門在偷偷造下一座大陣；雲篆派記得鴻篆 |
| 靈道 | 御靈谷、萬獸山 | 靈獸是靈脈的免疫，御靈谷把牠們趕到靈脈最傷的地方 |
| **冥道** | **玄冥宗（只剩這一個）** | 冥道的宗門都在把天缺滲出的濁氣扛進自己身體，一個接一個撐不住，玄冥宗是最後一個。世人以為它是邪宗 |

### 宗門之間的恩怨
- **太玄道院 ⟷ 玄冥宗**：死敵。一個篩掉「太重」的人，一個把所有重量扛下來。
- **問劍山 ⟷ 斷水門**：同門決裂。
- **問劍山 ⟷ 天工門**：那一劍毀了天工門造了百年的東西。
- **丹霞谷 ⟷ 百毒谷**：救人和用毒，同源相爭。
- **御靈谷 ⟷ 萬獸山**：一個把靈獸當夥伴，一個把牠們當戰力。

死敵會在某一章被迫並肩。

### 山城分院與各地本宗
- **山城**（新手大世界裡的垂直山城）是天下宗門的分院所在：
  - 七柱宗門派人來守山城腳下的天樞；
  - 每年的十日問心測資在這裡，宗門都來收徒。
- 開放某個地區時，那個道統的宗門是那一章的主角，**其他人也都能去**。

### 祖庭：每個道統的大宗門（2026-10-30 定案）

```text
劍道
 ├─ 祖庭（大宗門）：在不周的某個地區，劍道的源頭，非常宏偉
 └─ 分宗：問劍山、斷水門 ── 各自在山城設分院，新手在這裡拜入
```

- **祖庭不能直接拜入**。玩家以分宗弟子的身分，奉師命前往祖庭修行、受傳承；祖庭給鎮派絕學、道統最深的秘密，在那裡修煉稍快。
- **七個祖庭不都在山上**，各在不同的環境：每開放一個，就是一種全新的地形與建模套件，也有專屬的移動方式。

| 道統 | 祖庭在哪裡 | 樣子 | 為什麼 |
|---|---|---|---|
| 法道 | 天上 | 雲層上的浮空宮殿，雷雲環繞，冰與火的殿閣懸在兩側 | 天劫與大陣的秘密在天上 |
| 劍道 | 大地的裂谷 | 上古那一劍劈開的巨大峽谷，殿堂沿崖壁而建 | 祖庭本身就是那一劍的傷痕 |
| 體道 | 山上（唯一在山上） | 一座巨山，殿宇從山腳蓋到山頂 | 這座山就是撐天的柱子 |
| 丹道 | 湖上 | 大湖裡的千座小洲，每座是一片藥田，舟橋相連 | 救人與用毒兩條路在湖的兩岸分開 |
| 器陣道 | 地下 | 地脈裡的一座城，工坊、熔爐、巨大陣盤在岩洞裡運轉 | 煉器要地火，陣法要貼著靈脈 |
| 靈道 | 海上 | 外海群島，海獸、鯨群、海鳥，祖庭建在巨獸骨骸或珊瑚上 | 靈獸最多、最自由的地方 |
| 冥道 | 深淵 | 往地底沉下去的黑暗裂谷；最底下是一座空了的宗門，只剩一位守門等了很久的老人 | 最靠近濁氣的源頭 |

移動方式：天上要御劍或靈鶴、湖上划舟、海上騎海獸、地下與深淵往下垂降。

### 怎麼選宗門
1. 前十天在青溪做的事會被各宗門看見（練體、煉丹、找到某個機緣……）。
2. 第十天測資後收到幾封**接引帖**。
3. 到山城，看各道統的分院，挑一個拜入。
4. 選錯可以轉宗，但要走一段「出師」或「叛出」的劇情，部分貢獻帶不走。

### 資質：決定起點，不決定終點（2026-10-30 定案）

| 資質 | 入宗時 | 待遇 |
|---|---|---|
| 天才（極少數） | 內門 | 好住處、長老親自指點、資源多 |
| 普通 | 外門 | 大多數人 |
| 很差的靈根 | 記名弟子 | 從雜役做起 |

- **往上爬靠努力**：記名 → 外門 → 內門 → 親傳，靠宗門試煉與貢獻，不靠資質。親傳誰都不是一開始就有的。
- **待遇看得見**（升階就搬家）：

  | | 記名 | 外門 | 內門 | 親傳 |
  |---|---|---|---|---|
  | 住處 | 大通鋪的床位 | 自己的小房 | 小屋加小院子、兩塊靈田 | 獨立院落：靈田、靜室、小亭 |
  | 每月例錢 | 少 | 普通 | 多 | 最多 |
  | 藏經閣 | 基礎 | 多一層 | 再多一層 | 全部 |

  - 只有四種格局，用模組拼：Codex 的室內套件，加 10/31 協作者的家具與後院套件。
  - 各道統只「換裝」（材質、顏色、幾件代表擺設），不另做一套。
  - 待遇只影響日常方便與速度，不影響去不去得了祖庭，也不影響故事。
- **每個人都有師父**：每個宗門有兩、三位師父（NPC，個性不同），入宗時選一位或由接引的長老收下；記名弟子到親傳都有師父。師徒關係是每個玩家自己的。
- **每種資質都有適合的路**：
  - 靈根差引氣慢，但體道、器陣道、丹道靠身體、手藝與知識，靈根影響小；
  - 天才引氣快，但天劫更重。
  - 境界越高，資質的差距越小。
- **去祖庭不看階級、不看境界**：要走完宗門主線的一章（例如「問道之行」），每個人都從第一步開始，天才也不能跳過；難度依境界調整。
- **故事人人一樣**：主線完全相同，只保留**小點綴**，例如：
  - 測資那天長老說的一句話；
  - NPC 偶爾隨口提一句（「你可是被看好的」／「雜役做完了嗎」）。
- **每個道統去祖庭的條件都一樣**。開放順序只是排程，不是難度；每個地區開放時所有人都能去，地區分層，深處才看境界。

### 公平
- 宗門只決定修行方向，不決定強弱；付費不影響強度。
- 到了本宗會變強，但是變「**更多**」：學到鎮派絕學、在本宗修煉稍快。
- 「**更高**」大家一起：每個大版本提高所有人的境界上限。

## 五、空間：玩家在哪裡做什麼

| 空間 | 誰的 | 做什麼 |
|---|---|---|
| **自己的領地**（新手期，青溪借給新人的舊宅加後院） | 個人 | 種靈草、練功練氣、閉關、佈置、收藏（博古架） |
| **大世界**（不周大陸，從鼇極開始） | 全服共用、連線 | 探索、採集、狩獵、見聞與機緣、世界事件、主線 |
| **宗門分院**（山城） | 同門共用 | 拜師、宗門任務、大比、住處（宗門分派） |
| **各地本宗** | 開放後所有人 | 那一章的主線、鎮派絕學 |
| **秘境** | 依種類 | 見第六節 |

## 六、玩法

### 一直都有的
| 玩法 | 內容 |
|---|---|
| 修煉與突破 | 練氣、練體、功法；境界瓶頸要渡劫 |
| 生活技藝 | 種田、煉丹、煉器、畫符、佈陣 |
| 探索 | 見聞（人人找得到）、機緣（只有部分人遇得到，伺服器決定）、攀爬、隱藏地點 |
| 收藏 | 博古架擺出自己的旅程 |
| 靈獸 | 狩獵，之後可以馴養、騎乘 |
| 世界事件 | 全服一起修水路、守古樹 |
| 鴻篆 | 每人拿到的碑文片段不同，要交流才拼得出來 |
| 晝夜時辰 | 照現實時間；有些東西只在夜裡出現（已上線） |

### 新手期（前十天）
- 領地種田、練功；青溪斷流主線（上游調查、修水路、回村）；和其他新手一起探索、搶稀有機緣。
- 第十天測資、收接引帖、選宗門。

### 宗門
- 外門 → 內門 → 親傳：越往上，學得越深，也知道越多宗門的秘密。
- 拜師、宗門任務與貢獻、住處經營、守天樞值守、宗門大比、宗門工程。
- **宗門對決**：論道大會（公開比試）、約戰（向有恩怨的宗門下戰帖）、靈脈節點爭奪、宗門排名（獎勵名聲與外觀，不給強度）。

### 秘境
| 種類 | 能不能打 | 內容 |
|---|---|---|
| 劇情秘境（例如每週裂靈湖） | 不能 | 主線與感人時刻 |
| 爭奪秘境 | 自由對戰 | 寶物有限，帶到出口才算；被打倒掉一部分撿到的東西 |
| 宗門秘境爭奪 | 宗門對宗門 | 爭一季的管理權 |
| 其他（宗門秘境、機緣秘境、回溯過去的秘境） | 依設計 | 之後規劃 |

### 玩家對戰
| 地方 | 能不能打 |
|---|---|
| 新手大世界、宗門、城鎮、領地 | 不行 |
| 切磋 | 雙方同意，不掉東西 |
| 宗門大比、論劍台 | 規則內 |
| 險地、爭奪秘境 | 可以，進去前明確提示；打輸掉一部分剛採到的材料，不掉綁定物品與修為 |

依境界分段配對；人數以手機跑得動為準（例如 5 對 5、10 對 10）。

### 倒下：瀕死，不是死亡
1. 倒下先進入瀕死，約 60 秒內別的玩家可以「渡氣」扶你起來。
2. 沒人救就被帶回去療傷：新手期回青溪藥鋪或領地，入宗後回宗門醫堂。
3. 療傷幾分鐘，之後帶著「傷勢」一段時間；吃丹藥、泡藥浴可以提早好。

### 多人：個人的與全服一起的
- **個人的**：修為、宗門階級、機緣、支線，照自己的步調。
- **全服一起的**：世界大事、主線轉折，同一時間在全服發生。最感人的時刻放在這裡（「那天晚上你在哪裡」）。

## 七、遊戲怎麼長大

1. **現在**：新手大世界的青溪河谷（村子、官道、西溪、上游）加新手領地，做到「一個人玩得完整、好玩」。
2. **再來**：古林、山城、裂靈湖；第十天測資；山城先開兩、三個宗門分院（伺服器已有玄岳宗、太玄道院）。
3. **然後**：多人連線。
4. **之後每個大版本**：開放不周的一個新地區（某個道統的本宗所在），加宗門、加故事、提高境界上限。
5. **最後**：雲境。
