# 入世、宗門與秘境 · 玩法修訂 v0.2

2026-10-24。使用者本輪要求優先於舊 v0.1 的衝突部分。**這是設計文件，不是已完成的遊戲功能。** 下文分開標示「已確定」與「建議」，未確認的數值不可當成正式平衡。

## 一、已確定的新主流程

創角並隨機確定先天 → 初期共同聚落 → 人人取得煉氣訣 → 居家修煉／採集／低級狩獵 → 材料換靈石、購丹藥裝備 → 創角滿十個現實日 → 廣場測資與宗門選比 → 選宗門及起始身分 → 獲洞府與靈田 → 技藝、任務、貢獻及晉升 → 限時秘境尋找機緣。

| 項目 | 使用者已確定 |
|---|---|
| 出生 | 創角時隨機分配天賦、靈根等；差異保留，不重抽 |
| 揭露 | 廣場選比時得知確切資質；先天早已存在，不是在選比重抽 |
| 起步 | 大家在共同地點生活，均獲煉氣訣；可居家修煉或外出謀生 |
| 選比時間 | **創角後經過 10 個現實日，離線也計**；不是累積 240 小時遊玩 |
| 宗門身分 | 高資質可直接內門；普通資質從雜役或外門逐漸晉升 |
| 入宗獎勵 | 個人洞府、床、箱子、可種植靈田 |
| 宗門空間 | 公共地方多人；其餘是個人遊玩；可查看宗門有幾名玩家 |
| 宗門生活 | 可煉器、煉丹、出任務換貢獻；貢獻換修煉資源 |
| 秘境 | 每日／每週輪替；有通用及特定宗門入口，另有境界、年齡等條件 |
| 秘境時間 | 每次約一小時；活著就能在時限內繼續探索尋機緣 |

「共同地點」延續既有分區與分線技術，世界觀上是同一聚落，並不承諾所有帳號在同一即時程序。宗門私域不必持續運行多人伺服器，但資產與計時仍由後端核定，不能把「單機」等同本機可改存檔。

## 二、十天前期：給玩家選擇，不把它做成等開門

**建議**起步住宅採聚落借住小屋，只有床、基礎箱子與修煉位置；宗門洞府是正式安居與種植的解鎖。入宗前可採野生靈藥，也可在 NPC 藥圃試做種植教學，但不提前贈送完整私人靈田。

下表是內容節奏，不是每天強制完成的作業。可提早探索，也可晚幾天補做；十天期間不要求連續登入。

| 時段 | 主要內容 | 可留下的成果 |
|---|---|---|
| 第一次遊玩 | 領煉氣訣、試修煉、採一味草／完成一場低風險遭遇 | 有第一筆收入，知道先天差異會影響效率 |
| 第 1–3 日 | 三條採集路線、低級獵物、藥鋪與鐵匠、基礎武技 | 第一件工具／武器或一批修煉藥物 |
| 第 4–6 日 | 青溪調查、材料辨識、採獵委託、共同事件 | 名聲、探索知識、不同宗門線索 |
| 第 7–9 日 | 宗門功法展示、導師公開課、選比模擬 | 理解主修適性，準備入門試煉 |
| 滿 10 日後 | 廣場測資、選比、選宗、領洞府 | 從散修起步進入正式師承 |

較忙的玩家滿十日就取得選比資格，不補十份日課；強度高的玩家可先精進技藝、裝備及探索，不能只剩登入等待。是否允許入宗前築基需在成長曲線測試時確定，不能沿用舊版 12–48 小時築基目標後再硬加十天限制。

**前期三種等價選擇，不等價效率：**修煉者換取穩定修為；採集者先建立材料知識與收入；獵手承擔戰鬥風險換獸材。天賦高者修煉仍更快，生活玩法不偷偷將其優勢抵銷。

## 三、煉氣訣、凡骨與資質揭露

**建議**煉氣訣是共通入門教材，分為識息、調息、引氣。人人能閱讀與做呼吸訓練；無靈根者的引氣會明確顯示「目前未感應靈氣」，可以同步練基礎武技、淬體，並逐步取得後天開靈線索。不能讓凡骨十天都按一個必定失敗的按鈕，也不能為了人人領訣就取消無靈根設定。

測資前顯示可理解的體驗資訊，例如這次吐納所得、能否引氣、武技練習進度；不顯示精確先天級別、全部靈根與特殊體質。玩家可能從效率推測自己的資質，這是玩法的一部分，不承諾讓玩家完全猜不到。

測資後分別呈現「出生時的先天」與「十日以來的當前修行狀態」，不要把後天努力誤當成出生改抽。角色能力從第一天便依真實先天計算。

工程上必須建立公開角色投影：不能只在 UI 藏文字，卻透過 `/me`、操作收據、日誌或其他角色查詢送出完整出生資料。正式出生分配須與創角同一交易，故障重試取得原紀錄。

## 四、廣場選比與宗門晉升

**建議**滿十日後資格永久保留，廣場可隨到隨測。典禮可有固定演出時段，但不能因錯過半小時就再等一週。仍可選擇暫不入宗，繼續探索與謀生。

選比由四步構成：測資揭露 → 宗門／導師介紹 → 依主修進行基礎試煉 → 顯示各宗門可獲身分、由玩家選擇。每個宗門按自己的傳承看適性，不用一個全服戰力分數包辦。

| 身分 | 建議起點與權益 | 晉升路徑 |
|---|---|---|
| 雜役 | 基礎洞府、靈田、入門教材、可選生活與外勤委託 | 穩定修行／一項技藝成果／個人試煉 |
| 外門 | 更多教學、一般宗門功法、較廣資源兌換 | 境界、功法掌握或生產研究、進階試煉 |
| 內門 | 更早取得核心導師與高階教學、較好的初始供給 | 完成個人傳承與宗門責任；後續身分另定 |

高資質直接內門的優勢必須實在，不附加反向成本抵銷。凡骨／常資也能晉升，不以出生等級永久鎖內門。確切資格表（哪些天賦、哪些適性直入內門）另做可測配置，本版不擅自確定門檻。

雜役不是只准清掃打雜：藥圃、護送、採獵、器坊助手皆可選；難度與獎勵明示，不強制十次相同工作。晉升沒有固定名額，也不由其他玩家核准。大宗門人多不會因此耗盡新人的入門配額。

## 五、宗門私域與多人生活

公共空間包括山門、廣場、講法堂、坊市、組隊與秘境入口。私人洞府、田地、個人煉製操作獨立載入；他人不會突然進來偷取或摧毀。

宗門資訊建議分開顯示「總弟子數」「近期活躍」「當前在線」；不把帳號總數顯示成現場人數。可選同門通訊及小隊外出，維持世界有人共同生活的感覺。

入宗的床、箱子、田格採一次性配發；改名、重新登入、退宗重入與轉宗不能重複領取。轉宗保留個人財產，建議把箱子與布局搬到新洞府；宗門限定建築可換外觀，不銷毀物品。私人洞府邀訪是未確認的後續功能，本版不自動沿用舊版 4 人訪客。

## 六、靈石、貢獻與生產循環

**靈石循環：**採集／狩獵 → NPC 收購或後續玩家市場 → 買藥、工具、裝備、維修 → 挑戰更深地帶。

**貢獻循環：**宗門任務／品質合格的製品／研究成果 → 個人貢獻 → 教學、材料、藥物或修行服務 → 更有把握完成進階任務。

**建議**NPC 保底收購常見材料，但採集點與任務產出由服務端控制；沒有玩家買也能生活。普通物品可直接交易，高級關鍵成果維持已有綁定與試煉規則。貢獻不可轉讓，不與靈石固定雙向兌換，避免買材料無限循環刷貢獻。

委託收料應採指定品項、數量、品質與有限需求。煉丹、煉器都提供晉升成果，但不能買一件成品便當成自己掌握技藝。工具／設備支援生活路線，戰鬥裝備不包辦全部收益。

修煉丹藥建議補充能量準備，有吸收時段及適用境界；功法掌握與突破試煉仍須完成。首版先避免堆疊複雜丹毒數值，用用途、品質與服用間隔形成選擇。

## 七、每日／每週秘境：時間、宗門與年齡

秘境以「內容模板＋本次開放場次」定義，避免為每天輪替製作全新地圖。地形、事件組合、入口條件、資源與危機可以不同。

| 建議秘境 | 入口特色 | 一小時內的主要決策 |
|---|---|---|
| 青溪藥谷 | 多宗門、低境界 | 普通藥材穩收，或追蹤稀有靈植深入濁氣區 |
| 古劍冢 | 問劍山／劍宗傳承資格 | 解劍紋、挑戰殘影，換取劍訣理解與本命劍素材 |
| 丹霞遺圃 | 丹霞谷或未來明示的交流資格 | 判斷藥性與採收次序，保住易損材料 |
| 玄岳試煉洞 | 體修相關資格 | 搬障、承壓、護送，選擇更深層淬體機緣 |
| 斷脈古府 | 多宗門週輪替 | 小隊分工修陣、偵察與應戰，取捨路線與撤離 |

上述名稱及配額是建議，並未承諾首版同時製作五張新地圖。先做一個通用秘境與一個宗門秘境驗證，再擴充模板。

**入口驗證建議：**宗門、傳承、境界上下限、角色年齡、場次開放、個人次數、組隊每位成員逐一檢查。不能由高階隊長帶未達條件者繞過，也不能開局後換線刷新一小時。

**一小時建議採整個場次的截止時間。**單人從自己進場起算；組隊以開場時間起算，遲加入不延長。可以提早撤離；到時仍存活則由陣法送出並結算，不因最後一秒仍在移動就判死。開始前顯示剩餘開放時間；不允許在只剩幾分鐘的入口偷偷開出承諾一小時的新場。

每日輪替代表每天不同組合與入口，建議一整日可開個人／小隊場；每週公布接下來七天列表。不把可玩時間壓成每天晚上唯一一小時。宗門專屬秘境保留特色，但核心通用突破材料要有其他路徑。

**年齡尚未定案。**推薦使用角色世界年齡，與真人生日分開。創角十日用現實日，年齡可以採另一個明示的成長時鐘。建議年齡主要在修行／探索時推進，離線不令角色錯過全部青年內容，也不讓長期未登入者老死；具體換算比率與年齡上限待確認。不可默默用註冊天數充當角色年齡。

## 八、死亡、斷線與「機緣」的建議

使用者已確定死亡會失去繼續待在本次秘境的資格；以下損失規則是建議：

- 進場前資產不掉落，死亡不永久毀角或掉境界。
- 場內所得分成「已封存成果」與「攜帶中的收穫」。封存點的位置與使用限制明示；一般稀有材料需成功撤離帶出。
- 死亡失去未封存收穫並結束本次機會；已獲得的故事線索／知識按事件明示保存。讓深入有風險，也不抹掉全部發現。
- 斷線不重置時間、不直接判死；暫留角色並允許重連同場。伺服器事故另採可稽核的退票／保全方案，不能信任客戶端聲稱斷線。
- 第一版不強制玩家互殺。危險由妖獸、陷阱、環境與路線產生；是否另開可互鬥的秘境模式，待專門設計。

機緣不是只有稀有掉落：可有靈植變種、失落工序、導師線索、法器殘片、改善體質的事件線索、一次有代價的選擇。高資質可以更容易深入，但不壟斷他人的個人發現資格。關鍵永久改造必須走可追蹤流程，不能設計成全服只有第一人碰到就永久消失。

範例：進場 15 分鐘已採到普通藥材；20 分鐘發現傷獸，可以救治取得隱藏路線，或繼續採藥；35 分鐘找到古方，需決定先封存或深入；50 分鐘濁氣增強，剩下的撤離時間可見。玩家可以在 25 分鐘帶著穩定收益離開，不必待滿一小時才有收穫。

## 九、工程差異與下一批工作

| 目前 v0.3 原型 | 新規格需要改動 |
|---|---|
| 手動出生操作立即顯示天賦 | 創角原子分配、測資前公開資訊投影、廣場揭露 |
| 可直接加入兩宗並修行 | 入宗前煉氣訣／武技；十日資格、選比與初始身分 |
| 起步便能用四格田 | 前期借住；入宗一次性配發洞府與田格 |
| 無角色年齡與宗門晉升 | 確認年齡時鐘、個人評定與升階條件 |
| 無戰鬥與秘境場次 | 先完成基本敵人、掉落、可信場次與存活／撤離結算 |
| 無同宗人口資訊 | 後端人口摘要與在線統計，與分線人數區分 |

順序：先做創角／揭露／十日門檻與前期修行 → 入宗身分與洞府配發 → 採獵及貢獻閉環 → 一個可完整撤離的秘境 → 輪替與多種入口條件。不要一次把所有宗門與秘境量產後才驗證玩法。

服務端用 `createdAt + 10 × 24 × 60 × 60 × 1000` 判定資格，固定 UTC 絕對時間；不同時區、修改裝置時間、重裝與換手機都不能提早。創角失敗重送不可刷新建立時間。

老測試存檔保留出生、道具及既有洞府，不倒扣；以明確 migration 標記兼容。未有真實創角時間時不得猜測，把測試角色視為既有測試資格並保留稽核。正式新角色從完整新流程開始。

驗收至少涵蓋：十日前 1 ms／整點、十日離線回來、多裝置同時測資、未測資 API 不洩漏、無靈根第一天可成長、重入宗不重領、晉升不重複扣貢獻、年齡邊界、全隊資格、場次重連不延時、死亡與撤離並行只結算一次、伺服器重啟不複製場內收穫。

## 十、仍需試玩或後續確認

年齡的流速與限制、各宗入門分級表、秘境死亡損失與封存規則、入場次數及單人／小隊差異、轉宗冷卻與貢獻處理、前十日可達境界。以上已有建議方向，尚未當作使用者定案。
