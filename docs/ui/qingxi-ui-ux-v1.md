# 青溪新手入口 UI／操作 v1

更新：2026-10-27。這是《雲境》自己的介面與按鍵配置，不沿用參考遊戲的 HUD 圖案、排列或技能鍵配置。只在本機統一世界試走版接入，尚未接帳號、背包或戰鬥。

## 畫面與導引

- 左上顯示所在地，角色接近聽風台、採集點或商販時更新。
- 右上以「現在可以做」提出聽風台、溪畔和山兔三種方向，不強制依序完成，也不設在線計時壓力。
- 右側「旅途手札」展開探索選擇；可返回廣場或聽風台入口。傳送僅供本機試走，正式世界的旅行規則另設計。
- 左下僅在玩家學習操作時提示按鍵。正式版會根據輸入裝置替換為觸控、手把或鍵盤提示。
- 配色採青溪的墨青、月白與少量暖金，字與背景有明暗對比，資訊不蓋住角色和道路中央。

## 目前實作操作

| 動作 | Windows 試走版 | 待做的正式版設計 |
|---|---|---|
| 行走／奔跑 | WASD／Shift | 手機左側虛擬搖桿、手把左搖桿；奔跑可切換或長按 |
| 視角 | 滑鼠，V 切換近／遠鏡 | 手機右側拖曳、手把右搖桿；鏡頭碰撞與遮擋待調 |
| 跳躍 | 空白鍵 | 手機拇指區按鈕、手把面鍵 |
| 旅途手札 | M 或右側按鈕 | 手機右上入口、手把選單鍵 |
| 游標 | Esc 解鎖；點非 UI 區域再鎖定 | 手機不顯示系統游標 |
| 山兔互動 | F，只有本機示意 | 接合法距離、動畫、伺服器判定與掉落後重設 |

UI 的意圖是讓玩家自己挑方向。往後的戰鬥操作、功法快捷欄、背包與煉製頁應以《雲境》的「功法準備—環境互動—修行成果」為骨架單獨設計，不照搬其他遊戲的圖示或鍵位。手機橫向版要另量測安全區、拇指可及範圍與中文斷行。

## 實際完成與待驗

- 已完成程式化 uGUI 畫面、地點更新、手札選單與本機定位按鈕；Unity `6000.0.82f1` Windows 建置成功，畫面在 1280×720 顯示中文。
- `QingxiHudSmoke.Verify` 在固定 Unity Editor `6000.0.82f1` 的 batchmode 執行成功：手札由按鈕動作開啟、釋放游標並可關閉。Windows 程式畫面已目視確認；實際滑鼠點擊與鍵盤焦點仍待玩家操作驗證，手機橫向安全區、手把與重連也未驗證。Windows 程式可啟動不等於手機版完成。
- 山兔、靈草、任務與修行的顯示目前只是探索提示；沒有從 HUD 發放資產或繞過伺服器權威。
