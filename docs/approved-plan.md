# 《雲境》已核准設計基準 v0.1

2026-10-21。來源：使用者在本聊天貼上的《雲境》39 節完整專案方案並要求實作。本文件是便於工程維護的規格摘要；完整原文仍以聊天中的核准方案為準。未完成範圍見 status.md。

## 2026-10-24 優先修訂

使用者已改定：創角立即分配先天，廣場選比才揭露確切資質；人人先領煉氣訣，在共同聚落修煉、採集與狩獵謀生。**創角滿十個現實日（離線也計）**後開宗門選比，高資質可直入內門，普通資質從雜役／外門晉升。正式洞府、床、箱子與靈田於入宗配發。宗門公共區多人，其餘個人遊玩；可查看宗門玩家數。任務與技藝取得貢獻換資源。每日／每週輪替秘境，可限定宗門、境界、角色年齡，每次約一小時，存活者可持續探索。

這些條件取代下文衝突的「第一小時贈完整洞府」「立即拜師」與私人洞府預設多人訪客。舊築基時間曲線需重估；十日不能解讀為累積 240 小時。詳見 [玩法修訂 v0.2](gameplay-revision-v0.2.md)，其中標為建議的死亡、年齡換算、晉升門檻等尚非使用者定案。

## 產品與世界

獨立 Unity 原生手機橫向＋Windows 多人修仙生活 RPG，手機優先。同一遊戲角色跨裝置；樹伴仍是 Flutter 陪伴服務與斜俯視小世界，不把整款遊戲嵌入 Flutter。人格複製、聲音複製、逝者數位代理排除。

背景「斷脈之後」：玩家以個人洞府、宗門師承與共同環境修復，走出自己的成仙之路。以分區串成大世界，不採全服同一張無縫地圖。

| 空間 | 目標 |
|---|---|
| 私人洞府 | 含主人共 4 人 |
| 山院 | 24 名固定居民；即時分線 12 人 |
| 野外、宗門、坊市、公共危機 | 每條分線／場次 12 人 |
| 秘境 | 1–4 人，隨人數提供可行解法 |

宗門決定師承；山院決定鄰居，兩者獨立。山院無玩家會長與核心獎勵分配權。朋友優先同線，無活躍鄰居可搬遷。五到十分鐘可安排生產，二十到四十分鐘可完成探索，六十到九十分鐘可進行秘境與工程；不強制每日固定集合。

## 成長與先天差異

先天差距真實存在，天命不必附帶等值弱點。凡骨可以走到高境界，但付出與速度不必相同。禁止付費重抽、輪迴重抽、改名／換裝置／轉區重抽。機率是暫定測試值。

| 類型 | 機率 | 特徵 |
|---|---:|---|
| 凡骨 | 10% | 無先天靈根、靈竅、特殊體質 |
| 常資 | 76.97% | 基本單靈根、普通體質、少量靈竅 |
| 良才 | 10% | 更好的靈根、吸收與靈竅 |
| 天驕 | 3% | 明顯優勢，可能有特殊體質 |
| 天命 | 0.03% | 極稀有頂級組合 |

獨立抽樣，不按伺服器硬配額。先天紀錄不可變，當前靈根、靈竅、經脈、氣海、功法、心境與傷勢可成長。心境來自遊戲經歷，不做現實人格判定。本作允許優秀多靈根較強。

凡骨：識身 → 武技、負重 → 藥浴 → 淬皮鍛骨 → 氣血循環 → 體修築基。可持續體修或透過有明確師承的後天開靈轉向引氣。第一小時就能完成有意義挑戰，不能只有等待。

普通玩家選功法、資源配置、材料取得與師承。高天賦更快累積能量、承載更多功法並早用高要求招式，仍需掌握及試煉。第一次築基有效遊玩目標依序 36–48／24–32／20–26／16–22／12–16 小時，必須實測；目前原型不是此數值曲線。

首版境界：凡身／啟蒙、煉氣／淬體、築基／體修築基、結丹／體丹。元嬰、化神及更高境界留待擴充。突破由準備、掌握、試煉構成；失敗指出原因與修復路線，不隨機扣光材料或永久毀掉角色。離線修行最多 24 小時，作物按完整週期結算；沒有現實時間老死。

## 宗門、戰鬥與合作

官方宗門：太玄道院（綜合）、問劍山（劍）、玄岳宗（體）、丹霞谷（靈植丹藥）、天工門（器陣符）、御靈谷（靈獸）、玄冥宗（特殊能量與魔道）。首版各至少兩位不同方向導師。無玩家審核或有限招生名額；高階傳承可要求適性、境界與聲望。拜師前演示適性，轉修保留知識但需熟悉，不沒收洞府、裝備、出生。

劍修以距離、劍勢與破綻；體修以氣血、格擋、反擊；法修以屬性順序與範圍控制。魔修是可組合功法，以濁息管理風險，不等同強制 PK。角色可兼修，裝備功法有限。

手機：移動、鏡頭、普攻、防禦／閃避、兩個功法、一個本命技能、一個消耗品。鎖定、輔助瞄準、改鍵、減震；電腦不多一套技能欄。敵人有可辨識預告，不只堆血量。不強制坦補輸出配置，救援、護陣、解機關有價值。PvP 首版僅雙方同意切磋，無核心獨占獎勵。

## 洞府、生產、生態

住宅、靈田、丹房、器坊、靜室／演武場、水池水渠、陣眼、靈獸棲地。模組化建築、區塊布置；水、靈氣、土壤、陣法承載、工作位形成配置決策。訪客採收與搬物需明確授權，無偷菜。

六技藝：靈植、煉丹、煉器、陣法、符籙、御獸。材料共用屬性、藥性／材性、純度、穩定性。第一次研究重選擇，掌握後可批次可靠產出；研究失敗留下知識及回收，不炸掉本命法器。

一般作物 30 分鐘、4／12／24 小時起步，特殊靈植需環境。成熟不腐爛，不因漏登入毀田。靈獸探索取得，一隻出戰、一隻工作，首版不做抽卡及大量繁殖遺傳。

區域狀態：靈氣、水土、濁氣、妖獸壓力。公共靈脈不能永久私人占有；個人產出資格，不搶最後一下。共同工程有固定位置與分段成果，玩家不能拆掉他人成果。

青溪斷流事件：調查破陣、水蓮、妖獸育幼地；恢復生態、修復陣路、建立替代棲地或驅離。可分階段完成不同解法，不替別人永久封死主線。事件回饋洞府、配方、師承與環境。單人有工具／NPC 解法，合作提高效率。

## 經濟與樹伴連動

靈石是交易媒介；靈礦不直接無成本印錢。普通材料多數可交易；突破領悟、試煉、宗門貢獻綁定。資源回收包含煉製、維護、修復、交易費、擴建，修復不降永久上限。

固定價格刊登＋託管代煉＋NPC 基本服務。首版不開自由丟物、直接送靈石、全服競標、帳號交易。代煉繼承原料綁定。公共王個人獎勵，救援與機關可貢獻；多時段、多分場、跨線只領一次。突破材料有穩定替代來源。

樹伴可選綁定：個人兩格輸送田，每格一株、14 天成熟；任意連續 28 天同遊戲身分最多接收四株；不得把整圈產量集中。生長不要求陪伴任務，陪伴成果可提供紀念外觀。

一株連動靈草約兩株普通藥性，特定配方效果可加 10%。原料和成品綁定，不加永久靈根、不代過試煉。品階依已解鎖境界；遊戲內可取得同類用途及同級成品。改綁不重置額度，未完成輸送禁止改綁。

來源鎖定 → 唯一輸送 ID → 接收方檢查 → 物品與收據同交易 → 來源確認扣除。逾時不可直接退款；取消需先在接收方留下防止遲到入帳的取消紀錄。暫停連動不影響其餘遊戲。

## 體驗與付費

第一小時：外觀、出生、基本能力、小洞府與首次種植、兩種師承、看到其他玩家、青溪小成果、下一個目標。普通死亡有限磨損，不掉重要資產／境界；已結算成果保留。無永久死亡、強制掠奪、連續登入懲罰。

免費進入，固定價格外觀（服裝、建築、家具、技能／御器外觀）。不賣重抽、靈根、突破、種植加速、輸送田格、戰力月卡。封測不收費。

## 技術與發布基準

Unity 6000.0.82f1、URP 17.0.4、Blender 母稿；FishNet 4.7.4／Tugboat、Linux Dedicated Server、30 Hz 起步。伺服器判定碰撞、命中、傷害、消耗，客戶端預測／校正。空區五分鐘保存休眠，生產用服務端時間結算。

NestJS 模組化單體、PostgreSQL 資產真相、Redis 暫態工作、物件儲存與 CDN。Cloud Run API、Compute Engine 遊戲程序，單亞洲區域封測。獨立 Firebase Auth，用外部瀏覽器、PKCE、單次代碼換遊戲憑證；Windows 不依賴開發用途的 Firebase Unity 桌面 SDK。短效單次區域票證、同角色一個可操作連線。

出生唯一靠資料庫約束與冪等處理；真人一帳只能提高防刷成本，不能宣稱絕對唯一。封測邀請、公測手機驗證與風險訊號；不首版收證件或生物辨識。

所有資產變動唯一請求、持久保存後確認，來源與變動帳本。位置五秒保存；區域單一有效寫入者；資料庫故障停止資產操作。備份與還原演練、補償稽核、聊天封鎖檢舉申訴、商店／交易／連動獨立開關為發布門檻。

原始素材與大型二進位 Git LFS，快取不進 Git；共用素材必須固定版本及來源授權。Unity 與 Unreal 同條件對照樣片是未來限定驗證，不同時維護兩套正式遊戲。

美術：風格化東方仙俠，溫暖院落、清楚輪廓、自然材質與手繪色彩。手機降低陰影／植被／反射，PC 提高畫質但互動碰撞相同。聲音、動畫與手感納入第一完成樣片。

## 製作資源與風險

樣片估 3–4 位核心製作者 4–6 月；正式首版約 8 人 18–24 月。只有使用者與 AI 時先以 M0–M2 實際證據重估，不能套團隊時程。八人每月完整成本假設 NT$12 萬，18–24 月加 35% 預留約 NT$2,330–3,110 萬；這是規劃假設，不是報價或支出授權。

伺服器以實測 CCU、程序 CPU／RAM、頻寬、資料庫、下載、儲存、驗證費估算，不以註冊人數保證便宜月費。未授權就不建立付費雲端服務。

首要風險：系統互不連結、凡骨只有等待、天才壟斷資源、樹伴變必需、手機熱降頻、跨 App 耦合、複製物品、重複真人註冊、過早大量地圖、團隊不足。分別用完整事件、凡骨階段成果、個人獎勵、替代來源與額度、真機樣片、獨立介面、交易帳本、防刷如實說明、里程碑範圍及樣片產能驗證處理。
