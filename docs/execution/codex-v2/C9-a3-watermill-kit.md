# C9｜A3 西溪水磨坊套件（約 28 小時）

> 先讀 `00-operating-rules.md`，以及主場景工作樹 `docs/execution/blocks/A2-A3-block-plan.md`（A3 那一節）。
> 屬於 **A 青溪河谷**。

## 1. 一句話任務

做 A3 區塊（村子西邊的溪谷）的全套場景模組：
- 水磨坊與水車、引水渠；
- 洗衣埠頭、釣魚台；
- 單拱石橋、踏石；
- 竹林小亭；
- 低面數的溪石與蘆葦。

讓玩家走出村子西邊，看到「水車轉、溪水流、竹林搖」的第一個風景區。

## 2. 為什麼要做

- A3 是新手村之後的第一個風景區，也是協作者 B「斷流水路」玩法的實景地點。
- 現有的蘆葦叢和靈草每件 2.4–3.5 萬面，是網頁版下載太大的原因之一。這套要附**低面數**的替代品，示範怎樣「好看又輕」。

## 5. 重點要求

1. **水車要會轉**：WM02 的原點在軸心，旋轉軸是模型的 X 軸，寫進 README。另交一個 30 幀的 Blender 轉動預覽 GIF 或 MP4。
2. **橋要能走**：WM07 附可走路面的碰撞網格 `UCX_WM07_Deck`，平滑、沒有台階卡腳。
3. **低面數示範**：WM10–WM12 做完後，和現有的 `QX_WaterReeds`（`apps/game/Assets/YunJing/Models/GatheringB/Creek/`）在同一鏡頭並排，寫出面數對比。
4. **組合樣張**：在 Blender 依 A2-A3 區塊規劃的 A3 分區座標排出整個水磨坊區，渲染：
   - 俯視；
   - 從橋上看水車；
   - 從釣魚台看磨坊。
   - 中性光與遊戲光各一套。
