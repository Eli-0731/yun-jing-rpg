## 4. 每一項要回答的問題

照 `pr-review.md` 第 3 節的清單 A–E。另外每份工作包都要回答：

1. **位置**：工作包裡的東西放在區塊規劃的哪個區塊、格位？沒有位置的列出來。
   - 例如上游屬於 D3，D3 還沒有格位表。
2. **空間**：有沒有把該在領地做的事（種植、練功）放到大世界，或反過來？
3. **世界觀**：
   - 東西和文字對應世界觀的哪一層？
   - 有沒有說破未來？
   - 有沒有寫成單純的壞人？
   - 名字能不能照取名三層法改得更好？只提建議，不替協作者定案。
4. **用語**：照規範 §3.2 的用語表（洞府→住處、背包→乾坤袋……）。
5. **伺服器**：玩家做的事要變成哪些伺服器動作？列名稱、輸入、結果、冷卻。實作由 Claude Code 做。
6. **效能**：有沒有 LOD1／LOD2；重複件會放幾個。**不要求減面**（品質優先）。
7. **順序**：符合「先把青溪河谷做完整，再做多人」嗎？有沒有該延後或提前的？
8. **協作者之間**：A、B、C 的東西接得起來嗎（水接口、材質、尺寸）？
