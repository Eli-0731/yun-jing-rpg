- 要並排比較的既有作品（指定哪一件）

## 5. 寫工作包的規則

1. **位置先於模型**：沒有格位就不發工作包。需要新格位的，寫在 `questions-for-claude.md`，由 Claude Code 加進區塊規劃。
2. **一份工作包只有一個主題、一個區塊**，不要一份包山包海。
3. **分量要和協作者過去的實際產出相當**：
   - 參考：A 的 #45 一輪約 24 個形體與一個可玩展示；
   - 不要少到半天做完，也不要多到兩週做不完；
   - 寫出總時數（過去常用 14 小時或 42 小時的批次）。
4. **每件東西都寫面數上限**，照建模規格 §6 的類別；不能讓協作者自訂預算。
5. **重複件寫總量**：例如「這段河 100 m，最多放 14 段，總面數 ≤ 84,000」。
6. **玩法一定寫到伺服器**：只做展示的部分要明說「這是展示，不算進遊戲」。
7. **不交代**：工作包裡可以寫真相（給協作者理解），但要標明「這段給你理解，不能出現在遊戲文字裡」。
8. **用語照用語表**；不用「洞府」「背包」。
9. **協作者之間的接口寫清楚**：水接口、材質名、尺寸，誰先定、誰跟著用。
