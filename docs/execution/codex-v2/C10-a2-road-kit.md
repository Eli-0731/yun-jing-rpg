# C10｜A2 村外官道套件（約 24 小時）

> 先讀 `00-operating-rules.md`，以及主場景工作樹 `docs/execution/blocks/A2-A3-block-plan.md`（A2 那一節）。
> 屬於 **A 青溪河谷**。

## 1. 一句話任務

做玩家**走進青溪之前那段路**的全套陳設：
- 路牌、里程石；
- 路邊茶亭與小攤；
- 載貨板車；
- 土地祠（第一個機緣點）；
- 圍籬、路燈、觀景石凳、草垛。

## 2. 為什麼要做

- 這段路是遊戲的**第一印象**：新角色從這裡出發，一路看到遠山、溪流，最後在坡頂看見村門。
- 原神的開場會用路上的小東西（告示、營火、路人）告訴玩家「這是一個有人生活的世界」。A2 也要做到。
- 土地祠是「機緣」系統的第一個示範點：玩家拜一拜得到線索，教會玩家「到處看看會有收穫」。

## 5. 重點要求

1. **開場鏡頭**：在 Blender 依區塊規劃的 A2 座標，排出「從起點 (2, -40) 往北看」與「坡頂 (-4, 34) 往北看村門」兩個鏡頭。用 C4 的天際線概念圖當背景板，看前中後景是否成立。
2. **機緣點**：RK06 的 `Glow` 網格要能單獨開關。在 README 寫建議的發光顏色（色票的靈氣青 `#7FE0D4`）和強度。
3. **和 C7 同家族**：路燈、圍籬的木色與石色，要和 C7 的村口石燈、水井一致，看起來是同一個村子的東西。
