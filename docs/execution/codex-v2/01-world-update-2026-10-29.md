## 2. 世界觀（細節：`docs/story/world-lore-v1.md`）

- **一句話**：不周是浮在雲海上的許多塊大陸。很久以前天裂了（天缺），先人立「代天大陣」撐住天。陣快撐不住了。真正能讓世界活下去的，是活在上面的每一個人日常做的小事。
- **真相分五層**，越後面越深。新手十天只碰到第 1、2 層。
- **沒有真正的壞人**：每個宗門、每個人做的事，從他們的角度都是為世界好。
- **宗門很多**：
  - 七柱宗門：太玄道院、玄岳宗、問劍山、丹霞谷、天工門、御靈谷、玄冥宗；
  - 分支宗門；
  - 新宗與散修。
  - 可以一直加。
- **多文化**：各地神話講的都是同一件事（天缺、撐天的東西），只是版本不同。

  | 地方 | 文化 | 名字的典故 |
  |---|---|---|
  | 鼇極（新手世界所在） | 中國 | 女媧砍下巨龜的腿當新天柱 |
  | 八雲 | 日本 | 斬八岐大蛇後的第一首和歌 |
  | 夕苑 | 希臘 | 阿特拉斯扛天處的黃昏花園 |
  | 霜淵 | 北歐 | 冰與火之間的原初深淵 |
  | 羽衡 | 埃及 | 心臟與真理之羽的秤量 |
  | 眠海 | 印度 | 毗濕奴沉睡的原初之海 |
  | 天骸 | 兩河流域 | 用巨龍的半個身體做成的天 |
  | 翠穹 | 馬雅 | 四角神明扛著的玉色天穹 |
  | 雲境 | 原創 | 天缺下的浮島 |

- **天樞**：撐天的東西，**形狀不限**（山、樹、巨人、鏡子、天平、燈……），可以依想做的產品和物件設計。**小天樞**撐住一方水土，新手期就看得到，例如青溪村口的第三盞燈、縫脈陣的陣基。
- **長線的謎**（反覆出現、很久不解釋）：
  - **斷章**：每個文化的史書都被撕掉同一章；
  - **鴻篆**：刻在鴻篆碑上的上古文字；
  - **缺月**：像缺了一角的月亮的記號。
- **脈息**：玩家種田、修水路、淨化，伺服器都會悄悄記下來，代表他們在養世界的靈脈。現在不顯示給玩家。

## 3. 說故事的規則

- **完全不交代**：沒有開場旁白，不說未來會發生什麼。玩家一步一步探索才知道世界怎麼了，像《海賊王》一樣到處埋伏筆。
- 沒有人知道全部；說法可以互相矛盾；答案永遠比問題晚到。
- **取名三層法**：表面好聽，裡面藏一個神話或歷史典故，典故再暗示主線。地名、物品、宗門、靈獸都照這個；**角色名字之後再定**。
- **地名不和其他遊戲重複**：例如不能用原神的「須彌」、二重螺旋的「華胥」。取名前先上網查。

## 4. 遊戲結構（細節：`docs/game-structure-v1.md`）

- **自己的領地**：每個新手從第一天就有。是青溪村借給新人的舊宅加後院，個人空間。
  - 種靈草、練功練氣、閉關、煉丹、佈置，都在這裡；
  - 後院已經有兩塊靈田和身法木樁（灰盒）；
  - 伺服器已允許新手種兩塊田。
- **大世界**：所有新手共用、連線。探索、採集、狩獵、見聞、機緣、世界事件、主線。
- **入宗後**：宗門分派個人住處（玩家看得到的字不用「洞府」）。
- **機緣**：不是每個人都遇得到，由伺服器依機率、時辰天氣、資質與經歷、全服限量決定。人人都找得到的叫「見聞」。
- **世界大小**：目標 5–6 km²。約兩成是手工核心區塊，八成是資料生成的野外區塊。

## 5. 製作順序（z1nnz 決定）

1. **先把一個區域做完整**：青溪河谷 A1–A3，包含晝夜、聲音、對話、地圖、主線序章與第一章；
2. **然後才做多人連線**。

所以現在所有模型與玩法，都以「讓青溪河谷變成一個完整、好玩的區域」為優先。
