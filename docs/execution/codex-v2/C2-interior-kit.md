# C2｜借住處室內模組套件 v1（IK01–IK11）

> 先讀 `00-operating-rules.md`。本工作單**取代**舊的 `docs/execution/p1-codex-interior-kit-brief.md`。
> 主要改動：門洞改成和外觀一致的 1.7 × 2.4 m 雙開門、門牆改 3 m、新增窗格與燈具兩件、房間配置圖。

## 1. 一句話任務

做一套模組化的室內建築件：地板、牆、窗、門、柱、樑、天花等。用它們拼出新手村「借住處」的室內，取代現在的灰盒。

## 2. 為什麼要做

- 玩家在新手村的家就是借住處（joshsu54 的 StarterHouse v004）。推門後進入獨立的室內場景 `QingxiLodgingInterior`，可以睡覺、開箱、打坐。
- 現在室內是 Unity 方塊拼成的灰盒，這是玩家每天會回來好幾次的地方，看起來最廉價。
- 這套模組之後也會拿去拼其他民居、客棧的室內，所以要**可重複使用**。

## 7. 材質與貼圖

整套**共用 4 個材質**：

| 材質 | 用在哪裡 | 色票 | 粗糙度 | 貼圖 |
|---|---|---|---|---|
| `M_IK_AgedTimber` | 木框、柱、樑、門、地板、窗格 | 紅褐 `#7A4A2E`～`#5A3A22`（從外觀量後微調，記錄實際值） | 0.65–0.85 | 1024 Trim Sheet：上半部是幾種寬度的木條，下半部是地板木紋 |
| `M_IK_LimePlaster` | 牆面 | `#D9CFBD`、`#C8BCA6` | 0.85–0.95 | 1024 可重複：細微抹痕；牆腳 0.5 m 內稍髒 |
| `M_IK_GreyStone` | 牆基、柱礎、窗台 | `#5E6B6A`、`#7C8784` | 0.7–0.9 | 512 可重複 |
| `M_IK_WindowPaper` | 窗紙、燈罩 | `#EEE6D2` | 0.9 | 256，帶纖維 |

- 每個材質都要有 BaseColor／Normal（OpenGL）／ORM。
- 貼圖密度：照建模規格，建築 256 px/m，Trim Sheet 例外。
- 使用痕跡：
  - 門框常摸的地方顏色深、磨圓；
  - 門檻中間磨低；
  - 地板在門口到床的路線上較亮。
  - 磨損用頂點色或第二套 UV 的遮罩做，不要每件各做一張貼圖。

## 8. 製作階段（照 00 規範第 5 節，以下是本任務的具體內容）

### Stage 0｜分析
- 打開 StarterHouse v004 的 `.blend`，量出：
  - 牆厚、木框寬、窗格分割、門的樣式、材質顏色（RGB 轉 hex）。
- 量床、箱、蒲團的尺寸。
- 寫進 `PRODUCTION_STATUS.md`：已知結構／推測結構／設計假設。

### Stage 1｜三視圖（imagegen）
做 4 張即可，不用每件一張：
1. 牆系統：IK02、IK03a、IK03b、IK04、IK05 並排的正視圖，加一張側剖面；
2. 門扇 IK06：正、側、背；
3. 柱、樑、柱礎 IK07、IK08：正、側；
4. 窗格與吊燈 IK11、IK12：正、側、背。

提示詞要寫明：
- 正交視角、淺灰背景；
- 紅褐木框、白石灰牆、灰石基；
- 中國南方鄉村民居、修仙世界；
- 尺寸比例（例如「門高 2.4 m，是門寬的 1.4 倍」）。

存檔並寫 README：提示詞、檢視結論、推定設計。

### Stage 2｜Blockout
- 全部模組的灰模，加上**組裝場景**：照第 5 節配置拼出房間，並把三件家具匯入擺好。
- 渲染：
  - 每件的正、側、3/4；
  - 房間俯視（看配置）；
  - **門口眼高鏡頭**：相機在 (0, 1.7, -2.0) 往北看，焦距 24 mm。
- **關卡**：
  - 模組拼接沒有縫、沒有重疊；
  - 家具放得下，床不擋窗，箱子不擋路；
  - 門口看進去的構圖有主次（樑與柱框出畫面，視線落在床或蒲團）。

### Stage 3｜精修
- 倒角：木件 8–15 mm，石件 10–20 mm。
- 木框和牆面要有前後層次：木框比牆面凸出 15–25 mm，不能齊平。
- 門檻、窗台、柱礎的厚度要合理。
- 榫頭、門環、窗格交叉處的接合要清楚。

### Stage 4｜UV
- 用 Trim Sheet 的件，UV 對齊對應的木條；
- 牆面用可重複貼圖，維持 256 px/m；
- 每件做第二套 UV（光照貼圖用，`UVMap_Lightmap`，不重疊，邊距 ≥ 4 px，以 512 計）。

### Stage 5｜材質與貼圖
- 照第 7 節。
- 輸出兩種燈光的房間渲染：
  1. 中性光：規格第 8 節的設定；
  2. **遊戲風格光**：
     - 晨光從南窗與門斜射進來，暖色、帶光柱；
     - 室內補光偏冷；
     - 吊燈亮起（暖色點光源）。
- 加一張 0.5 m 距離的門框特寫，看木紋與磨損。

### Stage 6｜LOD、匯出、回匯
- LOD：每件 LOD0／LOD1（約 50%），物件名 `SM_IK_<名稱>_LOD0`、`_LOD1`。
- 碰撞：
  - 每件在 `model_info.json` 寫建議的碰撞盒（中心與尺寸）；
  - 門扇的碰撞要跟著門軸。
- 匯出：
  - 每件一個 FBX、一個 GLB：`IK01_Floor2x2_v001.fbx`……
  - 另外匯出一個**組裝好的整間** `IK_LodgingRoom_Assembled_v001.fbx`，給 Claude Code 對照用。
- 回匯檢查：寫進 `roundtrip-report.json`。
