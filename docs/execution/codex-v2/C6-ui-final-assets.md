## 1. 一句話任務

把 C1 的概念圖變成**能直接放進遊戲的素材**：
- 14 個向量圖示；
- 玉按鍵、紙面板、搖桿等九宮格圖片；
- 四個區域的外觀變體；
- 「雲境」標誌。

## 2. 為什麼要做

- 概念圖是「看起來的樣子」，遊戲需要的是**可以切開、拉伸、換色、在任何解析度都清楚**的素材。
- Claude Code 會用這些素材在 Unity 裡做 uGUI 元件：`UI_JadeButton`、`UI_PaperPanel`、`UI_FloatingJoystick`、`UI_SealToast`、`UI_RegionTitle`。

**規則**（介面方向文件第 6 節）：
- 畫布 64×64，內容區 52×52（四邊各留 6 px）。
- 線寬 3.5 px（以 64 px 計）。線條端點用**毛筆收鋒**（一端圓、一端尖），不是死板的等寬線。
- 兩種狀態：
  - `_normal`：只有線條，`#1C1F1E` 或 `#EEF2F2`（各出一份，給亮底和暗底）；
  - `_active`：線條加玉色填色 `#5FA89A`。
- 三種尺寸各**手修一次**：32、48、96 px。不能只是縮放：32 px 要簡化細節、加粗線條。
- **必須是向量重繪**：
  - 不准把點陣圖包進 SVG；
  - 不准有 `<image>` 元素；
  - 路徑要乾淨，節點數合理。
- SVG 用 `viewBox="0 0 64 64"`，不寫死寬高。顏色用 `currentColor`，方便程式換色。
- 檔名：`ico_<名稱>_<狀態>_<尺寸>.svg`，例如 `ico_bag_active_48.svg`。

**檢查**（存到 `review/`）：
1. 14 個圖示排一排，在 32 px 下並排，看線寬是否一致；
2. 灰階版本；
3. 色弱模擬：紅綠色弱、藍黃色弱；
4. 每個圖示能不能被沒看過說明的人猜對功能。你自己先猜一次並寫下結果。

## 5. 九宮格素材

每件出 2x 解析度 PNG（透明背景），並在 `slice.json` 寫四邊的切割像素：`{ "left":, "right":, "top":, "bottom": }`。

| 檔名 | 用途 | 2x 尺寸 | 狀態 |
|---|---|---|---|
| `btn_jade_round` | 圓形主鍵、次鍵 | 300×300 | normal、pressed、disabled |
| `btn_jade_cooldown_mask` | 冷卻遮罩（墨色由下往上退） | 300×300 | 一張，程式用填充比例控制 |
| `btn_jade_pill` | 長形按鍵（「使用」「丟棄」） | 240×96 | normal、pressed、disabled |
| `panel_paper` | 大面板（乾坤袋、設定） | 512×512 | — |
| `panel_paper_strip` | 任務條、提示條 | 384×96 | — |
| `slot_item` | 物品格 | 240×240 | normal、selected |
| `joystick_base` | 搖桿底盤 | 440×440 | — |
| `joystick_knob` | 搖桿把手 | 192×192 | normal、running（外圈亮） |
| `seal_square`、`seal_round` | 地名印、通知印 | 200×200 | — |
| `bar_frame`、`bar_fill_hp`、`bar_fill_qi` | 生命、靈氣條 | 600×40 | — |
| `minimap_frame` | 小地圖外框 | 360×360 | — |

- 以 C1 的 A 套為基礎。B 套、C 套只需要第 6 節列出的差異件。
- 圓形按鍵不需要九宮格（固定大小），在 `slice.json` 寫 `null`。

## 7. 「雲境」標誌

- 兩個字的書法感標誌。**手繪向量**：參考霞鶩文楷的結構，但筆畫要有毛筆的飛白與粗細變化，不能直接用字型轉外框。
- 可在「雲」字的最後一筆帶出一縷雲紋，但要克制。
- 出四個版本：深底用（月白）、淺底用（深墨）、單色印章版（朱砂方印裡反白）、小尺寸版（32 px 仍可讀，筆畫簡化）。
- 檔案：`logo/yunjing_logo_<版本>.svg`，加 512 px PNG。
- C3 網頁外殼的標題之後會換成這個標誌。

## 11. 驗收標準

| 項目 | 標準 |
|---|---|
| 向量品質 | SVG 不含點陣圖；在 400% 放大下邊緣乾淨 |
| 一致性 | 14 個圖示排在一起，線寬與風格一致 |
| 可辨識 | 32 px 灰階下每個都認得出來 |
| 區域 | 四區並排一眼可分，但看得出是同一套介面 |
| 可用 | 九宮格拉伸到 2 倍、0.5 倍都不變形；`slice.json` 數值正確 |
| 原創 | 沒有任何元素抄自其他遊戲 |
