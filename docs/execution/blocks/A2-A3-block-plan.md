## A2 村外官道與茶亭（cell [0, -1]，P2）

**用途**：玩家從外界走進青溪的第一段路。這段路要讓人一路看見：
1. 遠山與石峰天際線（C4）；
2. 溪流從右手邊流過；
3. 最後在坡頂看見青溪村門。

這是開場的「第一印象」，不能只是一條空路。

**地形**：南低北高，緩坡 0 → 3 m。官道從南邊界 (0, -50) 彎成 S 形，接到北邊界 (0, 50)，也就是 A1 的 `village-entry` (0, -46)。

## A3 西溪與水磨坊（cell [-1, 0]，P2）

**用途**：
- 溪流主段；
- 水路修繕事件（協作者 B 的斷流玩法）的實景；
- 釣魚；
- 過溪往裂靈湖（C 區）的通道。

這是新手村之後**第一個「風景區」**，要有璃月那種「水車、石橋、竹林、溪聲」的畫面。

**地形**：東高西低，A1 的溪流從 A3 東緣流過。在本地 (30, 20) 分出一條引水渠，經過水磨坊再流回主溪。
