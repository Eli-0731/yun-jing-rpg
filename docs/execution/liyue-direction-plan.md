# 往「璃月感」的青溪世界｜方向與分階段計畫

2026-10-29，依 z1nnz 的五張世界方向圖整理（`art/references/world-master-v1/` 主圖、`art/references/world-directions-v1/` 的 A 河谷、B 垂直山城、C 裂靈湖、D 古林）。目標是**給人像原神璃月的感受，但保有雲境自己的風格**，不複製原神的角色、建築或介面。

## 能不能做到

**可以逐步做到「看起來是同一種感覺」的一小片，但不是一次做出五張圖的整個世界。** 原神的璃月背後是上百人的美術團隊和專用工具。我們能追上的是「構成那種感覺的規則」，再用一塊一塊驗證過的小區擴出去。

方向圖裡的「璃月感」來自五件事，每件都有對應的做法：

| 感覺來源 | 方向圖裡看到的 | 我們的做法 |
|---|---|---|
| 地形層次 | 平地村落 → 階梯田 → 斷崖 → 遠方石峰 | Unity Terrain 由資料產生（已在新手村驗證），加斷崖模型和遠景石峰 |
| 水 | 溪流貫穿、瀑布、湖面倒影 | 地形沿溪挖渠，加水面材質；瀑布用模型加粒子；B 已交付河岸模組 |
| 空氣感 | 晨霧、雲海、逆光、遠景淡出 | URP 後處理：高度霧、色調、Bloom；遠景石峰用簡化模型或 billboard |
| 建築語言 | 青瓦翹角、木棧道、石拱橋、圓形廣場 | 協作者的房屋、橋、宗門件（已在 main），統一材質與配色 |
| 植被密度 | 竹林、松、花田、大樹地標 | 依遮罩自動散布；大樹用 elder-tree-esg 移植的成樹作地標 |

## 道路要像方向圖那樣

方向圖和你給的河岸三視圖，路都是**土面與碎石混合、邊緣有石塊和草叢、靠水的一側有石砌護岸**。做法：

1. 路面：地形材質（泥土＋碎石兩層），依路線資料自動塗上，邊緣加雜訊（新手村已經這樣做）。
2. 路緣：沿路線自動擺石塊和草叢，用 B 的 31 件 `EnvironmentTransitionKit`（RoadEdge／Riverbank 系列）和散布件。
3. 臨水段：用河岸三視圖那種石砌護岸模組，接在路和水之間。
4. 主幹道和廣場：石板路模組（模組件，不是地形）。

## 進屋：用獨立室內空間

建議用**獨立室內場景**，你的判斷是對的：
- 室外房屋只需要好看的外殼，室內另外做，比例可以放寬（室內常做得比外觀大一點，走起來才不擠）。
- 手機上兩個小場景比一個「外殼加室內」的大場景輕。
- 這和丹房已經用的做法一樣：門口按 F，載入另一個場景，再回到門口。
- 「動畫」做法：門口按 F → 推門動畫（門板旋轉）＋畫面淡出 → 載入室內 → 淡入。第一個要做的是新手村借住處：床、箱、桌，B 已交付 DiscipleBed、StorageChest。

## 瀏覽器版（PWA）

有兩條路，建議走第一條：

| 做法 | 好處 | 代價 |
|---|---|---|
| **A. 同一個 Unity 遊戲建置成 WebGL，包成 PWA**（建議） | 只有一套遊戲；新手村、玩法、地形全部共用 | 要在 Unity Hub 加裝「WebGL Build Support」（z1nnz 操作）；URP 在 WebGL 上要降畫質；手機瀏覽器效能要實測 |
| B. 繼續擴充 three.js 的 `tools/qingxi-trial` | 載入快、手機友善 | 等於再做一套遊戲，玩法要重寫兩次 |

## 分階段

| 階段 | 玩家看得到的成果 | 完成條件 |
|---|---|---|
| 1. 新手村可玩版（PR #49） | 地形、A／B／C 玩法、坊市、藥田、採集、木樁 | 已完成，建置版 smoke 22 項通過；待合併 |
| 2. 瀏覽器版 | 用手機或電腦瀏覽器開新手村 | 裝好 WebGL 模組 → WebGL 建置 → PWA 外殼 → 手機實測 |
| 3. 溪與進屋 | 西側溪流（河岸、踏板、小瀑布）；借住處可進入 | 溪的地形與水面、室內場景、門的轉場 |
| 4. 璃月感的第一張「明信片」 | 從村口看出去：霧、遠山、竹林、古樹地標 | 後處理、遠景石峰、植被密度、古樹進場且手機幀數可接受 |
| 5. A 河谷完整區 | 方向圖 A 的一小片：村、田、溪、橋、崖 | 每區都有玩法、碰撞、LOD、手機效能 |
| 6. B／C／D 與主圖 | 垂直山城、裂靈湖、古林，依主圖連接 | 依同一套規則一區一區擴，最後才是大世界 |

## 古樹

elder-tree-esg 的成樹已完整移植（`docs/qingxi-world-v11.md`）。它很適合當方向圖 D「古林」和村子中心的地標，但目前 GLB 約 16 MB，進遊戲前要做 LOD 和葉片合批，否則手機會吃不消。

## 需要 z1nnz 決定或提供的

1. 在 Unity Hub 加裝 WebGL Build Support（2023+ 版本在 Installs → 齒輪 → Add modules）。
2. 確認「先做瀏覽器版」還是「先做溪與進屋」。
3. 新的三視圖（例如鞦韆平台、河岸）請存成檔案放到 `art/incoming/`，聊天室裡的圖片 Claude Code 無法存成檔案。
