## 可玩的簡單玩法：物品去向

在 `tools/qingxi-return-c/` 建一個獨立、可直接開啟的 PWA 展示，使用自己的簡易畫面，不改 z1nnz／Codex 的角色、主 HUD 或登入。

1. 預設展示三個清楚標名的採集樣本；玩家能點選樣本看來源及用途，並可將其放到保存、留待煉製、委託展示三處。
2. 手札依玩家動作記錄「從哪裡帶來、選了哪個去向」，能取消一次誤選。三種去向都可選，不強迫完成固定清單。
3. 點桌子、匣子、布包時模型或其標示有明顯回饋；錯誤操作給一句容易懂的提示。鍵盤、滑鼠與手機橫向觸控都能操作。
4. 任何數字都只在本機演示。不可寫正式背包、靈石、宗門貢獻或委託完成紀錄；未來正式接線僅輸出需要服務端驗證的意圖與 UI 狀態表。
