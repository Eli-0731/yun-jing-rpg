# 青溪新手自由活動 v1

製作：z1nnz 指導／Codex 接線。這是 Unity 統一場景的**本機試玩**，不寫入正式背包、修為、靈石或帳本。

創角後的前十個現實日仍可自由遊玩；十日是測資與宗門選比出現的時間點，並非每天的強制任務期限。新手可按興趣在同一地區選擇以下活動，無須依序完成：

| 活動 | 目前可玩操作 | 本機結果 |
|---|---|---|
| 山道觀察 | 靠近六處既有線索點按 F | 每處只記錄一次，可帶回聽風台參悟 |
| 引氣訣練習 | 聽風台入口按 F | 初次與每個新線索各能得到一次本機領悟 |
| 採藥 | 六處靈草點按 F | 增加靈草，單株 60 秒再生，不可連按重複領 |
| 簡單煉製 | 坊市入口按 E | 用兩株靈草換一份本機調息散 |
| 調息 | 聽風台入口按 E | 消耗一份調息散，增加本機領悟 |
| 山兔遭遇 | 靠近現有山兔按 F | 計入本機山兔收穫；原兔子 90 秒重生 |
| 坊市交換 | 坊市入口按 F | 消耗當前靈草／山兔，取得當次試玩練習靈石 |

HUD 同時顯示附近 F／E 操作、收穫、線索、調息散、領悟與上次結果。玩家可以只走路、觀察或練氣，不被迫採獵與出售。現在的「練氣」是參悟的場景原型，沒有正式境界提升、功法適性或服務端時間結算。

## 下一段可玩的內容

1. 把採草、煉製與交換改為服務端權威結算，接背包、重登及距離驗證；本機數字不可直接同步成正式資產。
2. 讓山兔使用既有骨架與動畫，加一招有距離、冷卻與命中判定的基礎攻擊，再接服務端死亡收據。
3. 在新手住處加入床、箱與小靈田，讓喜歡經營的人可安排休息、收納和種植。
4. 為凡骨加入體修起步訓練，普通修士保留引氣訣；玩家不必先知道十日後的精確測資。
5. 增加告示、商販對話與溪畔修復等可選事件，讓小鎮的行動彼此產生結果。

## 驗證邊界

固定 Unity `6000.0.82f1` 已通過場景生成、Windows 建置及 Editor smoke：靈草再生與防重複、山兔防重複、線索唯一記錄、線索解鎖練習、兩株靈草煉製與調息散消耗、空手交換限制。人工全路線、手機操作及正式服務端存檔尚未驗證。
