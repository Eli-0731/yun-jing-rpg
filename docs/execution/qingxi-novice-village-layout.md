## 驗證

- 版面資料測試 7／7：道路節點、平台不重疊、相鄰平台之間的坡度、每件擺件都在平台上、採集點不在路或平台上。
- 接地驗收：失敗 0。83 件擺放模型都接地，路上沒有草，13 段路線全部走得到。林地入口要繞過避雨龕（NavMesh 9.2 m）。
- 建置版 smoke 16／16，含「採後換成採後模型」與「坊市攤位出現交易提示」。
