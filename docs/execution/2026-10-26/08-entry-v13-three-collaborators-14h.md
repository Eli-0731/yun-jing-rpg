## A｜玩家角色 14 小時

輸入：[原創角色 AI 三視圖](../../../art/references/qingxi-novice-cultivator-v1/three-view.png)及[目前低精度原型](../../../art/previews/qingxi-entry-assets-v13/novice-front.png)。參照使用者提供的仙俠短劇影像只抽取「清楚的臉部、層次長髮、深淺衣料、玉飾與有重量的動作」方向，不能描摹其演員臉或照搬服裝。暫定女性初始角色，身高約 1.75 m；讓未來能換膚色、髮型與服裝，不把資質／付費綁到模型上。

| 時數 | 必交結果 |
|---:|---|
| 2 | 量定三視圖比例、遊戲鏡頭下的輪廓與角色軸向；寫明原型哪些地方要保留、哪些必須重做。 |
| 4 | 重做可形變的身體／頭／手、衣襬和袖口拓撲；正、側、背近景圖均清楚，臉不再是簡單球體。髮絲採分層髮束，不靠高面數堆造型。 |
| 3 | 完成遊戲用骨架及權重，測肩、肘、膝、裙襬轉動；輸出 A pose 與極限測姿圖片。 |
| 3 | `idle` 和 `walk` 兩段循環，腳掌不滑動，髮與衣有受控的次級動勢；另交 10 秒轉身／移動錄影。 |
| 2 | 產生 LOD0／LOD1、GLB 與可編輯母稿，回匯檢查；跑 Blender QA，列三角面、材質數、骨數、尚存警告。 |

驗收：完成的是**可接遊戲控制器的角色資產**；PWA 或 Unity 尚未實際操控之前，PR 不寫「可玩角色」。廣告／AI 漫劇級臉部仍需要完整材質、表情、髮絲、光照與真機比較，不能只用一張美術渲染宣稱達標。

## B｜道路與河岸 14 小時

輸入：[道路三視圖](../../../art/references/qingxi-winding-road-v1/three-view.png)、[河岸三視圖](../../../art/references/qingxi-riverbank-v1/three-view.png)與 v12 12 m 道路。v12 母稿、v13 組裝圖保持不動。先交平面標註：土路可走淨寬 2.4 m、石與草的密度及大小至少三層，河岸沿曲線有高低變化。

| 時數 | 必交結果 |
|---:|---|
| 2 | 固定與 v12 的接縫規格，保存參考對照與尺寸；若有新增石頭或植物種類，先做其 AI 三視圖。 |
| 4 | 兩段可拼接 S 型路緣與一段橋頭過渡；剖面不呈矩形貼片、沒有露空或硬折。 |
| 3 | 至少三類岩石和兩類植被，利用實例形成碎石、半埋石、苔面、稀疏草到密集花草的梯度；提供可獨立擺放 GLB。 |
| 3 | 河岸石階與水邊淺灘銜接，從 1.7 m 角色眼高和俯視角各拍一張，指出離三視圖尚差在哪裡。 |

## 核心組與交付規則

z1nnz＋Codex 保留新手村組裝、樹伴原樹、模型來源登記、QA 與 PR 審查。三人 PR 應各附「修改檔案／來源／三視圖連結／正側俯視或操作圖／測試結果／未完成」，不要直接改 `main`。整合只在檢查通過後進行；衝突由核心組在獨立分支修，不把別人的提交改成 z1nnz 原作。GitHub 合併操作可由 z1nnz 帳號執行，但 Git 提交作者紀錄須保留實際製作者。
