# 青溪新手入口 v14 與瀏覽器試玩

## 與大世界的關係

`art/source/qingxi-world-art-directed-v3.blend` 和 `art/previews/qingxi-world-v3/` 保存較大的青溪世界視覺規劃；村莊、河道、橋與遠處山門仍在。v14 只精修其中的**村口與客舍周邊**，瀏覽器試玩再從這個入口取一小段可走場地。v14 的本地場景座標不等於完整世界的最終座標；接入 Unity 大世界時要重新核對比例、道路銜接、遮擋及碰撞。

今天的分工是核心組完成入口、角色操作與鏡頭的試玩主檔；A 做演武區、B 做溪畔採集路、C 做村內告示小事件。三份獨立交付通過檢查後由核心組接進入口，避免同時修改同一場景。

## 如何啟動

在專案根目錄執行：

```powershell
cd tools/qingxi-trial
npm ci
npm start
```

在這部電腦的瀏覽器開啟 `http://127.0.0.1:4173/tools/qingxi-trial/`。伺服器只綁定 loopback，不是公開多人服務。

## 這次能試什麼

- 第三人稱鏡頭：WASD／方向鍵或畫面方向鍵移動；滑鼠右鍵拖曳或手機畫面右側滑動轉視角。靠近村門時鏡頭會縮到遮擋物前方。
- 新手村口使用現有道路、牌樓、客舍、原樹、聽風台和山兔 GLB；v14 Blender 組裝有入口總覽、到達視角及聽風台視角三張圖。
- 可自由選擇到村門試練功、找一株靈草、追山兔並出招，之後回客舍商販交談；不用依固定順序或每天登入。
- 互動提示按距離出現；模型載入失敗時仍顯示基本場地，並在畫面回報失敗件數。

## 資料界線與目前品質

這是**本機 PWA 操作樣片**：練功、靈草與山兔記錄只在當前網頁記憶體，重整便重置，不會寫入遊戲角色、背包、靈石或正式伺服器。角色模型沒有完整動畫；出招只做距離與冷卻的試玩判定，沒有服務端命中與死亡收據。山兔會簡單逃跑，未接正式 AI。房屋與河道採簡化碰撞。不能把此頁當作多人、正式手機效能或完成的新手十日內容。

聽風台參照先前保存的原創 AI 三視圖進行局部精修；第三方下載場景及人物沒有匯入或提交。Blender 程序石材尚未烘焙為 GLB 貼圖，故瀏覽器的石材較原檔平。

## 驗證

- Blender 5.2.2 背景重新生成聽風台和 v14 入口場景，三張 v14 圖已檢視。
