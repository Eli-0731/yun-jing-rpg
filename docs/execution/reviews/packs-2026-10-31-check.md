## 事實核對與立即要修的接口

1. **房間**：B §3 的 7×5×3.2 m、床 (−2.75,1.0)、箱 (2.6,1.9)、蒲團 (1.2,−0.2) 與 Builder 22、35–37 行一致。B §3 的前後門 1.2×2.2 m 與 Builder 79–91 行一致，**但與 C2 室內套件 1.7×2.4 m 衝突**（`C2-interior-kit.md` 4、87 行），且 C2 目前是工作單，尚非已驗收的引擎尺寸。先由核心組決定最終門洞，然後調整 Builder 或 C2，再讓 B 定門簾；勿叫 B 自行猜。
2. **後院**：A §3 的 12×10 m、z=2.5–12.5、圍籬高 1.1 m、小徑寬 1.1 m，與 Builder 122–145 行一致。田格 (±2.8,6.7)、練功 (0,10.8)、石燈 (−5.2,12)、右角 (5,11.5)、藥架 (5.4,4) 與 Builder 185–190 行一致；田床/木樁現有擺放見 Builder 156、178 行。`TY_Fence`、`TY10` 只在文字與灰盒中，未見於 Slots 表，位置接口需補。
3. **屋內格位**：B §3 的 `TI_Shelf`、`TI_Desk`、`TI_Furnace`、雙燈、`TI_Screen`、`TI_Rug` 均見 Builder 191–197 行。`TI_Shelf` 工作單以 0.45×1.8×2.0 記未旋轉尺寸，Builder 用轉 −90° 後的世界足跡 1.8×0.45×2.0；需在模型 metadata 寫明局部軸和旋轉，避免誤判。`TI_Curtain_F/B` 未見 Builder Slots，須補。
4. **A2/A3 平台**：C §3 指定 A2 `a2-start`、`a2-tea`、`a2-shrine`、`a2-view`，均在 `A2.json` 108、117、126、135 行的 `pads`；A3 `a3-mill`、`a3-bamboo`、`a3-fish`、`a3-west` 均在 `A3.json` 101、110、119、128 行的 `pads`。A3 另有同名 `a3-west` 路線節點（40 行），`positions.json` 應標 `pad` 類別，不能只寫 id。
5. **時數**：`00-overview.md` 3、35–41 行為各 28 小時、三人 84 小時；A §5/§10 為 6+22=28 與 14+14=28；B 為 12+16=28 與 14+14=28；C 為 10+18=28 與 14+14=28。這是排程估算，不是完成證據。
6. **收藏與燈**：B §5 8 格每格至少 0.36×0.31×0.36 m，C §5 每件最多 0.35×0.30×0.35 m，數值上相容；需實際檢查配件、外接盒及 socket。A §5 的材質 0–4 五段與 §6 的脈息換算一致到狀態數量，但**沒有量化映射**，核心組需定義同一來源資料供本機展示及正式版。
