## 規則

- 色票、字級、按鍵尺寸照設計方向文件第 2、3 節。按鍵大小要符合：主鍵約為畫面高度的 14%，其他按鍵約 10%。
- 介面上的中文要是正確的繁體中文。生圖若產生錯字或亂碼，在說明裡標出，**不要假裝正確**。
- 不要模仿任何現有遊戲的介面元素（原神、鳴潮等的框、圖示、標誌都不行）。可以學它們的「排列邏輯」，但不能抄外觀。
- 不要大面積發光，不要整片金框，不要純白扁平圖示。
- 若生圖工具做不到某一項（例如精確文字），照實寫在說明裡。

## 交付說明

在輸出資料夾寫 `README.md`，內容：

- 每張圖的檔名與一句說明；
- 每一套你認為的優點與缺點（各 2–3 點）；
- 生圖時的提示詞（每張一段，方便之後重生）；
- 不符合規則或做不到的地方。
