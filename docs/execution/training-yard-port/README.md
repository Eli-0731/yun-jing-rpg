# 公共演武區：把 Johnnnny0823 的網頁版演出搬進遊戲（2026-10-29）

## 為什麼之前「不見了」

Johnnnny0823 做的公共演武區（`tools/training-yard-demo/`）是一個**獨立的 three.js 網頁**，只有在他的資料夾執行 `npm start` 時才存在，從來不是遊戲 PWA 的一部分。

新手村整合進 Unity 時，只搬了他的**模型**（木樁、演武棚等）和**計分規則**（`practice.mjs` 的 C# 版）。演出部分當時只用灰色方框代替，包括：
- 鏡頭推近；
- 呼吸環；
- 木臂動畫；
- 光效與音效。

所以在遊戲裡玩起來，他做得最好的地方都不見了。
