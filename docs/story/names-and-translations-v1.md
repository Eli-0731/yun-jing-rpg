# 《承天》名字與翻譯表 v1

> 2026-10-30，Claude Code 整理。z1nnz：「名字翻成英文、日文、韓文……會不會奇怪？如果翻譯後還能是伏筆更好。」
>
> 這份檢查目前世界裡所有的名字在五種語言裡的讀法：
> - 中文：繁體，本身的意思；
> - 英文：拼音，或特別的譯名；
> - 日文：漢字音讀；
> - 韓文：漢字音；
> - 越南文：漢越音。
>
> 結果分三種：
> - ✅ 沒問題；
> - ⚠️ 有點奇怪，用片假名或拼音可以避開；
> - ❌ 建議改名；
> - ✨ 剛好多一層伏筆，建議保留並刻意使用。
>
> 讀音是依各語言的漢字音整理的，**正式上線前請各語言的母語者再確認一次**。

---

## 一、預設做法（避免撞音）

- **日文**：專有名詞預設用**中文發音的片假名**（像原神日文版的璃月叫リーユェ），不用日文漢字音讀。這樣「不周」不會被讀成「腐臭」、「青溪」不會被讀成「整形」。
- **英文**：預設用**拼音**（Buzhou、Qingxi）。少數有伏筆的名字給特別的英文譯名。
- **韓文**：預設用韓文漢字音（韓國玩家習慣這樣讀中國風作品），撞到的再處理。
- **例外**：下表標 ✨ 的名字，刻意用該語言的漢字音或特別譯名，因為那一層讀音剛好是伏筆。

### 2026-10-30 定案
- 雲篆派改名**星篆閣**（原因：日文「うんてん」、韓文「운전」都是開車）。
- **不周、青溪、柳知微、百毒谷不改名**，只改讀法：
  - 不周：日文用片假名ブージョウ；
  - 青溪：日文用片假名チンシー；
  - 柳知微：日文用片假名リウ・ジーウェイ；
  - 百毒谷：英文譯成 the Hundred Poisons Valley。
  這幾個名字的中文意思都很重要（不周是世界觀的核心、青溪已在遊戲裡、知微是見微知著），問題只在讀法。

## 六、規則（寫進製作規範的取名三層法）

1. 每個新名字都要檢查**中、英、日、韓、越**五種讀音，不能撞到奇怪或冒犯的意思。
2. 預設：日文用中文發音的片假名、英文用拼音，避免撞音。
3. 能多藏一層的，就給它特別的譯名或刻意用漢字音（表中的 ✨）。
4. 正式上線前，每種語言請母語者再確認。
