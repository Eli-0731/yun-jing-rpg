## 一、什麼是意難平

意難平不是「很悲傷」，而是**讀者替角色不甘心**：差一點就好了，卻永遠差那一點。

### 參考的作品

| 作品 | 意難平在哪裡 |
|---|---|
| 長相思・相柳 | 愛了一輩子沒說出口，為大義赴死，還把自己留在鏡子裡的最後影像抹掉，不讓她記得、不讓她難過 |
| 周生如故・周生辰與時宜 | 師徒之間的愛不能說；他死前說「若有來世」，她用一生去等 |
| 二哈和他的白貓師尊・楚晚寧 | 徒弟恨了師尊一輩子；師尊早就把半個魂給了他。徒弟在師尊死後才知道 |
| 魔道祖師・魏無羨與江澄 | 魏無羨偷偷把金丹給了江澄，江澄恨了他十三年才知道 |
| 劍來・齊靜春 | 一個先生替整座小鎮扛下天劫，笑著走了，只留下一點點念想給那個少年 |
| 天官賜福・花城 | 八百年，一直有一個人記得、一直在等 |
| 原神・芙寧娜 | 五百年對所有人演戲，獨自守著不能說的秘密；真相揭開，她只是一個很累的女孩 |
| 原神・大慈樹王 | 為了救世界，把自己從所有人的記憶裡抹掉。世界得救了，卻沒有人記得她 |
| 原神・溫迪與無名少年 | 風神用的樣子，是一個死去的、想看見天空的少年 |
| 原神・哲平 | 一個很普通、很想幫忙的朋友，用了錯的方法，死了 |
| 星穹鐵道・翁法羅斯（白厄、昔漣） | 世界輪迴了幾千萬次，每一次都失敗；有一個人記得每一次，一次次重新愛上同一個人 |
| 星穹鐵道・遐蝶 | 碰到誰誰就會死，所以她從不碰任何人，卻是最溫柔的那一個 |
| 星穹鐵道・緹寶 | 一句「明天見」，沒有明天 |
| 星穹鐵道・流螢 | 約好在夢裡重逢 |

### 歸納：意難平的九種手法

1. **差一點**：差一步就趕上了、差一句就說出口了。
2. **沒說出口**：愛或真相到最後都沒說。
3. **被恨著的守護者**：保護你的人被你恨著，你很久以後才知道。
4. **把自己抹掉**：犧牲了，還讓被救的人不記得他。
5. **約好的明天沒有來**：「明天見」「若有來世」。
6. **求而不得，卻仍然溫柔**：碰不得、說不得，還是對所有人好。
7. **只有一個人記得**：世界忘了，只有一個人一直記得。
8. **遲了一步的真相**：人走了，你才知道。
9. **結局不能全部圓滿**：大局得救了，但一定有一件事永遠回不來。讀者是為那一件事意難平。

### 原神和星穹鐵道怎麼把它放進一整個大故事

- **每一國的中心都是一個「神」**，獨自扛著一個幾百年的秘密（芙寧娜、雷電將軍、納西妲、白厄）。玩家到了那一國，故事就是揭開這個人。
- **神旁邊一定有凡人**（哲平、緹寶）。凡人的死比神的犧牲更痛，因為他們本來可以只是平凡地活著。
- **秘密跨很多個版本才揭開**，前面的每個小細節之後都換了意思。

我們七位被困住的祖師，就是那個「神」。v3 在每一國都補上一個**凡人**，也一定留下**一件回不來的事**。

## 二、三百年前（v3）

**兩兄弟**
- 三百年前，青溪出了一個天才：問劍山祖師。他是七位宗主裡唯一出身邊陲的人。
- 他有一個十五歲的弟弟。
- 臨行前，哥哥和弟弟在溪邊說好：「等我回來，我們一起把溪修好。」

**那一劍**（v3.2 改寫，取代「投票」，見第八節）
- 斷脈之夜，靈脈在地底崩裂，天開始往下塌。七人的師父跳進靈脈，用身體撐住天。
- 要救天下，只剩一個辦法：在青溪斬斷靈脈，讓邊陲的那一段帶著重量沉下去。可是師父就在那段靈脈裡。
- 師父對最強的那個弟子喊：「斬。」
- 他斬了。一劍之間，師父和他的家鄉一起沉下去。
- 那一夜青溪的溪停了；遠處山城放起煙火，人們在歡呼天保住了。

**盟約與茶亭**
- 七位宗主在盟約上各蓋一印，答應回來補好邊陲。弟弟作為青溪的代表，帶著盟約回村。
- 哥哥沒有回家。他覺得自己不配再見家鄉，走進八雲最深的岩洞，把自己封了起來。
- 弟弟在官道上開了間茶亭，就是後來的**茶亭老人**。他每天看著路的那一頭，漆盒裡是那張盟約。
- 盟約上的印在他身上起作用：約定沒有兌現，他就走不了。

**伏筆：玩家早就替哥哥做了一半**
- 新手篇裡，玩家修好了青溪的溪。茶亭老人聽說以後，只說了一句：「水回來了啊。可惜他沒看見。」
- 玩家要到很久以後才懂，這句話裡的「他」是誰。

## 三、青溪的人（玩家天天見到的凡人）

### 柳知微：被誤會的師父（被恨著的守護者、把自己抹掉）
- 她是青溪負責教新人法術、主持測資的師父，出身太玄道院，就是那個篩人的宗門。
- 前期的樣子：她總是很累、夜裡出門、對測資很嚴。玩家會看到她把一個身上浮出缺月的新人帶走，從此那個人消失了。很多玩家會討厭她。
- 真相（中期，雷音一國揭開）：
  - 每一個新人身上都有一點點缺月，玩家也有；
  - 她在測資時，把每一個新人的缺月悄悄移到自己身上，讓大陣看不見；
  - 那個被她「帶走」的新人，缺月太深藏不住，她把人送去了九夜，玄冥宗收留了他；
  - 她身上的缺月越積越多，總有一天大陣會看見她。
- 結局：大陣在中期篩掉了她，玩家趕到時只剩她的法袍。
  - 她留給玩家的是一張測資單，上面寫著玩家的名字，旁邊寫著：「資質：可。」
  - 玩家這才知道，自己能進宗門、能走到這裡，是因為她替你藏了缺月。
- 學的是：楚晚寧、魏無羨的金丹、相柳。我們自己的：她替**每一個**玩家都做過，所以這是全服玩家共同的意難平。

### 霽弦：空屋的前房客（只有一個人記得）
- 他在門檻下留了一封信：「待我測過資質，便回來。」
- 他的缺月太深，柳知微藏不住，他被止步，出走了。
- 中期：他成了拆陣的邊陲人，玩家以為他是敵人。
- 真相：他是現在獨自承天的人。拆陣，是想讓天的重量平均分給所有人，不再由一個人扛。
- 結局：全服回應，天撐住了，霽弦活了下來，但缺月吃掉了他在青溪的記憶。
  - 他回到那間空屋前，看著田裡長得很好的作物（就是玩家種的），說：「我好像……在這裡住過。」
  - 一直住在這裡的玩家可以回一句：「歡迎回來。」他不知道為什麼，覺得鼻子很酸。
- 學的是：大慈樹王（世界記得，他不記得）、白厄。

### 阿穗和她的靈獸（沒說出口）
- 青溪有一個小女孩叫阿穗，身邊總跟著一隻不太像狗的靈獸，從不離開她。
- 在金穗一國，玩家知道了：那隻靈獸是阿穗的母親。
  - 當年為了救病重的女兒，她去了金穗，在世界樹下用自己換了一株藥；
  - 代價是變成獸，再也不能說話。
- 玩家可以選擇要不要告訴阿穗。
  - 不說：阿穗長大，那隻獸慢慢老去，她到最後都只當牠是一隻很好的狗；
  - 說了：阿穗抱著牠哭，那天晚上牠就回到世界樹下去了（約定就是「被認出來就要回去」）。
  - 兩個選擇都對，也都會痛。
- 學的是：溫迪的無名少年、遐蝶；我們自己的：把這個選擇交給玩家。

## 五、結局：萬木春，與那一件永遠回不來的事

1. **求救**：天缺最後一次裂開，霽弦撐不住，第一次開口求救。
2. **回應**：全服玩家一起回應（大事件）。每個人種過的田、修過的水路、點過的燈，都化成撐住天的力量。
   - 每個玩家身上都浮出一彎淡淡的缺月。原來柳知微替你藏起來的，就是這個。
   - 這一刻，所有人都想起她。
3. **燈**：每個人可以匿名把一件東西點成一盞燈，送給一個還沒走到這裡的陌生人。
4. **歸來**：
   - 六位祖師走回青溪，盟約上的六個印亮起；
   - 第七位是問劍山祖師，他最後一個到。
5. **茶亭**：
   - 茶亭老人眼睛已經看不清，問他：「客人從哪裡來？」
   - 哥哥知道，只要約定兌現，弟弟就會走。他在茶亭坐了很久，最後說：「從家裡來。溪水修好了。」
   - 老人笑了：「我知道，是那些孩子修的。」第七個印亮起，茶亭裡只剩一杯還溫著的茶。
6. **春天**：溪水在流，邊陲的土長出新芽。
   - 霽弦站在空屋前，不記得了；
   - 柳知微的法袍掛在測資台旁，沒有人收走。

**回不來的事**：兩兄弟只說了一句話；柳知微沒有回來；霽弦不記得青溪。大局得救了，這三件事永遠留在玩家心裡。

## 七、三種最戳人的感情：愛人、群像、家人

z1nnz：「愛人的故事、群像、家人，這種最戳觀眾感情。」v3 原本幾乎全是家人；這一節補上愛人和群像，讓三種感情都有一條主線。

### 愛人：沈岳與柳知微（沒說出口）
- 沈岳是青溪的體修師父，柳知微是法修師父。兩個人共事十幾年，村裡人都看得出來，他們自己從來沒說破。
- 沈岳是唯一知道柳知微在藏缺月的人。他勸過、吵過，攔不住，只好每天晚上在她屋外點一盞燈，等她從測資台回來。這就是前期玩家看到的「第三盞燈」。
- 柳知微被大陣篩掉那天，沈岳趕到時只剩她的法袍。
  - 他把法袍掛在測資台旁，誰都不准收；
  - 那盞燈，他之後每晚照樣點。
- 很後面，玩家在她的遺物裡找到一張沒交出去的測資單，名字寫的是沈岳，旁邊只有一個字：「待。」
  - 沒有人知道她要他等什麼。
  - 結局全服浮出缺月、所有人想起她的那一刻，沈岳身上沒有浮出缺月。她連他的那一份也藏走了。
- 學的是：周生如故（不能說的愛）、相柳（把自己抹掉）。

### 群像：青溪同屆的五個人（一起出發，各奔東西）
- 新手篇裡，玩家身邊有五個同時來到青溪的 NPC 新人。他們個性不同，各有一個小小的夢想：
  - 想當劍仙的少年；
  - 想替家裡賺藥錢的女孩；
  - 怕死卻總是第一個衝出去的胖子；
  - 不愛說話、只會做機關的孩子；
  - 一個總是笑著、其實身上有缺月的女孩。
- 他們和玩家一起修溪、一起被茶亭老人請喝茶、一起在測資前一晚坐在溪邊說「以後無論進了哪個宗門，都要回來喝茶」。
- 測資以後，五個人進了不同的宗門，散到七國。
  - 玩家在不同的國家會一個一個遇到他們；
  - 有人成了那一國的英雄，有人走上了不同的立場，有人死在途中（學哲平、緹寶：最平凡的人，死得最讓人不甘心）。
- 結局後，活下來的人回到茶亭喝茶，桌上多擺了一副碗筷，給沒回來的那個人。
- 這條線也呼應三百年前：當年也有一群人說好要回來，玩家這一代，終於有人真的回來了。
- 學的是：翁法羅斯的黃金裔、鬼滅的柱、幻想水滸傳 II（同伴走上不同立場）。不學竹業篇：他們不是天才團，沒有一起去闖禁地，只是一起長大的普通人。

### 三種感情的分配
- **愛人**：放在玩家每天見得到的地方（青溪），慢慢累積，到中期才痛。
- **群像**：貫穿全程，從新手篇到結局，是玩家自己的「同伴」。
- **家人**：每一國一段，讓每一國都有一個家的故事。

| 狐妖小紅娘・竹業篇 | 一代同齡的年輕人，曾經是最好的朋友，後來走散、各自背著傷活下去；後代追查才知道上一代的事 |
| 病樹枝頭又逢春（我死後成了反派白月光） | 同門師兄弟姊妹各有各的結局，女主死後，每個人用自己的方式記得她 |
| 鬼滅之刃、暗殺教室 | 每個人都有自己的一集，都是自己的主角 |
| 最好的我們、忽而今夏 | 同桌、同學，十年以後重聚，有人已經不在 |

### 三百年前也是一群人（像竹業篇，但不抄）
- 七位宗主在當上宗主以前，是山城學宮裡同一屆的七個年輕人，最好的朋友。問劍山祖師（青溪出身）也是其中之一。
- 他們曾經在學宮後山的溪邊說好：「以後誰當上宗主，都要讓天下一起好。」
- 斷脈之夜，友情在一劍之間裂開（v3.2，取代「投票」）：
  - 七人分守靈脈的七個方向，師父在中間用身體撐著天；
  - 只有斬斷青溪那一段才能救天下，師父喊「斬」；
  - 六個人有的喊「不要」，有的哭著喊「斬」，只有最強的那個人握著劍。**因為他最強，所以只有他斬得斷**（學五條悟：最強的人，最孤獨的選擇）；
  - 他斬了。守在北邊的兩個人親眼看見師父最後的臉；
  - 那一夜山城放煙火，所有人都在歡呼（學懷玉・玉折：眾人在為一個人的死鼓掌）。七個人站在煙火底下，沒有一個人笑；
  - 之後他們互相怪罪：你為什麼斬，你為什麼不攔，你為什麼喊了「斬」。七人各自去贖罪、去兌現約定，各自困在七國（第四節）。
- **和竹業篇一樣的地方**：一代同齡的朋友，走散了，後代追查上一代的事。
- **和竹業篇不一樣的地方**：
  - 他們沒有一起去闖禁地；拆散他們的，是師父親口要他們斬下的一劍；
  - 沒有「一個殘了、一個失了劍心」，七個人都活著，只是困在各自贖罪的路上；
  - 修補這段友情的，是下一代：玩家和青溪同屆的五個人。
- **兩代群像互相照應**：
  - 三百年前七個人在學宮溪邊許約，現在五個人在青溪溪邊許約；
  - 上一代沒做到「回來」，這一代有人回來了，也有人沒有。

### 小滿：小草王式的接班人
- 青溪同屆五個人裡，那個總是笑、身上有缺月的女孩，叫**小滿**。
  - 小滿是二十四節氣之一，意思是「將滿未滿」，像一彎缺月。
- 測資時，她的缺月藏不住，太玄道院把她帶走，「保護」在山城高塔裡，大家都說她是沒用的病秧子。
- 真相（中後期）：
  - 戊辰年那次天裂，上一位獨自承天的人（一位被所有人遺忘的女子）把自己從世界的記憶裡抹掉了，只留下一點點東西：一個嬰兒身上的缺月。那個嬰兒就是小滿。
  - 太玄道院關住她，不是怕她，是怕她長大以後也要去承天。
- 結局：小滿走出高塔，和霽弦一起扛天。她說：「我不是沒用的人，我是她留下來的人。」
- 學的是：大慈樹王與納西妲。不一樣的地方：她不是神，是玩家同屆的朋友。

### 七面：芙寧娜式的演員
- 七位宗主困在七國以後，山城不能沒有宗主。每年的天祭，七位宗主都會「出現」在高台上，戴著面具，威嚴、冷漠，從不回應邊陲的請求。
- 邊陲的人因此相信：宗主們明明還在，只是不肯回來。霽弦會恨，就是從這裡開始。
- 真相：高台上那七個人，三百年來一直是**同一個人**。
  - 她是七位宗主當年在學宮的小師妹，比他們小十歲，沒能進議事堂投票；
  - 她一個人輪流戴七張面具，演了三百年，不能讓大陣、宗門和天下知道宗主們都不在了，否則天下會亂；
  - 她不能求救，不能哭，因為面具不能哭。
- 揭開的那一刻：玩家在天祭的後台看見她一個人坐著，七張面具擺在桌上，她在給自己唱一首小時候師兄們哄她的歌。
- 結局：七位宗主回來時，第一個走到她面前的是問劍山祖師。他說：「小師妹，辛苦了。別哭。」她終於哭出來。
- 學的是：芙寧娜「水龍水龍別哭了」。不一樣的地方：她演的是七個人，等的是她的師兄們。

### 用在《承天》的地方
- **斷脈之夜**（取代投票）：學銀魂的「老師要你斬他」、懷玉玉折的「眾人歡呼」、五條悟的「最強的人沒得選」。三個合起來，變成：師父在靈脈裡喊「斬」，最強的弟子斬斷師父和自己的家鄉，山城在放煙火。
