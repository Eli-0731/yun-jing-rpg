# 《承天》世界觀總綱 v1

> **遊戲名稱：《承天》**（z1nnz 2026-10-29 定案）。「雲境」改為**世界的名字**：故事發生在一片叫雲境的雲上山河。
> 名字就是主線：天裂了，**誰在承天**？先是代天大陣，背後是七柱宗門，最後真相是活在上面的每一個人。程式與資料夾裡的 `YunJing` 只是內部代號，不改。

> 2026-10-29，Claude Code 依 z1nnz 的方向撰寫。原話重點：
> - 世界被天道損毀過，或者表面安好、底下暗潮洶湧；
> - 玩家做的事隱隱約約在幫這個世界，一環扣一環，到處埋伏筆；
> - 各宗門都藏著東西；看起來壞的宗門其實在為世界好，看起來好的也不一定是好人，**沒有真正的壞人**；
> - 讓玩家最後恍然大悟：「原來我們做的這些事，是為了這個世界」。
>
> 這份是**長期骨架**：真相分層，越後面揭露得越深。新手十天只碰到最外面兩層。
> 細的章節在 [新手大世界主線大綱](main-story-outline-v1.md)。之後的宗門篇、州域篇都要從這份長出來，不可以互相矛盾。

## 一、一句話

**雲境是一片浮在雲海上的山河。很久以前天裂了，先人用一座看不見的大陣代替天道，把世界撐住。陣撐了千年，開始撐不住了。真正能讓世界活下去的，是活在上面的每一個人日常做的小事。**

兩個方向都要：
- **天道損毀**：天在上古就裂了（「天缺」）。
- **暗潮洶湧**：今天的世界看起來很安穩，宗門林立、村落太平，但靈脈正在一處一處地裂開。

## 二、世界的樣子（玩家看得到的）

- **雲海**：雲境是好幾塊大陸浮在無邊的雲海上。地圖邊緣不是牆，而是**懸崖下的雲海**。這同時解決了「世界邊界」的問題：新手大世界的外緣就是雲海斷崖。
- **靈脈**：地底下像樹根一樣的靈氣河流，把一塊塊陸地「攏」在一起。靈脈強的地方草木茂盛、溪水清甜；靈脈弱的地方土地乾裂、溪流停住。
- **天道**：人人都說「天道」，以為是天地本身的規律。天劫、資質、境界的天花板，都被認為是天道定的。
- **宗門很多**，數量不設上限（z1nnz 2026-10-29：宗門會有很多個）。分三種：
  - **七柱宗門**：最古老的七宗。太玄道院、玄岳宗、問劍山、丹霞谷、天工門、御靈谷、玄冥宗（已在 `packages/content/world.json`）。前身是上古守著大陣七根柱子的七個家族，知道的秘密最多。
  - **分支宗門**：從七柱宗門分出去的支派、別院、叛出的門人自立的宗門。理念和本宗不同，常常互相看不順眼。
  - **新宗與散修**：斷脈之年後才出現的宗門、地方小派、散修聯盟、邊陲的宗門。**其中有一些暗中守著別的東西**（例如縫脈陣的節點、失落的母種、第八根柱子的傳說），越後期開放的宗門，藏的真相越深。
  - 新宗門可以一直加，規則只有一條：每個宗門都要對應世界觀的某一層，而且有自己「為世界好」的理由。

## 三、真相分五層（由淺到深）

每一層都會推翻上一層的一部分。**同一件事，換一層看就是另一個意思。**

| 層 | 玩家以為 | 其實 | 在哪裡揭露 |
|---|---|---|---|
| 1 | 青溪的溪水停了，是水路壞了 | 溪底的**靈脈**在變弱；水路的陣基是古人的「縫脈陣」，壞的不是水路是陣 | 新手第一章（青溪） |
| 2 | 三百年前「斷脈之年」靈脈斷了，七柱宗門合力縫好，從此太平 | 縫是縫了，但**縫法有代價**：把靈氣從邊陲引走，撐住中原；邊陲的村子從那時起慢慢枯 | 新手第二章（古林）、第三章（測資） |
| 3 | 有人在挖古樹的根、拆縫脈陣，是壞人 | 拆陣的是**被犧牲的邊陲人**：他們的土地快死了，只想把屬於他們的靈氣拿回來。他們做的事會讓中原崩，但他們沒有錯 | 入宗後第一季（裂靈湖秘境） |
| 4 | 天道公正，天劫是考驗 | 天道是上古先人造的**「代天大陣」**。世界的靈氣有限，飛升一個人要抽走一大片靈脈；**天劫其實是大陣在限制飛升人數**。守著這座陣的，正是最受尊敬的太玄道院 | 宗門篇中段 |
| 5 | 世界要靠大能、大陣才撐得住 | 靈脈會自己長回來，條件是**有人在上面好好活著**：種靈草、引水、淨化、照顧靈獸、修路修陣。每一株種下的靈草都把一絲靈氣還給地脈。上古之前，世界本來就是這樣活的；大陣反而讓人忘了 | 長線終局（由全服玩家一起決定） |

### 第五層就是那個「恍然大悟」

玩家從第一天開始做的事：
- 在**自己的領地**種靈草；
- 修青溪的水路；
- 淨化溪水；
- 照顧而不濫殺靈獸。

這些在遊戲裡都會**真的被伺服器記下來**，累積成每一塊地的「**脈息**」（見第七節）。玩家要到很後面才知道：這些小事就是在一針一線地把世界縫回來，而且是用活的方式，不靠大陣。

**這就是領地設計在世界觀裡的意義：你的田不只是你的田，它底下就是靈脈。**

## 四、沒有壞人：宗門各自的秘密（先寫七柱宗門，其他宗門照同一原則加）

原則：
- 每個宗門都有**公開形象**和**真正在做的事**；
- 真正在做的事，從宗門自己的角度看都是為了世界好；
- 衝突來自「怎樣才是為世界好」的答案不同，不是誰邪惡。

| 宗門 | 公開形象 | 藏著的事 | 為什麼他們覺得自己是對的 |
|---|---|---|---|
| **太玄道院**（引氣） | 正道之首、最受敬重 | 世代守著代天大陣；天劫是他們在「篩」飛升的人。偶爾會讓天賦太高的弟子「意外」止步 | 不篩，世界的靈氣三代就會被抽乾 |
| **玄冥宗**（暗影） | 邪宗、修陰煞之氣、人人避之 | 宗門建在斷脈裂口上；弟子把從裂口滲出的**濁氣吸進自己身體**，所以修出來的都是陰煞。他們是在替世界擋傷口 | 總要有人擋；被誤會比讓濁氣散出去好 |
| **問劍山**（劍） | 劍修聖地、當年斬妖救世 | 「斷脈之年」那一劍，是問劍山祖師**親手斬斷靈脈**：當時天缺擴大，要切斷才能止住；史書寫成「妖物斷脈、祖師斬妖」 | 不斬，整塊大陸會一起被拖進天缺 |
| **天工門**（器） | 只管造器、不問世事 | 縫脈陣、陣基、金紋鐵都是他們造的。他們知道陣快撐不住，正在偷偷造**下一座陣**，但材料要從古樹根下挖 | 陣壞了沒有新陣，大家一起死；古樹是可以犧牲的 |
| **丹霞谷**（丹） | 溫和、救人、煉丹 | 最早發現「種靈草能養靈脈」，卻把**母種**收藏起來，只賣子種：子種長得快，但不回饋地脈 | 母種一旦流出去就會被濫種、濫採；寧可慢慢來 |
| **御靈谷**（靈獸） | 和靈獸為伴，常和獵戶衝突 | 靈獸是靈脈的「免疫」，哪裡靈脈受傷，哪裡靈獸就多、就兇。他們在暗中把靈獸**趕到**裂得最厲害的地方 | 獵戶看到的是兇獸變多，他們看到的是世界在自救 |
| **玄岳宗**（體） | 樸實、苦修、最不講心機 | 唯一不知道任何秘密的宗門。祖訓只有一句：「**守山者不問山**」，他們世代守的那座山，就是大陣的一根「柱」 | 他們沒有想錯什麼，只是被所有人當成工具 |

**「真正的好人是壞人」**的那一個：太玄道院的院主。他溫和、公正、對新手最好，主線前期一直是導師般的存在；第四層揭露時，玩家才知道他親手讓好幾位天才「止步」，其中包括空屋的主人。但他依然不是壞人，他只是做了一個很冷的選擇。

## 五、關鍵人物（新手期就埋下）

| 人物 | 新手期看到的 | 真相 |
|---|---|---|
| **空屋的前房客**（暫名「季遠」，戊辰年住過） | 留下「待我測過資質，便回來」的信；宗門名冊寫「閉關未出」 | 測資時石台發出「裂光」（斷脈之體，見下）。太玄道院讓他止步，他逃了，加入了拆陣的邊陲人。他是第三層的「反派」，也是主角的鏡子：**玩家住的就是他的舊宅，種的是他留下的田。** |
| **沈岳**（玄岳宗教習，已在遊戲中） | 樸實、照顧新手 | 守山者。最後會面對「我守了一輩子的是什麼」 |
| **柳知微**（太玄道院，已在遊戲中） | 溫和的引路人 | 知道一部分真相，一直在猶豫要不要說。她會是玩家最早的「線人」 |
| **茶亭老人**（序章 A2） | 說「青溪這幾天不對勁」 | 當年縫脈時在場的人之一，活了很久；只對機緣夠的人多說一句 |

**斷脈之體**：極少數人天生和靈脈的「傷口」相通，測資時會發出裂光。這種體質能感受到靈脈，但大陣會把他們當成威脅。
- 這是**伺服器決定的稀有出生資質**，全服極少。
- 和「機緣不是每個人都遇得到」的設定一致。

## 六、伏筆的規則

1. **一條伏筆至少出現三次**：第一次是怪事，第二次是線索，第三次才是答案的一角。
2. **伏筆藏在玩法裡，不放在劇情框**：溪水的溫度、田裡長得特別好的一角、靈獸聚集的方向、NPC 隨口一句。
3. **同一個東西，不同層有不同解讀**：例如「金紋鐵」。
   - 第 1 層：鐵匠沒見過的鐵；
   - 第 2 層：縫脈陣的材料；
   - 第 3 層：天工門在挖古樹根找它；
   - 第 4 層：代天大陣的柱子也是它。
4. **少數人才有的真相**：機緣給的是別人拿不到的一片拼圖（例如全服只有幾份的「斷脈殘卷」）。拿到的人可以分享、可以藏。**玩家之間的討論本身就是玩法。**
5. **不說破**：任何一段文字都不能直接寫出下一層的答案。

## 七、世界觀怎麼變成玩法（伺服器真的記得）

| 世界觀 | 玩法 | 伺服器 |
|---|---|---|
| 靈脈會被人「養」回來 | 在領地種靈草、照顧靈田 | 每次收成在玩家那塊地累積 **脈息**；全區加總成「區域脈息」 |
| 縫脈陣在壞 | 一起修青溪水路（協作者斷流工作包） | 共用世界狀態 `world.channel`；修的人越多溪水越高（K22） |
| 靈獸是靈脈的免疫 | 狩獵靈獸 | 區域靈獸數量和脈息連動：濫獵會讓脈息下降、靈獸更兇 |
| 濁氣從裂口滲出 | 淨化溪水、淨水藥劑 | 淨化次數降低區域濁氣 |
| 天道（大陣）篩選飛升 | 境界瓶頸、天劫（宗門篇） | 境界上限由「大陣」規則決定，之後可被全服行為改變 |
| 結局不是寫死的 | 每一季的世界走向 | 全服的脈息、濁氣、大陣強度決定下一季世界長什麼樣（例如裂靈湖擴大或縮小） |

**重點：這些數字一開始就悄悄記錄，但不顯示給玩家。** 玩家只會在環境裡看到變化（溪水漲、草更綠、靈獸變少或變兇）。真相揭曉時再把數字攤開：「這一季，全服一起把青溪的靈脈養回了 37%。」

## 八、大時間線（內部用，不直接給玩家看）

| 時間 | 事件 |
|---|---|
| 上古 | 世界本來靠萬物生息養著靈脈，沒有天道陣 |
| 天缺 | 天裂開（原因留到最終章）；靈脈開始失衡，大陸往雲海下沉 |
| 立陣 | 先人建「代天大陣」，用七根「柱」撐住天；七宗的前身就是守柱的七個家族 |
| 約三百年前：斷脈之年 | 天缺擴大，問劍山祖師斬斷裂靈湖一帶靈脈止損；七柱宗門合力用縫脈陣縫合，靈氣改道往中原；不同意這個縫法的人出走，成了最早的分支宗門 |
| 戊辰年 | 靈脈第一次再裂；季遠住在青溪的舊宅；測資時發出裂光；被止步、出走 |
| 今天（遊戲開始） | 青溪的溪水停了；古樹的根被挖；裂靈湖的秘境每七天開一次；一群新手來到青溪 |

## 九、待 z1nnz 確認（不確認也可以照這份先做）

1. 雲境是「浮在雲海上的山河」，地圖邊緣是雲海斷崖。可以嗎？
2. 太玄道院院主是「最像好人的那位」。要不要換成別的宗門？
