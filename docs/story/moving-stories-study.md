# 感人故事研究：為什麼它們讓人哭，以及《承天》怎麼做到

> 2026-10-30，Claude Code。z1nnz：「我希望所有故事都是非常感人的故事。」也點名了幾部參考作品：
> - 翁法羅斯；
> - 海賊王（羅賓「我想活下去」、梅利號）；
> - 火影（自來也）；
> - 小說《病樹枝頭又逢春》（作者甜甜的瓜，原名《聽說我死後成了反派白月光》，2025 年完結，同年改編短劇）；
> - 以及其他感人的小說。
>
> **原則**：
> - 骨架不改，用的是最初的「承天」：天裂了，一直有人獨自承天，最後所有人一起承；
> - 這份研究只是讓它更打動人；
> - 只學「為什麼感人」，不照搬任何作品的情節。

---

## 一、參考作品與它們打動人的地方

| 作品 | 打動人的是什麼 |
|---|---|
| 崩壞：星穹鐵道・翁法羅斯 | 一群人各自扛著一份責任，在輪迴裡一次次失敗、死去，最後一起守住世界。結局的宿命感來自因果閉環：故事的開頭其實就是結尾的那個人 |
| 原神・芙寧娜 | 一個人在笑容背後獨自扛了五百年的秘密，不能對任何人說。真相揭開時，前面所有浮誇的樣子都變了意義 |
| 葬送的芙莉蓮 | 故事從「冒險結束以後」開始。主角在同伴的葬禮上才發現，自己從沒好好了解過他；之後的每一步都在補那份遲來的理解。愛意藏在戒指這種小細節裡 |
| 海賊王・梅利號 | 一艘船被當成家人。它撐到最後一刻，開口說了話，在火中告別。告別也代表一個時代結束 |
| 海賊王・羅賓 | 一個一直認為自己不該活著、獨自承擔的人，終於說出「我想活下去」；夥伴們為她向全世界宣戰 |
| 海賊王・艾斯 | 他死去時知道自己是被愛著的。這讓死亡不只是失去，也是一種圓滿 |
| 火影・自來也 | 老師在最後一戰把真相和意志傳給下一代。他的死推著徒弟長大，傳承比生命更長 |
| 鬼滅之刃・柱 | 英雄氣概和心碎交織。每一位的犧牲都換來後人前進的一步 |
| 誅仙・碧瑤 | 為所愛的人付出一切，那份誓言成為讀者心中二十年的痛 |
| 病樹枝頭又逢春（小說） | 修仙世界裡被虐待的男配，在女主死後棄仙入魔、要毀滅世界，只為了找回她。女主重生回來救贖他。**「壞人」是因為失去才變壞的**；救贖他的方法不是打敗他，而是讓他知道自己一直被愛著 |
| 仙逆（小說） | 李慕婉為王林煉丹、損耗壽元，等了他兩百年，在結嬰成功的那一刻死去；王林之後的逆天修行，都是為了復活她。感情沒有華麗的話，只有「我願為你付出一切」 |
| 天官賜福（小說） | 從萬人敬仰的太子，一路被貶到沒有一個信徒；八百年後，有一個人一直記得他、一直在等他。**落到最低處時，還有一個人沒有離開** |
| 詭秘之主（小說） | 主角好不容易對身邊的人有了歸屬感，然後失去；後來把卷菸盒和幾枚金幣託付給值得信任的人。**託付的小東西，比任何台詞都重** |
| 狐妖小紅娘・竹業篇（動畫、漫畫） | 一代八位天才世家子弟（王權弘業、楊一嘆、青木媛、張正等）組成面具團，想抗衡上一代、揭開世界的秘密。z1nnz 記得的版本：他們劈開封死的城牆走出去，幾乎全滅，活下來的一個殘了，最強的那個失去了劍心。**被期待的天才、想證明自己、打破禁忌的代價、活下來的人比死的人更痛** |
| 最終幻想 X（補充） | 一條世代重複的犧牲之路：每一代召喚士都以為自己是在拯救世界，其實是在延續循環。最後一代選擇打破它，代價是主角自己的存在 |

## 二、歸納：感人的十二個原因

1. **先有日常，才有失去**：觀眾先和角色生活、笑、吃飯，離別才有重量。
2. **隱藏的承擔**：有人一直一個人扛著，大家都不知道。揭開時，前面的每一幕都換了意思。
3. **遲來的理解**：失去之後才懂；之後的旅程就是在補這份理解。
4. **傳承**：犧牲不是終點，而是把東西交給下一個人。
5. **終於求救，而有人回應**：一直獨自承擔的人說出「我想活下去」，大家為他站出來。
6. **知道自己被愛著**：犧牲的人在最後知道自己不是孤單的。
7. **輪迴與打破**：一代代重複的失敗，每一次都留下一點東西給下一次；最後一次成功，是因為大家一起。
8. **物件承載記憶**：一艘船、一枚戒指、一封信。物件留下來，人不在了。
9. **犧牲要改變世界，並留下春天**：死要有後果，而結尾要有新生（病樹前頭萬木春）。
10. **跨越漫長時間的等待與約定**：兩百年、八百年，一直有人在等（仙逆、天官賜福）。時間越長，等待越重。
11. **「壞人」是因為失去才變壞的，救贖他的是愛**：不是打敗他，是讓他知道自己一直被愛著（病樹枝頭又逢春）。
12. **陪伴的真身**：一直陪在身邊的靈獸或器物，原來是某人最親的人，換了樣子留下來守著（z1nnz 記得原神有類似的一段，任務名稱待查）。前面所有的陪伴，揭開時全部換了意思。

## 三、用在《承天》：骨架不變，每一條都有對應

我們的骨架本來就是第 2、7 條：天裂之後，一代代有人獨自承天；歷史被撕掉（斷章），所以每一代都以為自己是第一個、也是最後一個。

| 原因 | 在《承天》裡怎麼做 |
|---|---|
| 1 先有日常 | 新手期的領地、青溪村、茶亭老人、師父沈岳、村裡的小孩。**主線前期刻意慢，讓玩家先住下來** |
| 2 隱藏的承擔 | 某位一直在身邊、看起來最普通的人，其實就是這一代的承天者。前期的每一個小細節（他總是很累、總在夜裡出門、第三盞燈）揭開後都換了意思 |
| 3 遲來的理解 | 空屋前房客的信「待我測過資質，便回來」。玩家住在他的舊宅、種他留下的田，很久以後才知道他為什麼沒回來 |
| 4 傳承 | 師父在最後把他知道的真相和未完成的事交給玩家。他的離開讓玩家從「被保護的新手」變成「承天的人」 |
| 5 終於求救，而有人回應 | **用多人連線做這一幕**：那位獨自承天的人終於撐不住、第一次開口求救。這時全服玩家一起回應（世界事件）。每個人種過的田、修過的水路、守過的燈，都在那一刻化成撐住天的力量。**玩家的回應是真的，不是動畫** |
| 6 知道自己被愛著 | 他倒下前看見的，是整個青溪、整個鼇極的燈一盞盞亮起來 |
| 7 輪迴與打破 | 每一次天裂（三百年前、戊辰年、現在）都有人獨自去扛，都失敗了一半；每一次都留下一點東西（一封信、一盞燈、一句話）。這一次不同，因為這一次所有人一起扛 |
| 8 物件承載記憶 | 茶亭老人不准打開的漆盒、博古架上的收藏、第三盞燈、前房客的田。**玩家自己擺在博古架上的東西，最後都會在故事裡被認出來** |
| 10 等待與約定 | 茶亭老人在等一個三百年前約好要回來的人；鼇極各地的天樞旁，都有一個在等的人 |
| 11 救贖「壞人」 | 前房客出走、加入拆陣的邊陲人，成了第三層的「反派」。救他的方法不是打敗他，而是讓他知道：當年青溪村的人一直在等他回來，他的田一直有人在種（就是玩家） |
| 9 留下春天 | 結局不是全滅，是新生：溪水回來、田裡長出新芽、孩子長大。主線最後一章可以叫「萬木春」 |

## 四、寫每一段故事時的檢查表

- [ ] 玩家和這個角色**一起生活過**嗎？（至少三次輕鬆的相處）
- [ ] 這個角色**扛著什麼**？前面有沒有埋下三個以上、揭開後會換意思的小細節？
- [ ] 他的離開**改變了世界或玩家**嗎？
- [ ] 他**留下了什麼東西**給玩家？
- [ ] 他走的時候，**知道自己不孤單**嗎？
- [ ] 這一段有沒有讓**玩家自己做過的事**被看見？
- [ ] 結尾有沒有**一點春天**？
