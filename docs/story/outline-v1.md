# 《承天》主線大綱與伏筆總帳 v1

> 2026-10-30，Claude Code。z1nnz：「不是什麼都要刻字，做事要有理有據，要埋伏筆、要寫故事線、要規劃大綱。」
>
> 故事內容以 `main-story-v4.md` 為準。這份文件管三件事：
> - 主線怎麼排；
> - 每個伏筆在哪裡埋、在哪裡提醒、在哪裡揭開；
> - 每個人物的故事怎麼走。

---

## 一、原則

1. **每個伏筆都要有三個點**：埋下（玩家第一次看到）、提醒（中間再出現一次，讓人記得）、揭開（真相）。缺任何一個點，就不算伏筆。
2. **有理有據**：世界裡的東西要有它存在的理由。刻字只放在本來就會刻字的地方（匾額、碑、誓言、名冊、書）。其他伏筆用東西、習慣、規矩、人的舉動來埋。
3. **人物的話照角色走**：台詞是角色在那個處境下自然會說的話，不是為了讓玩家抄下來寫的。
4. **揭開的順序有邏輯**：先揭開小的、近的（青溪、宗門），再揭開大的、遠的（三百年前、千年前、三千年前）。每一層揭開時，前面埋的東西都要回得來。

## 四、宗門篇（入宗到七國之前）

1. **入門**：拜師、分住處、學宗門的規矩。各宗的怪習慣在這裡第一次出現（見第七節）。
2. **天劫**：玩家第一次渡境界天劫。同時聽說一位師兄去渡飛升劫，大鐘沒有響，人也沒回來。
3. **六十年**：宗門裡老一輩抱怨六十年沒有人飛升，開始傳太玄動了手腳。宗門之間的表層衝突（論劍台、坊市、測資搶人）。
4. **戊辰年**：玩家聽到第一個有名有姓的第二層恩怨（依所屬宗門不同），找到當年的倖存者。
5. **柳知微**：回青溪探望，發現柳知微不在了，測資台旁只剩法袍。沈岳不解釋，只說「今天也點了」。玩家在她屋裡找到寫著沈岳名字、只寫一個「待」字的測資單。
6. **霽弦**：拆陣的人攻擊天樞，首領是霽弦。同屆五人之一（想當劍仙的少年）站在霽弦那一邊。宗門篇結束，玩家被派往七國查天樞的事。

## 六、終章：雲境

1. 小滿走出高塔，和霽弦一起扛天。想當劍仙的少年回到玩家這一邊。
2. 天缺最後一次裂開，霽弦求救，全服大事件。每個人身上浮出缺月。
3. 玩家走到雲境，見到第一個飛升的人。揭開三千年前和承天道。
4. 天缺變成門。
5. 小師妹摘下面具。七個印回到茶亭。
6. 萬木春。

## 十一、雷音的伏筆（2026-10-30 補）

- **地名**：《大林間奧義書》裡，造物主對天神、人、阿修羅只說了同一個音「Da」，三方各自聽成克制、給予、慈悲，每一方聽到的都是自己缺的那一樣；雷聲還在重複這個音。地名表只寫到這裡，不寫「雷是最高的法術」。
- **埋下**：師父常說「天塌下來，先砸到的是高個子。你們還矮，站我後面。」斷脈之夜，師父喊的那個字被一聲雷蓋住。
- **提醒**：雷音的雷從那一夜起就沒停過。
- **揭開**：法道那一位聽到的是「站」，以為師父要他們像平常一樣站到他後面、不准動手，所以她認定那一劍違背了師父最後一句話，定下「不得原諒」的律法。
- **收尾**：玩家把那一夜的雷聲找回來，大判官重審的是她自己，終於聽清楚師父喊的是「斬」。
