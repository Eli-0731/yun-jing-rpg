# 青溪角色跟隨視角原型

此版本先把現有固定鏡頭改成角色背後的可環繞視角；玩家仍在青溪開發場景內，模型是測試膠囊。這是操作基礎，尚未達到《原神》或《鳴潮》的動畫、戰鬥與畫面品質。

| 平台 | 移動 | 視角 | 遠近 |
|---|---|---|---|
| Windows | WASD，方向以當前鏡頭為準 | 按住滑鼠右鍵拖曳 | 滾輪 |
| 手機觸控原型 | 左下方向鍵 | 畫面右半部滑動 | 目前固定；之後加入雙指操作與 UI 設定 |

鏡頭繞角色轉動，俯仰限制在 -15° 至 65°，碰到場景碰撞物時會拉近。角色面向移動方向，伺服器仍決定移動並參與預測與校正。此版本不改出生、背包、獎勵或戰鬥規則。

驗證：Unity `6000.0.82f1` 批次執行 `YunJing.Editor.QingxiCameraSmoke.Verify`，確認鏡頭相對方向、生成場景的鏡頭元件與角色 prefab；另外完成 Windows 開發版建置。下一步是在開啟的遊戲中實際檢查滑鼠／手機觸控、跟隨抖動、牆角遮擋與網路延遲下的角色朝向。
