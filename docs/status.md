# 實作狀態 · 2026-10-24

目前是 M0／M1 的第一批基礎，**尚未完成 M0，也不是正式遊戲**。

## 本輪新增：入世流程 v0.4.0 與模型 v2

- 新身分創建與出生分配在同一資料庫交易完成；並行創角只抽一次，初始物資及煉氣訣資格不重發。
- 創角時間固定；滿十個現實日取得廣場測資資格，離線也計、不受本機生長倍率或客戶端時間影響。
- 測資前 `birth`、公開 `roots`／`apertures` 為 null，表示未揭露；`birthAssigned` 表示已分配。個人天賦支線暫不顯示，收據也不包含隱藏先天。
- 新角色可先使用煉氣訣或基礎武技；凡骨無根仍不能引氣，但可立刻練體。先天效率保留。
- 測資後可進入現有兩宗的基礎師承；入宗一次性開啟洞府／田地使用權。**雜役／外門／內門分級、選比試煉、床與箱子的實際互動、貢獻商店尚未實作**。新流程轉宗暫未開放，不能靠重入洗資源。
- 既有無 journey 的測試角色保留原本規則與財產，不猜測其創角時間、不重抽。本次加入獨立舊存檔 fixture 保留回歸覆蓋，沒有提供公開時間修改或資格跳過端點。
- API 與 DOM 模擬接 HTTP 共 **45 項自動測試通過**，包含十日前 1ms／到期、創角故障回滾、並行抽選、隱藏資訊、首次修行、田地門檻、舊存檔、重啟。
- 模型 v2 完成 6 張 1024px 烘焙貼圖、分離植物／水面、兩級 LOD、FBX／GLB 與打包貼圖的 Blender 母檔。12 個模型匯出重新匯入驗證通過；詳見 [素材紀錄](../art/README.md)。
- Unity 匯入與場景產生程式已接新版材質、LOD、顯示層。2026-10-24 重新嘗試 Generate 仍回報 **No valid Unity Editor license found**／exit 198；**尚未編譯或產生 prefab，不能稱為 Unity 已可運行**。
- 完整玩法修訂與建議在 [入世、宗門與秘境 v0.2](gameplay-revision-v0.2.md)。秘境、角色年齡、狩獵與裝備系統仍是規格／待辦，沒有因文件完成而成為可玩內容。

## 前輪新增：洞府灌溉 v0.3.0

- 建造蓄水池消耗 6 陣基石、4 靈石；提供 2 單位供水額度。
- 空田可配置自然生長、細流催生（1 供水／原時間 80%）、深灌養根（2 供水／原時間 125%／多 1 株）；採收不自動釋出水路配置。
- 播種時由服務端固定本茬識別、成熟時間與產量；作物未成熟前可花 1 青靈草照料一次，再多 1 株。不照料不會枯死。
- 建池與施肥使用綁定原料時，相關灌溉／照料收成繼承綁定；舊存檔作物保留原本時間及產量，不改出生。
- 新增 8 項後端測試和 1 項實際 HTTP＋DOM 模擬介面測試，含並行、斷線重送、舊資料及重啟。2026-10-24 全套 **36 項測試通過**；DOM 測試不等於真實瀏覽器視覺驗收。
- 先使用內建 image_gen 生成並保存三件物品的三視圖，再完成 Blender 靈田、蓄水池、導水渠模型；原始檔、FBX、GLB、渲染預覽及製作記錄見 [素材說明](../art/README.md)。共 5,760 三角面；六個匯出檔重新匯入 Blender 的幾何、尺寸及 UV 檢查通過。
- Unity 場景產生器已改為載入這三件模型，含基本 URP 材質轉換和碰撞盒；**尚未通過 Unity 編譯／匯入驗證**，模型也還沒有隨存檔變化的建造與生長外觀。

## 前輪新增：青溪章節 v0.2.0

- 修行手札：5 個主要目標＋生態支線，凡骨另有後天開靈支線。顯示前置、實際進度、缺少條件、取得材料的提示與個人成果。
- 沈岳／柳知微各 3 段師承對話，可在拜師前了解體修、法修及青溪事件；閱讀不會自動加入宗門。
- 青溪補給商人：4 項種子／材料，以固定遊戲內靈石價格購買。伺服器核價，扣款與入袋在同交易；用到綁定靈石時成品也綁定。
- 3 處調查的文字線索收進修行紀事。
- 舊存檔可直接推導手札，已有成果會計入；不改寫先天、不重抽，不因版本更新重新發初始資產。
- 改善頁面輪詢：資料沒變就不重建整份介面，倒數獨立更新；延遲回來的舊角色回應不覆蓋新身分。
- 當輪 27 項自動測試涵蓋後端與 DOM 模擬介面接實際 HTTP API，包含購買入帳後回應遺失、重新載入再重送。
- NestJS 固定更新至 11.2.7、Firebase Admin 至 14.5.0，修補套件稽核發現的已知問題；更新後 27 項測試全部通過，`npm audit --omit=dev` 回報 0 個已知弱點。這不等於正式服務安全驗收。
- 本工作階段瀏覽器控制無可用瀏覽器，未完成視覺排版驗收；DOM 模擬測試不等於真實瀏覽器或手機測試。

這些是玩法與本機驗證介面的實作。尚未把新增手札、NPC 對話及商店接到 Unity 場景中的人物與距離判定；不影響既有 Unity API 欄位。

- 唯一角色、伺服器抽選、出生不重抽、先天與當前修行分離。
- 四格種植、服務端計時、採收、防重複、成熟保留、離線結算。
- 兩配方、扣料、工作位、領成品、藥浴、綁定與上品藥效繼承。
- 三處調查、共同水渠、個人貢獻獎勵、後來者維護、淨化及共存兩路。
- 兩宗師承、體／法修進度、凡骨後天開靈、啟蒙試煉。
- 交易內保存、請求收據、資產變動帳本、並行請求與重啟恢復。
- 本機登入、登入交接、更新憑證輪替；PKCE 交換邊界與單次區域票證。
- 接收方靈草輸送：唯一 ID、28 日額度、取消墓碑、綁定加工。

## 具體阻礙

最近於 2026-10-24 驗證時，Unity `6000.0.82f1` 啟動回報 **No valid Unity Editor license found**，exit 198。這阻止套件匯入、C#／FishNet codegen、場景生成、Player 建置、實際雙端測試。使用者先前已表示會處理 Unity 授權；不以程式略過授權。

Editor 目前僅有 Windows／Android 支援，Linux Dedicated Server 模組需安裝。iOS 打包與簽章仍需適當 Mac／Xcode 環境。

4. Android 真機樣片，記錄持續幀時、溫度與記憶體；加入手把／鏡頭完善。
