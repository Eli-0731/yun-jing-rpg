# 雲境｜建模風格規格 v1（草案）

> **狀態：草案，待 z1nnz 核可後才發給協作者。** 2026-10-29，Claude Code 撰寫。
>
> 起因：協作者各自交的模型風格不一致：有的有完整貼圖，有的只有純色；面數從幾百到每件 3.5 萬；比例與原點也各不相同。[統一美術語言](yunjing-visual-language.md)定了方向，但多是形容詞。這份把方向變成**可以檢查的條件**：照做就會一致，不照做在驗收時會被擋下。

## 1. 風格一句話

**「寫實材質、略為誇張的造型」：** 材料要看得出真的是木、石、瓦、布、銅，有使用痕跡；但輪廓比現實更俐落、屋簷更翹、比例略為修長，遠看也一眼認得出來。參照五張世界方向圖的質感，不是卡通平塗，也不是照片級寫實。

| 要 | 不要 |
|---|---|
| 舊木有木紋、裂紋、榫卯；石有風化、苔痕、磨圓的邊 | 全新、乾淨、塑膠感的表面 |
| 輪廓清楚、有主次（屋頂 > 柱 > 窗 > 裝飾） | 每個面都塞滿同等密度的雕花 |
| 低飽和底色＋少量高亮重點（青、金、月白） | 整件高飽和、大面積發光 |
| 邊緣有倒角，高光會沿邊出現 | 銳利直角、沒有倒角的方盒 |
| 對稱中帶不規則（石塊大小、瓦片微錯位） | 完全複製排列的重複元素 |

## 2. 色彩（所有人共用）

| 用途 | 色票（sRGB） | 說明 |
|---|---|---|
| 舊木（主） | `#5A3A22`、`#7A5234`、`#3B2617` | 暖褐；風化處偏灰 `#6E6458` |
| 石灰牆 | `#D9CFBD`、`#C8BCA6` | 米白偏暖，不用純白 |
| 灰青石、瓦 | `#5E6B6A`、`#46524F`、`#7C8784` | 低飽和青灰 |
| 夯土、泥路 | `#8C6A48`、`#A88560` | 暖土 |
| 植物綠 | `#4E6B3A`、`#6F8A4A`、`#2F4A2A` | 不用螢光綠 |
| 氧化銅 | `#3E5C52`、`#6B8F7E` | 只用在包角、鉸鏈、香爐等少量部位 |
| 水 | `#1A5659`、`#2E7A78` | 低飽和青綠，透明度約 70% |
| 靈氣重點 | 青 `#7FE0D4`、金 `#E8C877`、月白 `#EEF2F2` | 每件最多一處，面積 ≤ 5% |

貼圖顏色要落在上面的範圍內（允許 ±10% 明度變化）。驗收時會把模型截圖與色票並排比對。

## 3. 材質與貼圖（統一做法）

- **一律使用 PBR 貼圖組**：BaseColor（sRGB）、Normal（OpenGL）、ORM（R=AO、G=Roughness、B=Metallic，Linear）。**不交純色無貼圖的成品**；灰盒階段可以，但要標 `Placeholder`。
- **貼圖密度**：近景道具 512 px/m；建築與大型結構 256 px/m；地標近景 1024 px/m。貼圖尺寸上限 2048，大多數 1024。
- **材質數**：道具 1–2 個；建築模組整套共用 3–4 個（木、牆、石、瓦）；角色另訂。
- **粗糙度範圍**：舊木 0.65–0.85、石 0.7–0.9、瓦 0.5–0.7、銅 0.35–0.55（金屬度 0.6–0.8）、水 0.05、布 0.8–0.95。
- **材質命名**：`M_<套件>_<材料>`，例如 `M_IK_AgedElm`、`M_QX_BlueStone`。

## 4. 比例與尺度

- 1 單位 = 1 m；角色身高 1.75 m（頭頂到腳底）。
- 門洞高 2.1–2.3 m、寬 0.9–1.2 m；欄杆 0.9–1.05 m；台階高 0.15–0.18 m、深 0.28–0.32 m；桌面 0.75–0.8 m；椅面 0.45 m；屋簷下緣離地 ≥ 2.6 m。
- 「略為誇張」只用在**屋頂與屋簷**（翹角上揚 15–25°、出簷 0.8–1.2 m）和**地標**（可放大到 1.2–1.5 倍）。日用器物照真實尺寸。

## 5. 細節分三層（遠／中／近）

| 層 | 距離 | 看得到什麼 | 怎麼做 |
|---|---|---|---|
| 遠 | > 40 m | 輪廓、屋頂曲線、色塊 | LOD2：只留輪廓，面數約 LOD0 的 15% |
| 中 | 10–40 m | 柱、窗格、欄杆、主要結構 | LOD1：約 LOD0 的 50% |
| 近 | < 10 m | 木紋、刻字、苔痕、釘、器物 | LOD0＋法線貼圖細節；小於 2 cm 的起伏都放在法線貼圖裡，不建成幾何 |

## 6. 面數預算（LOD0，三角面）

| 類型 | 上限 | 例子 |
|---|---:|---|
| 小道具 | 1,500 | 碗、瓶、書冊、燈籠 |
| 中道具 | 5,000 | 桌、櫃、藥架、丹爐 |
| 散布件（會大量複製） | 800 | 單叢草、花、小石 |
| 植物叢（中量複製） | 4,000 | 蘆葦叢、竹叢、灌木 |
| 建築模組（單件） | 4,000 | 牆板、窗牆、柱、屋頂段 |
| 整棟建築（組裝後） | 30,000 | 民居、坊市 |
| 地標 | 60,000 | 古樹、宗門門樓、測資廣場 |
| 角色 | 45,000 | 見女主角拼接說明 |

超過上限要事先說明理由，並由 z1nnz 核可。現有超標件（例如蘆葦叢每件 35,166）要補 LOD 或減面。

## 7. 原點、接口、碰撞、命名

- 照[接地規格](../execution/2026-10-29/14-grounding-spec.md)：原點在腳印中心、底部高度 0；不附地面底板；結構件附接口表。
- 物件名：`SM_<套件>_<名稱>_LOD0/1/2`；碰撞網格 `UCX_<名稱>` 或在 `model_info.json` 寫建議的碰撞形狀。
- 檔名有版本：`<名稱>_v001`，不覆蓋舊版。

## 8. 審圖的統一條件（每件都要交）

所有預覽用**同一套燈光與鏡頭**，才能放在一起比較：

- Blender 5.2、EEVEE；世界貼圖：Poly Haven 的 `kloofendal_48d_partly_cloudy_puresky`（CC0），強度 1.0；色彩管理 AgX、Medium High Contrast。
- 四張：正面、側面、背面（正交）、3/4 透視（焦距 50 mm），每張旁邊放 1.75 m 人形尺。
- 一張遊戲內截圖：放進新手村，用 1.7 m 眼高拍。
- 一張和既有協作者模型的並排比較圖：至少選一件相同類別的已交付模型。

## 9. 關卡（每件模型要過三關）

| 關卡 | 誰看 | 看什麼 |
|---|---|---|
| ① 三視圖 | z1nnz | 造型、比例、是否符合第 1、4 節；**通過才開始建模** |
| ② 輪廓（灰模） | 核心組 | 放進新手村，用遊戲鏡頭看比例和輪廓 |
| ③ 成品 | 核心組＋z1nnz | 貼圖、色票、面數、QA 報告、回匯、審圖照第 8 節 |

## 10. 目前已知的不一致（這份規格要解決的）

| 現況 | 問題 | 依本規格 |
|---|---|---|
| C 的回村道具 C01–C08 | 部分只有純色或簡單貼圖 | 補 PBR 貼圖組 |
| 核心組的丹房工作桌 v1 | 純色材質，沒有木紋 | 補貼圖（核心組自己改） |
| B 的蘆葦叢、靈草 | 每件 2.4–3.5 萬面 | 補 LOD 或減面 |
| B 的 dondon 套件 | 有的沒有 UV 烘焙、沒有碰撞或 LOD（`uv_baked: false`） | 補 UV、碰撞、LOD |
| 審圖燈光 | 每個人用不同背景與燈 | 改用第 8 節的統一設定 |

已交付的舊件**不要求立刻重做**；新件從核可日起照本規格，舊件依進度逐批補齊。
