## 已做與品質狀態

讀取頭面、虹膜、髮束與骨架的分區；另存本機材質改色檔。頭部樣片移除部分動物耳權重面、分離臉髮並加試作青玉銀葉。這讓我們可對照原創角色需要的臉型、長髮和妝造，但仍殘留來源角色輪廓及零散附件。

`yun-jing-head-study-v4.blend` 的頭部主網格約 17,587 三角面；Blender render profile QA **未通過**：110 對重疊面、97 對背靠背隱藏面、2 個零面積 UV 面，且 UV 疊用及多個分離島。它是結構研究，不匯入正式角色、Unity 或公開儲存庫。

## 下一段製作

1. 依 Heroine-01 參考圖，先定頭部正面與四分之三角的眼距、下顎、鼻口；保存近鏡對照。
2. 重做長直半挽髮及背面輪廓，移除獸耳、披風硬件和殘留附件；髮飾改為青玉、銀葉、垂珠。
3. 做臉部妝造、頭髮 UV／材質與動畫變形檢查；修清重疊面和游離件，再做四角度 QA。
4. 與青溪遊戲鏡頭對照，確認不是只有靜態近景像角色；通過後才製作身體衣裝與 Unity 匯入。
