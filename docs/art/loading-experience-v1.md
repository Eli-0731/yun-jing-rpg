# 雲境｜入境體驗（網頁載入畫面）設計 v1

> 2026-10-29，Claude Code。z1nnz 問「Unity 前面的載入畫面能不能去掉，原神也沒有」。
> 答案：Unity 標誌已關掉；但載入時間不能消失。原神也在載入，只是把它做成開場的一部分。
> 這份是雲境的做法：**載入時間＝入境儀式**，讓玩家等待時就已經在雲境裡。

## 1. 原則

1. **第一秒就是雲境**：打開網址 0.2 秒內出現山水與「雲境」二字。不能有白屏，也不能有任何 Unity 字樣。
2. **等待要有東西看，但不能逼人看**：可以靜靜看雲，也可以互動，但沒有任何事情非做不可。
3. **進度說實話**：顯示真實的 MB 和百分比。卡住時要說出原因（例如網路慢），不能假裝在跑。
4. **第二次打開要快**：下載過的東西快取起來，再進來只需要「點擊入境」。
5. **轉場是作品的一部分**：從載入頁進遊戲用墨暈擴散，不是畫面一黑再亮。

## 2. 玩家看到的流程

| 時間 | 畫面 | 玩家可以做 |
|---|---|---|
| 0–0.2 秒 | 山水雲霧插畫（約 160 KB 的 WebP），「雲境」標題淡入 | — |
| 0.2 秒起 | 雲層開始緩慢飄動；底部墨線進度條從左往右畫；「凝氣中… 12%　8.4 / 46 MB」 | 拖動畫面：手指劃過處雲霧被撥開，露出底下的山（純 CSS 與 Canvas 2D，不用等 Unity） |
| 下載中 | 每 8 秒換一張「雲境見聞」卡片：一句世界觀、一個地名，或一個新手提示。例如「青溪村的古樹，據說比村子還老」「靈根要到第十日才會顯現」 | 點卡片可以切下一張 |
| 90–99% | 文字改成「築基中…」（Unity 解壓與初始化），墨線收縮成一個玉色光點 | — |
| 100% | 玉點緩慢呼吸，「點擊入境」 | 點擊或按任意鍵 |
| 點擊後 0.6 秒 | 墨暈從玉點擴散，蓋滿畫面再退開，露出遊戲第一個鏡頭；同時開始播環境音（溪聲、鳥鳴） | — |

**第二次以後打開**：檔案都在快取裡，進度條 1–2 秒跑完，直接出現「點擊入境」。卡片換成「歡迎回來，已在青溪住了 3 日」（之後由伺服器提供天數）。

## 3. 畫面設計細節

- **背景**：三層視差，遠山、中景村落、近景竹葉，各一張 WebP，總共 ≤ 220 KB。手機用 960 px 寬，電腦用 1920 px。用 `<picture>` 讓瀏覽器自己選。
- **雲**：兩層半透明雲帶圖片，用 CSS `transform` 動畫往左右緩慢漂移，30–60 秒一循環。
- **撥雲互動**：一個 Canvas 2D 遮罩，手指經過處把遮罩擦淡，3 秒後慢慢恢復。純前端、不連網，手機上很省電。
- **標題**：「雲境」用手繪書法 SVG（Codex C6 的標誌）。完成前先用霞鶩文楷子集字型。
- **進度條**：SVG 路徑模擬毛筆的粗細變化；數字用等寬字，跳動時版面不動。
- **配色**：用介面方向文件的色票，月白天空、灰青山、墨色文字，只有玉色光點一處亮色。
- **聲音**：瀏覽器規定點擊前不能播放聲音，所以只在「點擊入境」那一刻開始，正好當作「入境」的儀式感。

## 4. 技術：讓等待變短（比畫面更重要）

| 做法 | 效果 | 狀態 |
|---|---|---|
| 關掉 Unity 標誌開場 | 少 2.7 MB，少 2 秒 | ✅ 2026-10-29 完成 |
| 字型只留常用 5,401 字 | 27.5 MB → 4.8 MB | ✅ 2026-10-29 完成 |
| 模型網格壓縮、貼圖 Crunch 壓縮 | 預計再少 30–40% | ✅ 已設定，量測中 |
| ServiceWorker 網路優先＋版本化快取 | 第二次打開幾乎不用下載 | ✅ 已有（serve.mjs／C3 外殼） |
| **分段下載** | 第一段只載入 A2 村外官道（目標 ≤ 15 MB），玩家走路的同時在背景下載青溪村與其他區塊 | 待做，搭配區塊串流，P2 |
| Brotli 壓縮（取代 gzip） | 實測 49.6 → 41.3 MB（含新增的 A2、A3） | ✅ 2026-10-29 完成；正式主機設定 `Content-Encoding: br` 可省掉瀏覽器端解壓 |
| 行動數據提醒 | 偵測到行動網路且下載量 > 30 MB 時，先問「要現在下載嗎」 | 待做 |

**目標**：第一次打開，4G 網路（約 10 Mbps）在 **15 秒內**可以點擊入境。之後每次打開不超過 3 秒。
