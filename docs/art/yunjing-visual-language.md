# 《雲境》統一美術語言 v0.1

更新：2026-10-27。這是新素材的製作準則，並非現有素材已全部達標。以使用者選定的五張世界規劃圖、青溪道路與河岸三視圖、Heroine-01 原創三視圖為方向；只使用我們有權使用的素材。不同地區可有自己的樣貌，但遊戲畫面要能一眼看出屬於同一個修仙世界。

## 世界共同語彙

- **形狀：** 山、樹、屋簷及衣袖以流暢長曲線帶出向上生長的方向；石塊、水岸與土路保留不規則邊緣。建築的柱、門與橋保留清晰可讀的結構，避免每件物品都變成裝飾雕塑。
- **材料：** 原木、灰青石、夯土、瓦、竹、布、少量氧化銅。細節呈現實際製作與風化痕跡：木材有接榫，石階有磨損，牆腳有濕痕。靈氣以少量透光、符紋或環境反應表達，日常場景不鋪滿發光線條。
- **色彩：** 基底為暖土色與植物綠，水與瓦取低飽和青藍，靈氣或重要互動點用更亮的青、金、月白色。整個畫面保留明暗焦點，不讓地面、房子、樹與角色同時高飽和。
- **尺度：** 以 1.75 m 角色身高與 1 Unity 單位＝1 m 為共同校尺。門洞、欄杆、台階、採集點都在角色鏡頭下驗收，遠景仍需有明確輪廓。
- **密度：** 近景靠材質與少量立體細節，路沿有成組草、花、碎石；中景依大輪廓和光影；遠景以山體、建築剪影、雲霧分層。散佈使用同一套小物變體，避免等距複製。
- **角色：** 精緻仙俠漫劇質感與世界的自然材料互相呼應。臉、髮束與衣料可以更細，但服裝的金屬、布色、符紋與宗門建築使用相同材料及色彩邏輯。Heroine-01 以原創三視圖固定面部辨識點。使用者提供且表示已有授權的角色模型可做本機改造研究；來源、原作者與修改範圍須分開登記，不把改色或改面說成完全原創。

## 青溪新手區的當前主題

主題為**臨水初入世的有人居住的修仙聚落**。入口應看到彎曲土石路、河流、木石橋、竹與闊葉樹、灰青瓦屋、可辨識的公共平台。地面不要是一整片純色平面；房屋不要全用同一個方盒。重要路線以路面、欄杆、燈與水聲引導，不靠巨型發光箭頭。

| 部件 | 青溪做法 | 可變動範圍 |
|---|---|---|
| 道路與地面 | 土路有車轍／踩踏中心、碎石過渡、疏密不一的草邊；斷面接入周圍地形 | 坊市可增石板，山徑可增裸岩，但仍沿用材質與不規則過渡 |
| 河與橋 | 青藍透明水、深淺及岸緣變化；橋有可信的承重、扶手與可行走寬度 | 上游窄急、村內緩流，橋式可換木、石、索 |
| 房屋 | 灰青瓦、暖木樑與淺牆；屋簷有層次，生活區有器具與植物 | 宗門建築可更莊嚴，民居更小、更舊 |
| 植被 | 同種樹保留樹冠輪廓變體；根部實際入土，樹蔭落在可走地面 | 靈脈區可加特殊色葉或微光，但自然生長結構仍可信 |
| 角色 | 髮絲與布層次在近鏡辨識，遠鏡保持清楚剪影 | 宗門與地域可換衣式，身形、臉部品質與布料邏輯一致 |

## 每件資產交付前的順序

1. 自製模型先生成、檢視並保存該物品的 AI 三視圖，標出正、側、背及推定區域。重用已有模型則記錄來源、作者及可用範圍。
2. 先做輪廓與實際尺寸，放進青溪場景用遊戲鏡頭看比例；只在輪廓與連接方式通過後做近景細節。
3. 保存可編輯母檔、引擎交換檔、正側背與實際場景鏡頭圖。用同一角色、天空和光線比較，不只看白背景展示圖。
4. 檢查地面接觸、浮件、重疊面、UV、材質數、碰撞及 LOD。手機預算以真機量測調整，不能拿單張渲染圖宣稱達到遊戲內品質。
5. 在 `docs/work-ownership.md` 登記原作者、整合者、用途及未完成項。新素材與已有素材並排檢查輪廓、顏色和細節密度。

## 本輪與目標之間的差距

現有青溪世界仍混有灰盒地表、平直道路、簡化水體與未統一的匯入材質；Heroine-01 目前的臉部原型與三視圖不相似；角色戰鬥操作與技能效果也未達目標。這份規範用來逐區替換與驗收，不能把風格提案當成已完成畫面。
