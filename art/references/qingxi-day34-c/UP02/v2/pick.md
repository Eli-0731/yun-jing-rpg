# UP02 第二版候選選擇

選定：**UP02-v2-cand-1.png**。以其**上排**左側正面、中央側向與右側俯視所描述的三石組合為主要造型依據；下兩排只用來理解表面處理，不當作額外石頭或另外兩組資產。

## 選擇理由

- 大石居後、兩顆較小石分列前側，形成緊湊而有高低變化的三角形輪廓。大石輪廓最接近水流磨圓的卵石，較不容易被做成尖銳山岩。
- 三顆石頭的遮擋、石間低谷與各自的落地位置容易讀取。可先用三個不等大的卵形體建立輪廓，再處理接地與表面，不需要發明支架或拼接結構。
- 暖灰乾燥面、下緣較暗的濕面、頂部苔蘚與石縫植被層次完整；頂部與周圍苔蘚的黃綠／赭黃變化能支持「內部微暖」的敘事。
- 比第 2、4 張更少強烈發光熱點；細裂紋仍可調整為提示詞要求的「幾乎不可見琥珀暖意」。
- 細節豐富但石體仍是主角。蕨葉、草束、細礫與少量斑駁可分成可製作的部件。

## 四張逐一檢查

| 候選 | 判斷與問題 |
| --- | --- |
| 1（選定） | 三石整體最清楚、圓潤度最好。缺點是生成成三排重複三視組合，各排大石比例與植被位置略有漂移；不是精密正交工程圖。上排主裂縫仍稍亮，苔蘚黃化沒有形成完全清楚的小環，石體也沒有字面上埋入一半。後續須鎖定上排設計，將裂光壓低、用局部斷續黃化帶表達溫暖。 |
| 2 | 大石像傾斜的長片／立碑，側向偏尖高，與圓潤溪石的第一印象較遠。主裂縫長而直、亮度偏高，容易被做成熔岩或金色接縫。九個畫面中的主石傾角、附石位置也不夠一致，且部分底部近似積水亮斑。 |
| 3 | 石材與苔蘚細節很好，但把大中小三顆石拆成三個分開展示的個體，缺少「三石一組」的固定接地、遮擋與植物共享空間。最大石還出現較碎裂的前緣附塊；照圖建模容易變成三個獨立道具。 |
| 4 | 三角構圖完整，但主石更斜長、面轉折較稜角化。多處裂縫出現醒目的橘黃熱點，超過「barely visible faint amber warmth」；視圖間形體、苔蘚及裂紋位置也有漂移。更像有顯著魔力的岩石，較不符合克制的溪邊微暖感。 |

- 四張候選皆為四次獨立內建影像生成呼叫，均逐字使用使用者完整原始提示詞，未附帶前一張圖片作為參考。
