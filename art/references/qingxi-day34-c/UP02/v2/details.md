# UP02 建模製作核對清單

本清單供 Blender 製作三顆微暖溪石、附生苔蘚與接地植被。所有長度以**公尺（m）**記錄；數量、尺寸與位置為依提示詞及參考圖整理的製作目標，不是照片量測值。依 **5 m 距離的輪廓與大色塊 → 1 m 距離的材質及生長關係 → 近看細節**排列。

## 優先級 1：5 m 看去的輪廓、重量與三石關係

### A 主石：一個完整石體，不能以碎塊拼出

- [ ] 建立寬 0.90 m的非對稱卵形基體；最高處略偏左後，頂面是寬圓冠，前腹飽滿，右肩緩降。勿使用球體均勻縮放後直接交付。
- [ ] 以 6–10 個大而柔和的面轉折塑出水磨感，單一可讀色面／形面約 0.12–0.30 m；保持連續曲面，沒有尖峰、刀口、階梯或明顯低多邊形輪廓。
- [ ] 肩頂、側腹的大轉折曲率半徑約 0.04–0.12 m；局部較平的前面與圓肩交界以約 0.012–0.030 m的柔和過渡接起。這些是雕塑圓角，不是每條網格邊都加同一倒角。
- [ ] 前方中部保留一塊主要裸石面，約 0.35–0.50 m寬；苔蘚只分割它的邊緣，不在正面鋪滿。
- [ ] 下半部連續延伸為稍收束的圓卵底，埋入土中；不因轉面圖下緣近似水平就切成平底半球。
- [ ] 後面比前面稍平緩，寬度仍約 0.85–0.90 m；沿用同一肩頂，不另外拉出凸背或尖頂。
- [ ] 材質為無金屬感的暖灰石；上面偏灰米色，陰面混冷灰紫，底部帶濕灰綠。細節圖的角狀筆觸主要屬貼圖，不把每塊色斑都雕成硬岩屑。
- [ ] A 與 B、C 在不同位置接近；可見狹縫約 0.01–0.04 m，向底部收窄並被泥、苔與根部填入。不得出現明顯互相穿插的切面。

### B 左前石與 C 右前石：大小、形狀、覆蓋各自不同

- [ ] B 為 1 顆完整石，外側略鼓、內側靠 A 稍陡；主形面約 0.08–0.18 m。其左右寬大於 C，不能是 C 的鏡射複製。
- [ ] B 的圓肩半徑約 0.025–0.065 m，局部平面轉折過渡約 0.006–0.015 m；下腹與泥面接觸處保持圓鈍。
- [ ] B 暖灰主色略帶橄欖灰；苔蘚在頂肩和外側較集中，前面下半有深灰綠濕斑。至少留一片連續裸石面。
- [ ] C 為 1 顆完整石，主形面約 0.06–0.16 m，頂肩比 B 低，前臉略斜，外緣偏扁圓；避免正圓球外形。
- [ ] C 的圓肩半徑約 0.020–0.055 m，局部過渡約 0.005–0.012 m；一條短斜裂紋是其辨識點，位置不能移到另一顆小石。
- [ ] C 上緣比 B 稍暖亮；下前緣濕面較深，頂部少量苔斑沿肩轉折延伸。裸石面積大於苔蘚面積。
- [ ] B、C 與 A 都由下方土礫承重，沒有金屬、繩索、黏合件或木支架；「接合」是石間遮擋與落地關係。
- [ ] 從正面看 B、C 分守左右，石間中部留約 0.12–0.22 m寬、不規則且被植被部分遮住的凹谷；不要做成對稱拱門。
- [ ] 從俯視確認 A 居後、B 與 C 偏前；從背面看，小石應被主石部分遮住，不能照生成圖把它們再移到後側以求三顆完整露出。
- [ ] 三顆石共用材質風格，但石形、裂紋、濕斑與苔斑均有獨立分布；禁止複製同一石頭再只改大小。

### 接地面與遠距植被輪廓

- [ ] 地表為約 1.60 × 1.18 m的鬆散不規則斑塊，外圍有幾處凹缺及稀疏散礫；不是圓盤、矩形板或有厚側壁的展示底座。
- [ ] 地面薄片可供場景拼接；埋入石體的隱藏部分由場景地形包覆，不必建一個厚 0.30 m的獨立土塊。
- [ ] 礫土在石腳堆高約 0.005–0.020 m，順著曲面形成不均勻接觸線；根部插入地表，所有可見礫石都落在地表或部分埋入。
- [ ] 約 5 m距離先讀到暖灰三石、低矮暗色接地帶、局部黃綠苔蘚與數束植物；不應先看到金色裂縫或滿地碎點。
- [ ] 植物集中在左右外側、A–B／A–C 縫隙及後方；前方中央留出礫石與石腳，形成疏密節奏。
- [ ] 草葉與蕨葉偶爾伸出石群外緣約 0.05–0.12 m；最高一兩片可接近主石頂部，但不鋪成整圈高草牆。

## 優先級 2：1 m 看去的乾濕色塊、苔蘚與微暖敘事

### 石材底色與手繪面層

- [ ] 三石共用不均勻暖灰底色；可用灰米色 #8C8576、淺暖灰 #AAA08B作起點。色碼僅供選色，最終依燈光與色彩管理校正。
- [ ] 大色階每塊跨約 0.08–0.25 m；正面灰米、朝上面暖淺灰、側面冷灰紫；先做寬而柔和的漸層，再疊少量有方向的筆觸。
- [ ] 次級岩面色斑約 0.015–0.060 m，邊緣有軟硬變化；一部分互相融入，少數留可見筆鋒。避免均勻蜂巢、迷彩貼花或全表面等密度顆粒。
- [ ] 最細礦物點約 0.001–0.004 m，只在少數區域零星出現；多數以顏色表示，不做同尺寸球粒遍佈全石。
- [ ] 前面偏中下有少量灰藍、灰青的冷色小斑，約 0.005–0.025 m；作礦物／地衣感的低對比色層，不作鮮藍寶石。
- [ ] 幾何高度變化保持克制：主要平緩凹凸約 0.002–0.008 m；小色斑通常不需要幾何位移。
- [ ] 無木紋、拼板縫、繩纖維、金屬銹、釘孔或修補扣件；這些材質在本物件不存在。

### 濕斑、土漬與磨耗方向

- [ ] 每顆石下部建立 1 個不規則主要濕區，再拆成 3–6 個互相連接的舌形邊界；濕色向上延伸約 0.04–0.12 m，縫內可稍高。
- [ ] 濕區用低明度灰褐、灰紫與灰綠，參考 #575B53、#5E5C67；保持細微底色變化，不能以純黑漆出接地圈。
- [ ] 濕斑上緣過渡寬約 0.015–0.040 m，包含少量局部硬邊；不畫完全水平的水位線。
- [ ] A 前下部與兩個夾縫最濕；B 外前下腹、C 前下腹次之；頂部保持較乾較淺。以高度、遮陰與積水位置組織斑塊，不用隨機噪聲替代。
- [ ] 濕面主要以顏色加深表達，粗糙霧面仍保留；若使用 Principled，非金屬且粗糙度可從乾面 0.80–0.95、濕面 0.65–0.85起調，不能產生鏡亮高光。
- [ ] 石腳有約 0.005–0.020 m高的泥褐積垢，內側凹處較厚，外凸圓肩較薄；薄泥層視覺厚約 0.0005–0.002 m。
- [ ] 少量上往下的淺水痕沿曲面流向石腳，寬約 0.003–0.012 m、長約 0.03–0.10 m；斷續、低對比，避免長條鐵銹色污線。
- [ ] 水磨痕順著外凸圓肩與下緣作弧向延伸，寬約 0.006–0.025 m、長約 0.03–0.12 m。圖中沒有明確水流方向，不發明滿面平行刮痕。
- [ ] 受磨外凸處稍淺且較平滑，凹陷與裂縫留暗土；高光是柔寬色面，不能像金屬刃口。
- [ ] 接觸陰影只局限在真實近接區，用柔和深灰紫／灰褐；不要把完整輪廓都描黑。

### 苔蘚：石頂附生、石縫潮濕、局部黃化

- [ ] A 有約 4–6 組主要苔斑，位於左後冠頂、上肩、右肩和少量前下緣；單組跨度約 0.06–0.24 m。相連者仍有露石破口。
- [ ] B 有約 2–3 組主要苔斑，跨度約 0.035–0.12 m，偏頂部、外側肩與腳邊；C 有約 2–3 組，跨度約 0.025–0.10 m，覆蓋量略少。
- [ ] 可見石面苔蘚覆蓋以 A 約 20–30%、B 約 15–25%、C 約 10–20%為目標；按埋深調整，不把埋入泥中的部分刷滿鮮綠苔。
- [ ] 每組苔斑是貼合曲面的薄墊，厚約 0.002–0.006 m，偶有小丘到 0.008 m；邊緣碎裂成大小不一的小葉／顆粒狀輪廓，不像厚草皮或球狀海綿。
- [ ] 苔斑用 3–7 個大小不一的相連葉狀島構成；主要邊緣缺口約 0.005–0.025 m。遠看讀成整塊，近看才見細碎邊緣。
- [ ] 孤立小苔島直徑約 0.003–0.018 m，零星出現在大苔斑周圍與凹面；分布有聚集與空白，不能平均撒滿。
- [ ] 新鮮區用橄欖綠、灰苔綠，受光偏黃綠，遮陰帶低彩度青綠；參考 #747B38、#555F40、#53675A。
- [ ] 局部乾燥苔以赭黃、稻草黃與灰橄欖過渡，參考 #A59A4D、#B5A660；不是亮黃發光貼片。
- [ ] 「小圈黃化」做成石腳或局部苔斑外緣的**斷續窄帶**，寬約 0.015–0.040 m；沿曲面與生長邊界彎繞，約一半至三分之二弧段可辨識，其餘被土、礫、裸石或鮮苔打斷。
- [ ] 黃化帶內有少數扁塌、褐黃的小苔尖；其外緣仍有較新鮮的綠色，形成由局部微暖向外恢復的變化。不可做成規則同心圓或光環。
- [ ] 圖片黃化帶並不完全連貫；建模時補足的是局部色彩關係，不新增魔法符文、燒焦黑環、煙、火或冒光粒子。
- [ ] 石縫苔蘚最濕、最深，緊貼泥土與石面；石頂較乾、較黃且稀疏。這兩種分布不能套用同一個全局頂向遮罩。
- [ ] 細節圖上肩可見少量纖細枯苔尖／小葉狀枝，約 0.003–0.012 m長；每個主要苔斑保留數處即可，不做出整片蕨林。
- [ ] 苔蘚底部先貼石面，再以短小不規則邊緣覆住接線；沒有懸浮的苔片，也沒有同厚度整片塑膠膜。

### 裂紋與極弱琥珀色

- [ ] 每顆石只保留 **1 條主裂紋，最多 1 條短次裂紋／分支**；細節圖中密集色塊交界不可全部當作裂紋。
- [ ] A 主紋由前面偏左下處向上彎至左上肩，再向頂部延伸，沿曲面長約 0.35–0.55 m；走勢有幾處鈍折，不能是一條筆直切割線。
- [ ] A 短分支從主紋中上段向側方延伸約 0.06–0.14 m後漸細消失；若選擇冠頂短裂紋作第二條，就不另外增加第三條。
- [ ] B 裂紋較不顯眼，藏在上肩或偏內側面，長約 0.10–0.20 m；一部分被苔蘚或植被擋住，不能為了「看得到」把它移到正面中央。
- [ ] C 保留前面由左下向右上彎折的短斜紋，沿面長約 0.15–0.25 m；末端到肩部漸弱，可有約 0.025–0.060 m短分支。
- [ ] 裂紋可見寬約 0.0004–0.0012 m，局部節點最多約 0.0015 m；視覺凹深約 0.0005–0.002 m。放大圖中的誇張開口不按圖放大成深槽。
- [ ] 裂口唇邊圓磨半徑約 0.0003–0.0008 m，不做新鮮銳利崩裂；邊緣偶有微小缺點，但石體不分離成兩塊。
- [ ] 裂紋端部長約 0.015–0.035 m的區段逐漸變細、斷續、融入表面；不突然以等寬圓頭截斷。
- [ ] 裂紋底色為灰褐偏暖；只有短段內部帶暗赭琥珀，參考 #99703D。可見暖色只佔裂紋部分長度，不畫完整金線。
- [ ] 常態先以顏色表達暖意；必要時僅加極弱自發光。在正常晨光與 1 m觀看距離下，暖意需仔細看才發現，5 m處不可成為主要亮點。
- [ ] 不產生 bloom、發光熱點、向外照亮植物或地面的光暈；沒有熔岩、金屬鑲嵌、金繕或符號圖案。
- [ ] 以同一組 UV／曲線資料鎖定裂紋，從正面轉到側面、頂面時路徑能接續，背面不鏡像出另一條同形裂紋。

## 優先級 3：1 m 的植被、礫土、縫隙與零件固定關係

### 蕨類：莖、葉軸、羽片、幼葉與根冠

- [ ] 目標約 **5 個根冠**，約 4–6 個可接受：左外後側、A–B 夾縫、A–C／C 後側、後右側、後左側各一組；後方組在正面可被石體遮住，不為了展示全部而移到正面。
- [ ] 每個根冠覆蓋直徑約 0.025–0.050 m，深褐根基插土約 0.01–0.025 m；不是從光滑石壁無根長出。
- [ ] 每冠約 4–7 片大小不同的羽狀葉，完整葉長約 0.10–0.25 m、寬約 0.035–0.085 m；靠石縫的小葉可縮至 0.07–0.12 m。
- [ ] 葉柄／中軸粗約 0.001–0.0025 m，從根冠向外上方彎出，色為黃橄欖至深橄欖；葉柄下段較暗。
- [ ] 每片主葉沿中軸排約 7–11 對羽片，近基部較大、尖端漸小，頂端留一片終端小葉；左右可錯開，不要求機械式完全對稱。
- [ ] 羽片長約 0.008–0.022 m、寬約 0.004–0.011 m，輪廓偏圓卵／小匙形，端部柔圓；不要做成尖銳鋸齒或寬大的熱帶葉。
- [ ] 每片羽片以極短小柄接中軸，彎折約 0.001–0.004 m形成薄片弧度；實體厚度僅約 0.0002–0.0005 m，或使用雙面薄葉片。
- [ ] 葉面中央稍亮、葉緣稍深，保留柔和主脈；側脈只用低對比手繪暗示，不畫滿寫實細脈。
- [ ] 向光葉偏黃綠，內側葉偏橄欖／灰青綠，少數近暖石的葉尖輕微黃化；不將所有葉片刷成同一亮黃。
- [ ] 每冠留 1–2 片短小幼葉，長約 0.035–0.080 m，靠根部較直立；其餘向不同方向舒展，避免同角度扇形陣列。
- [ ] 蕨葉可跨過石腳或遮住少量裂紋，但不能大面積穿透石體；葉柄進入縫中時仍有合理連續路徑。

### 草束：寬窄葉、乾尖與少量種梗

- [ ] 建約 **7–9 束草**：左右外腳各約 2 束、兩個主石夾縫各 1 束、前緣約 1 束、後側約 1–2 束；按遮擋合併重複可見的同一根部。
- [ ] 每束根盤直徑約 0.025–0.055 m，黃褐／灰褐葉鞘插泥約 0.01–0.02 m；草基與苔、碎礫交錯。
- [ ] 每束約 7–13 片葉，長約 0.06–0.24 m；中央較直立，外側彎垂，寬約 0.002–0.007 m，根部較寬，末端收至尖點。
- [ ] 細節圖中央較寬的帶狀草葉保留 3–5 片，寬約 0.006–0.010 m；不可全部換成同細度線段。
- [ ] 草葉薄且帶細折脊，實體厚度約 0.00015–0.0004 m；中軸沿葉長走，色階由根部深橄欖向尖端黃綠。
- [ ] 約五分之一至三分之一葉片有枯黃尖端，枯段約 0.015–0.060 m；少數整片乾葉彎向外側，呈低彩度稻草色。
- [ ] 曲率各不相同，長葉可越過短葉形成交疊；不能像整齊刷毛、刺球或圓柱束。
- [ ] 細節圖低處可見少量細種梗／乾草梗，目標全組約 4–8 根；高約 0.04–0.10 m、粗約 0.0005–0.0012 m。
- [ ] 每根種梗頂端只有 2–5 顆微小赭黃粒，單粒約 0.001–0.003 m；作乾燥草籽感，不發展成亮色花朵或新的主角。

### 低矮圓葉地被：不要誤認成苔蘚

- [ ] 建約 **8–12 個小葉叢**，聚在中央低谷、兩側根部和後側濕土；有些只露出幾片葉，不平均排成一圈。
- [ ] 單叢寬約 0.035–0.10 m、高約 0.015–0.055 m，約 5–9 片葉，中心有短莖與基部連接。
- [ ] 葉片長約 0.012–0.035 m、寬約 0.010–0.028 m，圓卵、匙形或淺分瓣；細節圖的前低葉叢保留柔和波狀葉緣。
- [ ] 葉柄長約 0.008–0.035 m、粗約 0.0007–0.0015 m，向地面不同方向伸展，末端托起葉片。
- [ ] 葉面有中央淺折與少量放射淺脈，弧度約 0.001–0.004 m；黃綠受光面、橄欖內面、灰青陰面互相穿插。
- [ ] 葉片以 0.0002–0.0005 m厚薄片或雙面面片表示；葉叢根部插泥約 0.005–0.015 m，不能浮在礫石上。
- [ ] 少量葉片下垂貼近土或壓過小礫，讓石、土、葉有前後遮擋，而不是互不接觸的散件。

### 礫石、砂粒、泥土與沉積

- [ ] 礫石屬接地散件，與 A／B／C 三顆主石分開管理；不把前方礫塊計為第四顆主石。
- [ ] 大礫約 **12–18 顆**，長 0.025–0.070 m、寬約長度的 0.55–0.85、厚 0.012–0.035 m；前左、中央、右腳分成鬆散幾組。
- [ ] 中礫約 **35–60 顆**，長 0.010–0.030 m、厚 0.006–0.016 m；填在大礫之間，保留可見泥土空隙。
- [ ] 細礫約 **80–140 個可見點**，尺度 0.003–0.010 m；遠處或邊緣可用手繪／貼花表達，不必每粒建成高面數幾何。
- [ ] 更細砂粒約 0.0005–0.003 m，只作疏密變化與低對比筆觸；避免全畫面均勻鹽胡椒點。
- [ ] 大中礫的形狀包括壓扁卵形、偏圓三角形與不規則鈍角塊；多數經水磨圓，少數保留柔和小面，不出現長尖碎玻璃形。
- [ ] 大礫圓邊半徑約 0.002–0.008 m，中礫約 0.001–0.003 m；有一面較平並朝向地面，重量感自然。
- [ ] 礫色以暖灰和灰藍為主，少數灰米、赭灰、暗灰紫；每顆只用 2–4 個大色面，不加寫實石紋照片。
- [ ] 每顆可見礫石下部約四分之一至二分之一被泥覆住；長軸朝向略有變化，不能全部直立或等間距環繞。
- [ ] 主石根部、石間低谷與草叢旁的礫粒較密；外圍逐漸變小、變稀、露出更多泥色。
- [ ] 泥土主色為濕灰褐，約 #6D6251；稍乾外緣是灰赭米色，約 #94806A。紋理以不規則軟邊斑塊表達，不使用寫實掃描貼圖。
- [ ] 泥面主要凹凸約 0.001–0.004 m，局部堆積到 0.01 m；大型礫石腳周圍稍凹，泥脊順著受阻位置堆起。
- [ ] 外緣用 0.04–0.10 m寬的稀疏過渡區融入場景，不保留可見矩形透明片邊或厚邊框。
- [ ] 石腳局部苔與土交接要有幾處重疊：土蓋苔、苔覆小礫、草根藏在礫後；不是一層石、一層土、一層草的整齊水平分層。
- [ ] 沒有水面、積水鏡面、流動水網格或水花；溪邊感由濕痕、圓礫及植被表達。

## 優先級 4：近看才需要的磨邊、缺口與微小附著

- [ ] 三顆主石各保留約 3–6 個可辨識淺缺口，散在肩轉折、裂紋轉折附近與可見下緣；不要把每個筆觸都算成幾何缺口。
- [ ] 缺口長約 0.003–0.012 m、寬 0.002–0.008 m、凹深 0.0008–0.003 m；輪廓偏扁、不規則且磨圓，沒有剛炸裂的銳角。
- [ ] 缺口邊緣圓磨半徑約 0.0005–0.0015 m；淺迎光邊略暖亮，內面灰紫偏暗，底部可積少量灰褐土。
- [ ] 少量淺凹窩直徑約 0.002–0.006 m、深度小於 0.0015 m，放在局部色面中；避免石頭像火山浮石般滿面孔洞。
- [ ] 磨亮只是表面較淺、較平滑的短片，不提高到塑膠或濕鏡面光澤；磨耗依凸面與接觸位置，不能沿所有邊等寬描白。
- [ ] 裂縫內含少量暗土，尤其下段與苔蘚遮住之處；不在每條裂紋內長出厚苔條。
- [ ] 苔面可有約 0.001–0.003 m的小突起，以稀疏幾何、法線或筆觸完成；最小紋理不能在遠處形成雜訊閃爍。
- [ ] 蕨與草的乾尖是色相、捲曲與細薄邊的變化，不只把葉片最後一段塗成純黃色。
- [ ] 兩三片靠土葉可有少量灰褐髒邊；沒有大片蟲洞或枯爛黑斑，因參考沒有這些特徵。
- [ ] 石體沒有定向木質纖維；可讀的方向性只來自水磨圓肩、沿重力流下的淡水痕、苔蘚生長邊與葉片中軸。
- [ ] 檢查所有細小物體均有依附來源：苔附石、泥卡縫、根入土、葉接莖、莖接根、礫落地。禁止用漂浮色點代替立體附著。

## 製作整合與視覺驗收

- [ ] A、B、C 保持三個可辨識封閉石體；苔片、植被與礫土可分組，但層級命名只存在 Blender 物件資料中，畫面上不加文字。
- [ ] 將主形體與裂紋、苔蘚、乾濕遮罩分開控制；同一材質樣板可以共用，三顆石的遮罩分布必須獨立。
- [ ] 隱藏的石底簡化即可；可見輪廓、近距接觸與葉柄優先使用幾何，微小礦物點及大部分砂粒優先手繪。
- [ ] 接地土片若暫時隱藏，植物根部可以露出供檢查；最終場景仍須有土遮住根基，不把懸空根留作成品。
- [ ] 裂紋與苔斑跨 UV 接縫要連續；重複貼圖不能在三顆石正面出現同一塊斑點或相同裂線。
- [ ] 以柔和偏金的低角度晨光、寬柔補光檢視；陰影偏藍紫，石頭下方最暗處仍有色彩，不用純黑。
- [ ] 先在中性柔光確認材質，再在晨光看暖意；若只有加強金色燈光才看出黃化苔，需修正苔蘚底色。
- [ ] 參考背景的暖灰色與氛圍霧不屬於網格、貼圖邊框或土塊；孤立轉面展示不放場景霧。
- [ ] 正、右、背、頂四個檢查攝影機採正交投影及相同世界尺度；不要為填滿每格而對不同方向各自縮放模型。
- [ ] 5 m驗收：能辨識大石居後、兩小石在前；石頭圓潤、落地穩定、植物有疏密，整體是自然溪石而非發光法器。
- [ ] 5 m驗收：黃綠苔蘚形成幾處柔和重點，裂縫不發光搶眼，微小石粒與礦物點不形成噪聲。
- [ ] 1 m驗收：能分清乾暖灰石、濕暗面、橄欖苔、乾黃苔、羽狀蕨、帶狀草與圓葉地被；同一位置有合理前後關係。
- [ ] 1 m驗收：每石 1–2 條細裂、少量圓磨缺口、下緣泥漬、局部黃化帶皆存在，但仍需仔細看才察覺裂縫中的琥珀暖色。
- [ ] 俯視與背面驗收：沒有多出主石、移動植物根冠、重複裂紋、破碎輪廓或對稱複製；四向確實是同一組物件。
- [ ] 交付前核對主石完整尺寸 0.90 × 0.72 × 0.60 m及半埋約定；大尺寸先正確，微細缺口不得反過來改變主輪廓。

## 最容易被做丟的細節

- [ ] **三顆不同的卵形輪廓**：左小石與右小石不是鏡射縮放；主石有偏心圓冠、寬前腹與不同肩坡。
- [ ] **半埋的重量感**：圓石在泥下延續，土礫頂住腳邊；不能做成平切石塊擺在薄板上。
- [ ] **潮濕與微暖同時存在**：下部濕暗、頂部偏乾，苔蘚只局部黃化；不是全石烘乾或全表面等濕。
- [ ] **黃化是一條破碎的小帶**：有灰綠、赭黃、乾尖與露土缺口，不是全局黃色覆蓋或規則光環。
- [ ] **髮絲裂紋的收尾與遮擋**：細、短、局部被苔與土遮住，琥珀色幾乎不可見，不能變成亮金深槽。
- [ ] **裸石留白**：苔蘚、礦物點和細碎筆觸都有空白區；程式隨機散佈最容易把整塊石頭填滿。
- [ ] **植物的連接鏈**：羽片接中軸、草葉收進葉鞘、葉柄接根冠、根入土；不是漂浮的綠色面片。
- [ ] **三種植物的差異**：羽狀小蕨、長帶狀草與低矮圓葉地被各有尺度、姿態及生長位置。
- [ ] **石間的細土與深色濕苔**：夾縫不是空黑洞，也不是硬性接縫；內部有潮濕填料和根部。
- [ ] **磨耗有方向與位置**：圓肩變淺、凹縫留暗、淡水痕往下走，不能一鍵沿所有邊描亮。
- [ ] **礫石有埋深、平面朝向與尺寸層級**：少量大礫、更多中礫、細砂用色；避免平均大小的漂浮石子。
- [ ] **手繪石面不是低多邊形雕刻**：角狀色筆觸應大多留在貼圖，外輪廓持續圓滑，光影保持柔和。
