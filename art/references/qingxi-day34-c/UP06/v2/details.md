# UP06 第二版：手提竹竿紙燈建模勾選清單

本資產採用 **UP06-v2-cand-4.png**，並對照 **UP06-v2-turnaround.png** 與 **UP06-v2-details.png**。用途為 Blender 製作的未點亮手持紙燈；所有長度、厚度、直徑、縫寬、倒角與位置均以 **公尺（m）** 表示。角度另以度標示。

只有竹竿約 0.900 m、燈體約高 0.300 m、寬 0.150 m 來自原提示；其餘數值是依這三個尺寸推定的建模建議，不是實物測量。清單先處理距離 5 m 的剪影與明暗，再處理距離 1 m 的結構、材料及磨耗。

- [ ] 尺寸衝突時採用本清單的公尺數值；造型與配色以候選 4 為主；接合與表面以六格細節圖補充。不可把生成圖像素當成已校準工程尺規。

- [ ] 細節圖是放大觀察，木蓋厚度、木紋起伏、紙纖維及補綴的厚度不可按畫面放大比例直接建模。

## 2．1 m 先看：紙罩形體與六根竹肋

### 2.1 紙罩的形與固定

- [ ] 紙罩以一張環繞式楮皮紙外皮形成，分出六個肋間面區；不是六塊帶厚接縫的玻璃窗。背面保留一條主要縱向搭接縫。
- [ ] 形體剖面參考：Z = 0.036 時外半徑約 0.047；Z = 0.065 約 0.060；Z = 0.110 約 0.071；Z = 0.155 約 0.075；Z = 0.215 約 0.071；Z = 0.252 約 0.059；Z = 0.277 約 0.043。這些半徑包含附近肋條的外廓，紙面可內退 0.001–0.002。
- [ ] 肋間紙面只有約 0.001–0.003 的柔和鼓度變化；縱向輪廓平滑，避免把所有皺褶都做成凹凸輪廓。
- [ ] 紙厚約 0.0002–0.0004；翻邊與補紙能看出薄度。厚度不應像布毯、皮革或厚紙板。
- [ ] 紙上沿伸入木頂蓋下緣約 0.003–0.005，在竹肋與木領之間被壓住；露出的壓痕沿邊形成一圈很細的暖灰暗線。
- [ ] 紙下沿向內折回約 0.004–0.006，包住底部竹箍的內側或上側後黏接。折紙與箍之間不得有可看穿的大空隙。
- [ ] 紙與竹肋以極薄糊料貼合，接觸線連續但不畫成黑色膠條；膠痕僅在局部約 0.001–0.002 寬處略偏黃。
- [ ] 紙罩內部為空腔。沒有圖像依據的蠟燭、燭臺、燈芯、電線與燈泡不列入可見資產；必要內側封面只延續既有紙、木結構。

### 2.2 縱向竹肋

- [ ] 建立 **6 根**完整竹肋，每隔 60° 一根，環繞 Z 軸。為對應候選正面兩條內側肋，先將肋角設為 0°、60°、120°、180°、240°、300°，0° 朝 +X。
- [ ] 同一角位由底箍一路連到頂蓋，不在正面、側面或頂面另外新增肋。頂視生成圖的肋角若稍有偏移，以此固定角位為準。
- [ ] 每根沿曲面弧長約 0.260–0.275，寬 0.0035–0.0045、厚 0.0015–0.0022；截面為稍扁的圓角長方形，外面略凸、內側較平。
- [ ] 竹肋兩側倒圓約 0.0003–0.0006，不能做成刀鋒，也不能圓成等粗竹棍。
- [ ] 上端最後約 0.005–0.008 收窄，進入木蓋下緣的淺槽；下端最後約 0.006–0.009 靠在底箍外側並綁固。
- [ ] 每根竹肋保留約 **3 處**低矮竹節／節痕，分布在下肩、中段、上肩附近；六根不必完全同高。節痕寬 0.0015–0.0025，凸起 0.0003–0.0007。
- [ ] 不把每一條明暗細線都當成竹節或金屬套；局部竹節與細綁線必須可區別。
- [ ] 六根竹肋形狀略有手工差異，局部偏移約 0.0005–0.0015 即可；整體仍支撐規整外形，不能扭曲成六種不同燈罩。
- [ ] 每根肋的亮面沿長軸延伸；纖維紋也沿肋彎曲走向，不橫著跨過竹肋。
- [ ] 上下各 **6 組**細綁固結，共 **12 組**：細麻線直徑約 0.0007–0.0010；單結外廓約 0.003–0.006。只在接點纏繞，不沿整根竹肋做密集螺旋。
- [ ] 底部可見綁法採兩道交叉線壓住竹肋，再繞到底箍內側打結；線的下方壓痕約 0.0002–0.0004，線不能穿入木座後無故消失。

## 3．1 m 的使用與承重結構：竹竿、握把、吊接

### 3.1 竹竿本體

- [ ] 竹竿 **1 根**，中心線長 0.900；裸竿大致直徑 0.018，往左端可略收至 0.017，握把側可略增至 0.021。
- [ ] 主軸為 X；可有總振幅約 0.003–0.006 的柔和天然彎曲。正交對照與裝配時仍以中心軸 Z = 0.400 為基準，不做明顯弓形。
- [ ] 可見自然竹節固定為約 **5 道**，建議 X 約 −0.340、−0.110、+0.140、+0.400、+0.525；可在上述位置附近調整 0.010，避免等距機械複製感。
- [ ] 竹節比相鄰桿身凸約 0.0006–0.0012，沿軸寬約 0.003–0.006；節兩側有收頸，不能只是套上粗圓環。
- [ ] 兩個端部均為自然截斷竹材，切口倒角約 0.0005–0.0010。端緣不添加黃銅帽或金屬裝飾。
- [ ] 竿端可見較深的節隔／淺凹端面，凹深約 0.001–0.002，外圍保留纖維邊；它不是通往無限黑洞的管口。
- [ ] 兩端各保留 **1 圈**較窄的天然節緣，屬竹材本身，和五道主節的造型協調；不要誤建成可拆金屬套件。
- [ ] 竹皮底色為蜂蜜金褐，受摩擦處偏淺麥色，凹側偏灰橄欖褐；青綠只作非常微弱的舊竹底色。
- [ ] 長纖維沿 X 軸；局部剝皮長約 0.010–0.035、寬 0.001–0.004，露出較淡竹肉；總量少，不做滿身剝落。
- [ ] 保留約 **3–5 處**低對比縱裂與小擦痕，長 0.008–0.030、寬 0.0002–0.0006，深度以材質／法線為主，集中在端部、節旁、握把相鄰裸露位置。
- [ ] 磨耗方向以沿竹竿長軸為主，竹節最高點有短弧形擦亮；不能使用隨機全方向金屬刮痕。

### 3.2 布握把

- [ ] 握把為 **1 條**舊灰褐布帶螺旋包覆成的一段，包覆範圍 X = +0.180–+0.370。它是纖維布，不是皮革、橡膠或金屬彈簧。
- [ ] 布帶原寬約 0.018–0.023、厚約 0.0005–0.0008；展開總長可估約 0.85–1.00。完成包覆後沿軸可讀出約 **13–15 道**斜向交疊。
- [ ] 相鄰布圈重疊約 0.004–0.007，邊緣凸起約 0.0005–0.0010；不是每圈都相同高度與斜率。
- [ ] 中央常握區略壓扁，包覆半徑縮小約 0.0005–0.0010；外層緊貼竹竿，不能像鬆動套筒。
- [ ] 握把兩端各 **1 組**細麻繩收口，每組約兩圈；繩徑約 0.0015–0.0020，結頭藏於下側。布帶頭尾各壓回前一圈下面約 0.008–0.012。
- [ ] 在最外層邊緣保留約 **4–7 處**小毛邊／缺口，長 0.002–0.007、寬 0.001–0.003；最長鬆纖維不超過 0.004。
- [ ] 中段手掌接觸區呈暖灰褐汗漬，跨度約 0.070–0.110；中央稍暗、凸脊被磨成較淡灰米色，光澤仍低。
- [ ] 布的經緯只在近看以柔和小筆觸暗示；粗織紋尺度約 0.0003–0.0007。不要把噪點鋪滿整段。
- [ ] 保留沿纏繞斜線的摺痕與局部縱向磨平區。沒有長垂帶、腕繩或流蘇；這些屬其他候選的設計，不移入選定模型。

### 3.3 竹竿上的主吊結

- [ ] 主吊點以 X = 0、Y = 0 為中心；承重順序必須連續為：竹竿 → 纏繩 → 下垂短環 → 鐵環 → 四腿吊繩 → 木蓋 → 六根竹肋 → 底箍與木座。
- [ ] 主纏繩 **1 組**，軸向占寬約 0.036–0.045；繩徑約 0.0025–0.0030，約 **5–7 圈**主繞線，含交叉壓線及下側收結。
- [ ] 主繩採三股捻合外觀；股線斜向節律間距約 0.004–0.007，保持不均勻但緊實。顏色為舊麻纖維的黃赭灰褐。
- [ ] 主繩貼住竿面，圓周接觸處略扁；外側最高點更淡，凹股處較深，不使用純黑溝紋。
- [ ] 主吊結下方留 **1 個**雙股短繩環穿過金屬環上半部，外露高約 0.014–0.020、寬約 0.007–0.010；收結外廓約 0.008–0.012。
- [ ] 繩端僅留 **1–2 段**短尾，各長約 0.004–0.009，貼近結頭；沒有額外裝飾鬚。
- [ ] 竹竿被纏繩覆蓋處稍暗，僅在繩邊露出寬約 0.001–0.003 的積垢或磨痕，不在繩上長青苔。

### 3.4 小鐵環與四腿吊繩

- [ ] 金屬環 **1 個**，外徑約 0.016、線徑約 0.003、內孔約 0.010；微橢圓也可，但不可放大成主視覺裝飾。
- [ ] 環大致在垂直平面，中心約 Z = 0.366；上下繩實際穿過內孔並壓到環的內側承重弧，不以表面貼靠假裝相連。
- [ ] 鐵環為暗灰藍舊鐵，表面有非常薄的褐色氧化斑；局部高點磨成較淡冷灰，沒有亮鉻、鏡面或大塊紅鏽。
- [ ] 鐵環可見一處低矮鍛接／收口痕，長約 0.002–0.003，隆起不超過 0.0003；是否保留可視角度依模型而定，不製造未閉合的大缺口。
- [ ] 吊繩固定為 **4 條承重腿**，可由兩條連續繩折返形成；每腿直徑約 0.0022，從環下緣至木蓋固定點的露出長約 0.075–0.085。
- [ ] 四個下端固定於木蓋圓周的前、後、左、右，半徑約 0.040–0.042、高度約 Z = 0.290；承重腿在空中保持繃直，只有小幅纖維起伏。
- [ ] 每個下端穿過木蓋邊上的孔／短槽後回折，形成 **4 組**小繩結。回折長約 0.006–0.010，結外廓約 0.004–0.007；後側結即使被遮住也要存在。
- [ ] 四個木蓋吊孔直徑約 0.0030–0.0035，孔邊圓滑，倒角約 0.0004–0.0006；與下方竹肋槽錯開高度，不讓槽孔打穿整條薄木邊。
- [ ] 繩材與主結同屬麻繩，但吊繩更細；股線節律約 0.003–0.005，最外細毛以材質為主，個別突出長不超過 0.0015。
- [ ] 不把視圖中重疊的繩腿合併成少一條繩；也不為了每個角度都有三角形而新增第五、第六條。

## 4．1 m 的深色結構重點：木頂蓋、底箍、木座

### 4.1 頂蓋與低圓拱

- [ ] 頂蓋總成分成 **1 個環形木領＋1 片低拱木蓋**；圖中的橫向深線是接縫／磨損，不解讀為多層屋簷。
- [ ] 環形木領外徑約 0.090、內徑約 0.076–0.078；高約 0.018，位於 Z = 0.276–0.294。壁厚約 0.006–0.007。
- [ ] 木領側面上、下緣各有一道淺退階或壓線，退入約 0.0008–0.0012，高約 0.002–0.003；整體仍是小而緊湊的木圈。
- [ ] 上蓋盤直徑約 0.082–0.086，邊厚約 0.003–0.004，中央拱起約 0.006；最高點 Z = 0.300。沒有尖頂、寶珠或中央高柱。
- [ ] 上蓋盤的薄企口壓入木領內緣約 0.002–0.003；接縫寬約 0.0003–0.0006。這是為遮蔽接合指定的建模做法，圖像未提供可拆裝機構證據。
