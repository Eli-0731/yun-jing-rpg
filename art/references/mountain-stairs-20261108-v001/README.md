- 03：兩側側欄的頂石順坡、柱孔在頂上，側面青灰整砌，最像山城的正式石階。

## SG02-LANDING｜轉折平台 → 暫選 01

- 01：外圍一圈收邊石，中間 3 × 3 大石板，角落一座蓮瓣圓燈座，好讀也好接。

## SG03-BALUSTRADE｜石欄杆套件 → 暫選 01，端柱帽參考 04

- 01：圓的尋杖扶手、兩端小托墩、下方浮雕框石板（華板），是中式石欄杆的典型做法。
- 02：一排寶瓶柱，偏西式，不選。
- 03：鏤空回紋板很好看，但細格多、手機上成本高，遠看也容易糊。
- 04：粗扶手配矮墩，太簡單；但雲紋柱帽合工作包「端柱有簡單雲捲帽」，借到 01 的端柱上。

- 03：木構架，太像木亭。
- 04：翹角木構，像小廟，跟 TE05 太接近。
