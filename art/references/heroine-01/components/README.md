三張圖都要求正面、嚴格左側與背面同尺度、灰底、柔和棚燈，不加入新角色或新配色。頭部圖刻意去掉頭髮，髮型圖刻意挖空臉部；身體圖使用無臉人台，這些空白只為方便分件建模。AI 對被頭髮遮住的頭顱、衣服內部結構、鞋底、頭飾固定件及側背刺繡做了推定；建模時若與原圖衝突，以原圖為準。髮型圖側面的一縷前髮與原圖的長度可能不一致，不能直接當作尺寸定稿。

## 生成提示重點

1. 身體：以原圖為唯一造型基準；產生無頭衣裝的正、嚴格左側、背面；保留藍白交領、青藍腰封、流蘇、半透明花紋長袖、白色中裙、藍色外裙及鞋；底部拆出袖、腰、裙、鞋局部。
2. 頭部：以原圖臉型為基準；產生無髮、無髮飾、無衣的正、嚴格左側、背面頭頸，保持眼、耳、頜的位置可供雕刻。
3. 頭髮：以原圖黑色半盤長髮為基準；產生無臉、無身體的正、嚴格左側、背面髮型；保留銀葉藍花、珠鏈、青藍流蘇及後方長緞帶。

下一步建模應先確認頭與髮的相同尺度及扣合位置，再分別建立頭模、髮束、衣裝。整合後須與來源圖並排驗收正面及側面輪廓，不能因為三張拆件圖分別漂亮就宣稱角色已完成。
