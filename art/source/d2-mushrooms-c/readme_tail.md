## v001 視覺檢查紀錄（DP01）

灰模三輪、上貼圖後兩輪，每輪看同樣的角度，先修最嚴重的：
1. 灰模第一輪：傘太扁，像一片片圓餅 → 改成有厚度的傘；DP01_04 的柄擠成一束、傘疊在一起、木片是方盒 → 柄往外彎、木片改成不規則的片；DP01_03 太小太細 → 傘和柄放大。
2. 灰模第二、三輪：DP01_04 的幼菇脹成球、四朵大的都在同一邊 → 幼菇縮小、大的分到四個方向。
3. 上貼圖第一輪（和 D2 並排）：傘是尖的斗笠形，D2 是寬的扁平微凸 → 改成低圓頂加中間小隆起；傘上白斑太多太大 → 減成幾點小斑；苔墊太亮太綠、太高 → 改暗橄欖綠、壓低。
4. 上貼圖第二輪：傘緣看得出多邊形 → DP01_01、DP01_02 的傘段數加多（面數還在 4,000 內）；柄像淺色塑膠 → 改成灰褐、加深色纖維紋；DP01_04 的木片像一塊亮橘色木板 → 改成暗、濕、有剝落的朽木。

**v001 自評：和 D2 設定圖並排約 65–70% 像，還沒到 85–90%。** 傘的顏色、形狀、淺色傘緣、細長柄和成叢的樣子對得上；差的是：
- 設定圖的蕈長在根、苔、蕨、落葉中間，單件放在空地上看比較「乾淨」；整合時和根、苔、蕨擺在一起才是設定圖的樣子（DP05 的擺放示範會做這件事）。
- 小傘（DP01_03 兩端、DP01_04）段數少，近看傘緣有稜角；DP01_04 的朽木片還是低面數的稜面。
- 菌褶從上往下看不到，只有蹲低的鏡位看得到（D2 V6 也是蹲低才看得到）。

## DP05 蕈叢擺放示範

工作包要在 Josh 的 DR08 朽木（或任一段倒木）上擺一組 DP01–DP04，給整合時照抄。DR08 還沒做，所以用 main 上已有的 **DR06_FallenTrunk_A**（`art/exports/d2-logs-b/`）中段 x 1.6–3.9 m 這一段。這不是新模型，所以沒有三視圖，也不另外匯出 FBX。

- **座標**：`art/exports/d2-mushrooms-c/DP05_placement.json`。十三件，每件寫明用哪個 GLB／FBX、位置（m）、旋轉（XYZ 歐拉角和四元數），座標是 DR06_FallenTrunk_A 自己的資產座標（它的原點、z 朝上、Blender 軸向）。整合時把這些件掛在已擺好的那根倒木底下即可。
- **擺法**：根腳一排褐蕈（DP01_03）、兩叢褐蕈（DP01_01、DP01_02）、淡水青三朵（DP02_02）和黏菌（DP04_02）沿著倒木前面的根腳；朽木段上的白蕈（DP02_03）在前面地上；簇生褐蕈（DP01_04）、白蕈（DP02_01）、小菇（DP04_01）和苔枝（DP04_03）在倒木頂上；三種層狀菌（DP03）貼在倒木前側。每件都用射線放到表面上，照表面坡度傾斜，不會浮空；DP03 的樹皮板背面壓進樹皮 8 mm。
- **重做**：`blender -b --factory-startup -P art/source/d2-mushrooms-c/place_dp05.py -- --log <DR06_FallenTrunk_A_v001.glb>`，再跑 `python art/source/d2-mushrooms-c/compose_dp05.py <放 D2 V6.png 的資料夾>` 出總表。DR06 的檔案從 main 取（LFS），沒有複製進這個套件。
- **審圖**：`art/previews/d2-mushrooms-c/DP05/`，全景、斜看、倒木頂上、蹲低、俯視，以及和 V6 倒木並排的 `DP05-sheet.jpg`。

**自評：擺法和 V6 右側那段長苔倒木的「根腳白蕈、苔上小點綴」對得上，約 60%。** 差的是：
- 審圖用的地面和光比 D2 單調，V6 倒木旁還有蕨、石頭、心形小葉，這裡只有 DR06 自己帶的植物。
- DP03 的樹皮板比 DR06 的樹皮亮、板子的邊看得出來；整合時要挑樹皮接近的地方，或請核心組統一樹皮顏色。
- 沒在 Unity 裡擺過，也沒放進正式 D2 場景。
