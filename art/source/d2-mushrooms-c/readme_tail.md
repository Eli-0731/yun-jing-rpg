## v001 視覺檢查紀錄（DP01）

灰模三輪、上貼圖後兩輪，每輪看同樣的角度，先修最嚴重的：
1. 灰模第一輪：傘太扁，像一片片圓餅 → 改成有厚度的傘；DP01_04 的柄擠成一束、傘疊在一起、木片是方盒 → 柄往外彎、木片改成不規則的片；DP01_03 太小太細 → 傘和柄放大。
2. 灰模第二、三輪：DP01_04 的幼菇脹成球、四朵大的都在同一邊 → 幼菇縮小、大的分到四個方向。
3. 上貼圖第一輪（和 D2 並排）：傘是尖的斗笠形，D2 是寬的扁平微凸 → 改成低圓頂加中間小隆起；傘上白斑太多太大 → 減成幾點小斑；苔墊太亮太綠、太高 → 改暗橄欖綠、壓低。
4. 上貼圖第二輪：傘緣看得出多邊形 → DP01_01、DP01_02 的傘段數加多（面數還在 4,000 內）；柄像淺色塑膠 → 改成灰褐、加深色纖維紋；DP01_04 的木片像一塊亮橘色木板 → 改成暗、濕、有剝落的朽木。

**v001 自評：和 D2 設定圖並排約 65–70% 像，還沒到 85–90%。** 傘的顏色、形狀、淺色傘緣、細長柄和成叢的樣子對得上；差的是：
- 設定圖的蕈長在根、苔、蕨、落葉中間，單件放在空地上看比較「乾淨」；整合時和根、苔、蕨擺在一起才是設定圖的樣子（DP05 的擺放示範會做這件事）。
- 小傘（DP01_03 兩端、DP01_04）段數少，近看傘緣有稜角；DP01_04 的朽木片還是低面數的稜面。
- 菌褶從上往下看不到，只有蹲低的鏡位看得到（D2 V6 也是蹲低才看得到）。

## DP02 白色小蕈叢 v001

**驗證**
- QA 嚴格、寬鬆都是 0／0（三件）；接觸檢查最大間隙 1.3 mm（DP02_03 朽木段的底）。報告在 `art/previews/d2-mushrooms-c/qa/`。
- Unity 6000.3.28f1 獨立匯入：DP01 和 DP02 一起跑，112 項 PASS、0 項 FAIL（`art/previews/d2-mushrooms-c/unity/report.txt`）。
- D2 對圖：`art/previews/d2-mushrooms-c/<ID>/d2/<ID>-d2-compare.jpg`，設定圖裁切（V6 石邊苔上的白蕈、朽木旁淡色三朵）、成品眼高 1.6 m、蹲低 0.6 m。

**視覺檢查紀錄**（灰模三輪、上貼圖三輪）
1. 灰模第一輪：傘太扁太小 → 傘加大、加厚、傘緣往下垂；朽木段兩端是尖齒、面很硬 → 斷口改成不規則但不尖，段數加多、平滑著色。
2. 灰模第二輪：傘變成尖錐 → 改成圓頂；朽木頂上苔和木頭交界有一道縫 → 苔改成蓋在木頭上的一層薄殼（離木面 5 mm，邊緣收進木頭裡，不共面）。
3. 上貼圖第一輪（和 D2 並排）：傘偏灰、柄太細 → 改暖象牙白、柄加粗；DP02_02 太灰、溝紋太黑像斑馬紋 → 加淡水青色、溝紋只留在法線上；朽木段像一個亮面深褐木桶 → 改成灰褐、有深裂紋的樹皮，木上的蕈加大。
4. 上貼圖第二、三輪：朽木頂上的苔像一塊平布 → 苔的邊緣不規則、往兩側垂下，表面有起伏；樹皮裂紋加深。

**自評：和 D2 設定圖並排約 65% 像。** 對得上：象牙白微凸的傘、高低錯落的成叢、DP02_02 的淡水青色。差的是：
- V6 那三朵淡色蕈是微微發光的；這裡只照顏色，不做發光（共同標準的材質沒有自發光，要不要發光留給整合時決定）。
- V6 的白蕈傘面有濕潤的光澤、菌褶更密；成品近看比較乾。
- DP02_03 朽木段的斷口還是低面數的稜面，苔的邊緣有一點厚度。

**已知問題與未驗**
- 工作包寫「擺幾處 18」，這裡只交三種模型，擺放由核心組做。
- 正式場景擺放、手機上的效果都未驗；不寫幀率。
