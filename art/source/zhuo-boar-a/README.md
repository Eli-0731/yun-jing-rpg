# 第 3 天模型：濁化山豬 BR01、會被撞歪的小松 BR02

依工作包 `docs/execution/2026-11-02/01-A-day3-zhuo-boar.md` 和美術風格指南。全部是原創程序建模，沒有第三方網格或貼圖。

**流程**：工作包提示詞＋風格指南 5.2／5.3 → 每件 4 張三視圖 → 挑圖存進 `art/references/` → 建模。

| 編號 | 選中 | 為什麼 |
|---|---|---|
| `BR01` | #2 | 比例最接近規格，濁氣紋路像墨滲進毛裡，不像魔物 |
| `BR01_clean` | #2 | 和濁化版同一隻的樣子，當 `_Zhuo = 0` 的參考 |
| `BR02` | #2 | 樹冠不規則，基部有被撞掉的淺色傷痕 |

使用者另外給了 [3D66 的野豬模型列表](https://m.3d66.com/collection-3d/yezhu.html) 當形體參考。那是別人的商品，我只看縮圖的比例（前重後輕、腰腹上收、下腿細、頭是長楔形、耳朵大），沒有下載，也沒有用它的網格或貼圖。

## 重建

```powershell
blender -b --python-exit-code 1 --python art/source/zhuo-boar-a/build_boar.py
blender -b --python-exit-code 1 --python art/source/zhuo-boar-a/build_pine.py -- A
blender -b --python-exit-code 1 --python art/source/zhuo-boar-a/build_pine.py -- B
blender -b --python-exit-code 1 --python art/source/zhuo-boar-a/review.py -- boar
```

審圖燈光用 Poly Haven 的 HDRI（CC0），不在倉庫內，路徑可用 `YJ_HDRI` 指定。

## 怎麼做的

**BR01**：軀幹斷面、四肢、肌肉塊先合成一張皮（體素重建），再壓出嘴線、眼窩、鼻孔和泥塊，然後減面。貼圖從程序材質烘到一張 2048 的圖。毛是兩層：貼著皮、順毛流排列的扇形毛束，靠第二組 UV 和 `T_BR01_ZhuoBoar_Fur.png` 的透明通道切出一根根的毛；加上肚子、臉頰和背脊上立體的鬃毛。毛直接取皮的貼圖，不佔貼圖空間，根暗梢亮的漸層存在頂點色。

**`_Zhuo`**：Unity 材質 `YunJing/QingxiZhuoBoar`，遮罩 R 是濁氣紋路（沿毛流拉長的分岔線條，周圍有墨的暈染）、G 是眼睛（紅色眼珠）。`_Zhuo` 從 1 降到 0 時，紋路往最深的地方退，最後消失。不另做網格。

**骨架**：`Root` 加 24 骨（脊椎 4、頸 2、頭、下顎、耳 2、尾 2、四腳各 3），命名沿用山兔 v003，左右是動物自己的左右。

| 動畫 | 幀（30 fps） | 循環 | 內容 |
|---|---|---|---|
| `Idle` | 60 | 是 | 呼吸、耳朵抖 |
| `Paw` | 36 | 播一次 1.2 秒 | 低頭、重心後移、前蹄扒地兩下 |
| `Charge` | 17 | 是 | 衝撞，頭低耳朵向後 |
| `Daze` | 75 | 是 | 搖頭、站不穩、腳踉蹌 |
| `Cleanse` | 60 | 否 | 縮著 → 站直 → 甩頭 → 耳朵豎起 |
| `Flee` | 21 | 是 | 頭抬高、尾巴翹起的跑 |

動畫都在原地，移動由遊戲控制。製作時腳用 IK，匯出前烘成一般關鍵幀；IK 控制骨不匯出。

**BR02**：兩棵不同的樹，不是旋轉同一棵：A 傾斜、分枝低而長；B 分枝高、樹冠較圓、下半段光禿。原點在樹根，遊戲旋轉物件就能歪 8°。`_Scar` 打開基部的淺色傷痕，傷痕繞樹幹大半圈，所以從哪邊撞都看得到。

## 已知缺項

- 耳朵沒有毛，只有貼圖（試過，邊緣會參差且取到雜色，拿掉了）。
- **透明裁切**：毛束用 alpha clip，手機上比不透明貴，要實測。用一般材質開 GLB 看不到裁切，毛束會是實心的扇形。
- 濁氣紋路仍是程序產生的，不是手繪；照著毛流走，但線條的設計感還比不上手繪。
- 腿在 `Charge` 時沒有真實的腳步對位，因為衝撞速度比步幅快很多。
- 手機效能沒有實測。山豬和三棵小松同時在畫面上時面數不低，靠 LOD 切換；切換距離要在手機上調。
