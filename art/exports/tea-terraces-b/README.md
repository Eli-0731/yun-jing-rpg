# B｜48 小時：東坡茶田（第一批）— TE01 梯田／TE02 茶樹／TE03 步道

槽位 `A4_TeaTerraces`。12 件素材，全部以 Blender 5.2.2 程序化建模（腳本可重跑），在 Blender 與 Unity 6000.0.85f1（URP）中驗證。
本批只交付模型與驗證，**沒有改主場景、沒有宣稱正式落位**；40×40 m 組裝只是樣本。

## 共同風格三點

1. **暖灰乾砌石＋暖褐土**：石材統一為暖灰田石（壓頂石稍淺），土面是暖褐色、帶土塊和落葉，
   不用純黑陰影，石縫填土。茶樹葉用黃綠（嫩梢）到青綠（老葉）。
2. **大色塊、少量細節**：材質以大面積柔和漸層為主，少量刷痕；細節（小石、草、苔）只放在合理的位置，不鋪滿。
3. **只在該舊的地方舊**：苔蘚只在背陰石縫和步石邊緣；草沿牆腳、路緣、步石邊稀疏生長；崩塌段露出新土和散落石塊，
   其他部位保持有人在照顧的茶田樣子。

## 尺寸衝突（依 ID 列出，未自行改規格）

- **TE01_InnerBend、TE01_OuterBend**：工作包寫「8×4 m」，但 90° 轉角要在兩個方向都接上 4 m 深的直段，實際是 **8×8 m**。
- **TE01 全系列高度**：牆高 1.0 m（每階 1 m，落在 0.8–1.2 m 內）；壓頂石與草葉讓包圍盒到 1.25–1.28 m，可走的土面在 z = 1.0。
- **TE03_Stair**：可走寬度 1.2 m，但兩側砌石與草讓整體寬 **1.32 m**、長 2.6 m（6 階，每階高 1/6 m、深 0.40 m）。
- **TE03_Path**：工作包只規定寬 1.2 m，長度自訂為 **4.0 m**（直段兩件接一個 8 m 梯田）。
- **TE03_Stepping**：長度自訂為 **2.0 m**，四塊步石，步距 0.4–0.7 m。

## 驗證標記

每件都標四級：**Exported**（Blender 匯出）／**Imported**（Unity 匯入）／**Visually Verified**（看過渲染與 Unity 截圖）／**In-game Verified**。

- 12 件全部 **Exported、Imported、Visually Verified**。
- **In-game Verified：否**。Unity 檢查是編輯器批次模式下的自動測試（CharacterController 走路、接縫射線、碰撞），不是實際遊戲流程，也沒有放進主場景。
- 不宣稱任何行動裝置 FPS；沒有做效能量測。

## Blender 檢查（每件 `validation.json`，全部 all_pass = true）

- 尺寸與包圍盒、底部 z = 0、FBX 回匯尺寸誤差（最大約 0.02 mm，要求 ≤ 2 cm）、LOD0/1/2 存在、LOD 比例約 50%／15%、碰撞、插槽、GLB、十方位。
- TE01：接縫面 ≤ 2 mm、土面可走、排水口。
- TE02：寬 1.2 m、高 0.8–1.1 m、葉片卡 alpha 裁切雙面、Wind 頂點色、嫩梢卡、木質主幹。
- TE03：踏階高度 1/6 m ±2 cm、每階 < 0.2 m、頂階接上層土面 z = 1；步道兩端截面一致 ≤ 2 mm；步石步距 0.4–0.7 m。

## Unity 檢查（TeaTerracesModelCheck，157 PASS／0 FAIL）

- 每件：尺寸、原點、底部、LOD 三角面數等於 model_info、MeshCollider、無錯誤著色器、Wind 頂點色、插槽。
- 組裝：9 排 × 4 條接縫線＋2 個轉角接縫，射線量測 ≤ 2 mm、無破洞。
- 行走（半徑 0.3、高 1.75、stepOffset 0.3、slopeLimit 45）：三排步道、崩塌段、從前緣一路爬上 9 座石階到第 8 排（終點 z = 9.0）、下 3 座石階、
  三種端頭（含鏡像）、步石、碰到茶樹會停下、內外轉角。另檢查每 0.3 m 水平移動內腳底下降 ≤ 0.25 m、上升 ≤ stepOffset（防止掉下牆或爬牆）。
  爬階路線會經過第 1 排崩塌段，該處土坡局部約 41°，低於 45° 坡度上限，所以上升上限用 stepOffset（0.3 m）而不是 0.25 m。
- 閃爍（靜止鏡頭 A-B-A 畫素差）：接縫 ≈ 0.13%、石階 ≈ 0.30%、茶樹 ≈ 0.26% 畫素。接縫處最低，沒有 z-fighting 的跡象；
  石階與茶樹的數值推測來自陰影與 alpha 裁切的取樣雜訊，**未進一步確認**。
