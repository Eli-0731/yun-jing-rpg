# GR01／GR04 地形材質

GR01 是古林與溪邊苔地；GR04 是田邊與水邊的濕泥地。兩張來源圖以內建 AI 生圖製作，原尺寸保存於 `art/references/ground-textures-v1/`。GR01 指定灰綠苔、少量碎葉與石粒；GR04 指定偏暗的濕土、細淤泥與少量石粒。兩者都要求正上方視角、均勻密度、無方向性照明或文字。

每種交付 2048 × 2048 的 `Albedo`、`Normal`、`MaskURP` 和 2 × 2 平鋪預覽。遮罩通道：R 金屬度為 0；G 為遮蔽；B 細節遮罩為 1；A 為平滑度。法線由色彩亮度梯度推導，不是高模烘焙，因此深度只供中距離地面使用。

三張貼圖的左右與上下邊界逐通道差值均為 0。2 × 2 預覽可見素材內部的大型明暗圖樣在重複，因此建議 Unity Terrain 以旋轉或交錯比例混用，不能只靠此單層覆蓋大片地面。尚未在 Unity 6000.3.28f1 驗證匯入色彩空間、法線方向及實際 4 m 尺度。
