# 林下植物（undergrowth-c）

11/14 的 120 小時包 B 批：D2 林下（設定圖 V2、V3、V6），也用在 D1、A1 院子。SH01 先交樣品；SH02、SP01、UG01–UG06 照「不等審查先做完」先做完，審查意見回來再改。靜態擺設；擺進世界由核心組做，這裡不改主場景、不改區塊 JSON。

**共同做法**
- 先生成三視圖（每件 4 張）、自評選一張（分數和取捨在 `prompt.txt`），再做灰模（`art/previews/undergrowth-c/<ID>/clay/`），最後上貼圖。
- 照指南的順序：先定三面剪影和幹，再分次枝、細枝（三級粗細），最後才排葉子；葉子是五頂點的立體葉，一片片沿枝排，不用葉片卡、不用葉團圖集、不在球裡撒葉，不鏡像。
- 原點在幹基或根冠中心的地面（z = 0），Blender −Y 是正面（FBX／Unity 是 −Z）；SH01、SH02 的幹往地下延伸 0.18 m，SP01 往地下 0.3 m，UG01–UG04 的根冠往地下 6–9 cm。UG05 落葉堆原點在底面中心；UG06 原點在根頂的那條線上（見各件）。
- **UG 的葉子**：每片葉照自己的輪廓切網格（心形、掌狀深裂、舌狀長條、花瓣、卵形和裂葉的落葉，輪廓寫在 `ug_shapes.py`），葉脈、中肋、鋸齒邊畫在那種葉自己的來源貼圖上（`ug_sources.py`），UV 直接對著每一片葉，所以葉脈和葉形對得上；蕨的羽片是五頂點立體羽片。沒有葉片卡、沒有透明貼圖。
- **頂點色**：glTF 會把 COLOR_0 乘到底色上。SH01 寫的是葉色；SH02、SP01 和 UG 改寫灰階明暗（下內 0.78、上外 1.0），A 是遮蔽，免得在會乘頂點色的檢視器裡變暗變綠。
- 一件一個材質、一套 1024 貼圖（Albedo／Normal／ORM／MaskURP），雙面；葉色同時在 Albedo 和頂點色。可有可無的小東西放 `Detail_*`（標準畫質關掉）。`minTier` 都是 `standard`。
- **面數**：工作包寫「件小，面數各 ≤ 4,000」，《樹木重做 v2》寫灌木 LOD0 ≤ 30,000、LOD1 ≤ 7,500、LOD2 ≤ 2,000。SH01 取品質優先：LOD0 約 16,600 面，LOD1 ≤ 4,000，LOD2 ≤ 2,000；SH02、SP01 同樣照 v2 的灌木、幼樹上限（LOD1 再壓到 ≤ 4,000）。如果 LOD0 也要 ≤ 4,000，請在審查時說。**UG01–UG06 照工作包，每件 LOD0 ≤ 4,000**（1,054–3,740 面）。
- 建模流程和 yard-props-c、yard-roadside-c 相同（共用工具和來源貼圖），`build_ug.py` 只多三件事：原點留在幹基、葉子減量的 LOD、頂點色和風權重。
- 重建：`blender -b --factory-startup -P art/source/undergrowth-c/build_ug.py -- <ID> [--clay]`；審圖、QA 和植物出圖（剪影、樹冠下、20 m／60 m、正面和左右 35°）：`BL=<blender> sh art/source/undergrowth-c/render_reviews.sh`；Unity：`UNITY=<Unity.exe 6000.3.28f1> sh art/source/undergrowth-c/unity/run_unity_check.sh`。

### SH01 林下灌木（闊葉）（UnderstoryShrubBroadleaf，v001）

七根細幹從一點分開（幹腳站在 14 cm 的一圈上），每根往外彎的角度不同：正面是一把扇子，側面比較窄，整叢往右後方微斜。幹往地下延伸 0.18 m，可以放在不平的地上。每根幹三到六根次枝，繞著幹交錯長出（不鏡像），每根次枝三到六根細枝：幹、次枝、細枝三級粗細分明（幹腳約 1.2–1.6 cm、次枝約一半、細枝約 2.4 mm）。葉子是五頂點的立體葉（四點輪廓加抬高的中脈），一片片沿細枝和次枝的外段繞枝螺旋互生（137.5°），葉柄接在枝上，葉面朝上朝外，每個枝頂一片嫩葉；彼此很近又幾乎平行的兩片，其中一片繞中脈轉開，不會疊成一片。沒有葉片卡、葉團圖集，也不是在球裡撒葉。幹的下段光裸，有一根次枝斷掉只剩一截。葉色依高度和內外連續混色（上外亮暖、下內深冷，下層幾片偏黃），同時寫在 Albedo 和頂點色（A 是樹冠遮蔽）；第二組 UV「Wind」u 是風的權重（幹腳 0、葉 1）、v 是相位。幹腳的青苔和泥、較高處的淺色地衣畫在貼圖上；地上 34 片落葉是 Detail_Litter。沒有碰撞（人可以穿過去）。

## 已知問題與未驗

- **SH02、SP01**：SP01 的樹冠比三視圖瘦、幹比三視圖直；SH02 的葉比三視圖小而稀。在 D2 的陰天光下，背著天空看時葉子接近黑色剪影（設定圖裡的小樹葉偏亮黃綠、有透光感）；葉色已調亮一次，差別不大，主因是逆光和小葉，材質沒有透光。v2 寫每種 3 個變體（A、B、C），這裡和 SH01 一樣只做一個，要變體請在審查時說。正式場景擺放、手機上的效果、風動都未驗。

- **UG**：葉的網格邊在近看時是折線（每片葉 12–30 個輪廓點）；寬鬆 QA 的近乎共面見上；UG06 不含根，要擺在半徑相近的根上，沒在 Josh 的根上實際擺過。UG 沒做 Detail_ 群組。正式場景擺放、手機上的效果、風動都未驗。

- **和標準圖比**：標準圖的樹冠是很細碎的小葉、密度高；SH01 照三視圖是比較疏的林下灌木，葉子 6–9 cm、約 1,800 片，枝間看得到天空。近看（樹冠下往上看）每片葉子是菱形的輪廓，這是五頂點葉的形狀。如果要更密、更細碎，可以加葉數或改成更小的葉，面數會往上。
- **變體**：《樹木重做 v2》要每種三個變體（A、B、C）。這個樣品只有一個，變體用不同的 `UG_SEED` 產生，等樣品審過再做。
- 面數取捨見上方「共同做法」：LOD0 約 16,600 面，超過工作包寫的 4,000；LOD1 在 4,000 內。
- 側面看七根幹比較集中、幾乎平行，沒有 cand-2 側視那麼斜。
