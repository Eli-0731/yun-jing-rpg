# C 部分遠中景並排檢查

`C-midground-with-SK03.png` 將同批 SK03 天空／遠山預覽、從 MM01／MM02 實際 Blender 網格透明渲染的石峰，以及 MM03 樹丘 RGBA 卡片排在同一張畫面。`review.json` 記錄來源與畫面擺位。這是圖像合成的美術檢查，不是 Unity 場景或真實透視尺寸的實測。

檢查結果：石峰與樹丘、遠山的前後景層次可以辨認，MM01／MM02 已從瘦長石柱改為較寬且有側峰的連續山體。仍可見石峰比樹丘卡片更暗、岩面較單調，畫法也有落差；在實際光照、霧與植被整合時需再審。MM03 下緣和 SK 山脊的接合亦需場景端以地形遮擋。

重建後的 MM01／MM02 均為 12,464 三角形，低於 15,000 的 LOD0 上限。Blender 5.2.2 遊戲資產 QA 再次通過，0 錯誤；重疊 UV 是共用平鋪岩面貼圖的設計，底面 -1 m 需埋地。
