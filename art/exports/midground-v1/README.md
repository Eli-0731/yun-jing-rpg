# MM01／MM02 中景喀斯特石峰

- 參考：各自的 AI 三視圖，已先檢視並保存於 `art/references/midground-v1/`。
- 第一版環向石柱輪廓不合格；本版改成連續高度場，以偏心峰頂、不規則岩脊和圓形山腳形成兩種剪影。未沿用方塊堆石。
- MM01 為單峰，MM02 為高低雙峰。每件 LOD0 均為 12,464 三角面、1 個材質、1 張 1024 × 1024 岩面貼圖；另有灰模、Blender、FBX、GLB、預覽及 `model_info.json`。
- Blender 5.2.2 的遊戲資產 QA：兩件皆通過；無非流形邊、破面、重疊面及退化 UV 面。UV 有意將底面和岩壁重疊使用同一張平鋪貼圖，因此不能直接拿這套 UV 烘焙獨立圖集。底座最低點為 -1 m，需埋入中景地形。
- 這是 200–500 m 的中景件，沒有碰撞。尚未在 Unity 6000.3.28f1 測試弧面遠景、霧、LOD 或擺位。岩峰與三視圖的樹木、細碎懸崖仍有差距，需在全包畫面一同判讀。
