# MM01／MM02 中景喀斯特石峰（v7 A2）

- 已先檢視並保留各自的 AI 三視圖於 `art/references/midground-v1/`，再用內建 imagegen 畫新正面透明石峰圖。MM01 是陡峭單峰與左側岩台，MM02 是高低雙峰與中央窄谷；峰頂、岩台及石縫有松樹，下半部融進霧。
- 舊高度場網格已由 12 三角面的微弧卡取代；舊建模及岩面貼圖腳本也已移除。每件有 2048 × 2048 RGBA、灰模、Blender 母檔、FBX、GLB、預覽與 `model_info.json`。來源貼圖由 1254 × 1254 imagegen 透明原圖放大到交付尺寸；放大不會增加原生細節。
- Blender 5.2.2 遊戲資產 QA 均通過：各 12 三角面、1 個材質、1 張 UV 圖，沒有退化面、錯誤法線或 UV 重疊。開放邊是卡片設計。卡片下緣低於地面零點，目的是使可見霧腳對齊地面；不作碰撞。
- 200–500 m 中景用途。透明排序、雙面材質、真實鏡頭尺寸與場景霧尚未在 Unity 驗證。

## MM03–MM06

- 四件均先產生、檢視、保存各自的 AI 三視圖，再從正面圖生成透明輪廓貼圖。MM03 是樹丘、MM04 是斷崖牆、MM05 是梯田遠坡、MM06 是遠山脊；已校正成執行文件的順序。
- 依 D1 原規格，這些是玩家走不到的遠看中景，因此選用單張透明卡：各 2 三角面、1 材質、1 張 RGBA 貼圖；四件皆有灰模、Blender、FBX、GLB、預覽和 `model_info.json`。可見高度依序為 42、50、40、45 m。GLB 材質檢查為 `BLEND`、雙面。
- Blender 資產 QA 四件通過；開放邊為面片設計。網格下緣低於零，因透明邊緣需將可見山腳對齊地面；不是實體碰撞。Unity 需指定雙面透明材質並檢查排序。MM04 左右邊不直接無縫，連續擺放時應每隔一片鏡像並稍微重疊；實際接縫仍待全包檢查。
