## 換材質怎麼做（照實記錄）

- 原檔照「互不相連的零件」拆開（402 件），頂點不動；照原本的 15 個材質分到灰泥、石、木、瓦四組，用 VL 的程序化材質重新烘焙。
- **原版的共面問題**：原檔有很多兩個零件的面在同一個平面上、朝同一個方向（例如牆板貼在柱子上）。原版用純色看不出來，換成烘焙貼圖後兩面的花紋不同，遠看會閃爍。修法：同一平面、同方向的兩個面，把小的那個零件的面沿法線往後退 1 mm（每個頂點最多移 3 mm），跑 4 輪後零件之間剩 0 組；共找到 1,130 組、移動 597 個面、898 個頂點。外形尺寸誤差 0.0 mm。

  - 原因：展開時有些面被壓成沒有面積（挖孔邊緣、倒角留下的細長三角形）。舊流程在打包之後才把它們就地撐開成不到 1 texel 的小塊，這小塊在圖集裡就成了獨立的一塊，壓在它原本所屬那一塊上面。之前鐵匠鋪的 13、材料鋪的 400、山門的 51 個 texel 都是這種，每處 1–1.5 texel。（鐵匠鋪挖孔第一次重建時是 316 個，先把挖孔後的面重新三角化降到 13，這一輪再降到 0。）
  - 做法（`ti_pipeline.detach_zero_uv`，只在 RS02／RS03 打開，VL／VH 不受影響）：打包前就找出這些面——沒有面積的、比該有的貼圖密度少到一成以下的——把它們從原本那一塊切出來，在自己的平面上照正常密度展開（細到展不開的給一個 3 texel 的小三角形），讓打包時和別塊之間留足間隔；每次打包、放大小塊之後再找一次，直到沒有。三件分別切出 302／3,523／780 個面，這些面仍烤到自己位置的顏色，外形不變。
  - 第一次修完後，鐵匠鋪爐罩轉角還有 8 個約 5 cm² 的三角形在 UV 裡寬度幾乎是 0：那是繞過轉角彎折 90° 的多邊形，整個面只用一個方向展開，總有一半被壓成一條線。建 LOD 時本來就會把五邊以上的多邊形切成三角形，所以改成在展開前先切（同樣的切法，匯出的三角形一樣），轉角兩側分開展開後就沒有了。這一步切了幾個多邊形沒有記數。
