## 路面與接縫（整套共用）

- 共用截面（`fp_parts.section`）：踏面寬 1.16 m、高 0.055–0.06 m，中間踩出的淺溝深 8 mm；兩側土埂頂 0.12 m（距中線 0.82 m），外緣 0.012 m（距中線 1.0 m）。
- 每件兩端最後 0.4 m 起伏漸平，端口截面就是共用截面，量測偏差 0 mm。所以任一件的端口可以接任一件。
- 接法：下一件的 `Socket_Path_W` 對齊這一件的 `Socket_Path_E`，繞 Z 轉 180°。FP03、FP05 的 `Socket_Path_E` 在高 1.2 m／1.5 m。
- **每一級 LOD 的端口都一樣**：土板的 LOD 不用減面，而是整排刪掉沿路的格線，兩端那排永遠保留，所以 LOD0 接 LOD2 也是 0 mm。
- 端口那排頂點設了截面的解析法線，兩件接起來光影一致。
- 貼圖沿路方向以 6 m 為週期，兩端顏色相同。接縫色差量法：在接縫線上用雙線性取樣、離角點 0.7 texel，兩邊比較。要求整條接縫線平均差 ≤ 0.006、最差的 16 cm 視窗 ≤ 0.015。另外在同一件內部 1/4、3/4 長度的格線兩側用同樣量法量一次，當作「土色本來就有的變化」參考，不算進合格標準。
