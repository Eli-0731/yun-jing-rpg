# CL01–CL03｜雲海、雲帶、薄霧

三張皆為 2048 × 512 RGBA 貼圖，使用一般透明混合；左右可平鋪，四片等寬相接可繞一圈。上、下邊緣透明，避免卡片邊界形成直線。圖像由可重現的分層雜訊產生，來源腳本為 `art/source/sky-and-distance-v1/build_cloud_layers.py`。

- 左右首尾的 RGBA 像素最大差值均為 0；貼圖不含字或介面。接縫檢查圖上的細紅線只供審圖。
- 預覽把貼圖合成到 SK01 的中性天空畫面，僅驗證層次與柔邊；不是 Unity 實景截圖。
- 建議材質關閉深度寫入，按遠近關係排序。CL01 的卡片可置於 B1 視點下方；CL02、CL03 應避免遮住山門和玩家可行走路面。
- 實際高度、流速、透明度與夜晚亮度須在 Unity 6000.3.28f1 的場景中校準。
