# VP04 茶棚

- 規格：3.6 × 3.0 × 約 3.08 m，正面朝 -Y；四根木柱、歇腳桌凳、小爐茶壺、空白舊布。
- 原任務要求沿用 v009 幾何，但此工作樹與可見 Git 物件皆找不到 VP04 v009；因此先生成並檢視三視圖，再獨立重建。本件不能稱為 v009 的延續版本。
- 瓦圖與木紋皆為本件 AI 生圖來源，保存於本資料夾，整理成 `VP04_Tile_Albedo.png`、`VP04_Wood_Albedo.png`、`VP04_WoodLight_Albedo.png`。屋頂兩面使用 `VP04_Tile_UV`，沒有引用 RK03 的貼圖或 UV。
- LOD0：54 個網格、3,752 三角面、8 個材質。附灰模、Blender、FBX、GLB、材質預覽與 `model_info.json`。
- Blender 5.2.2 全物件遊戲資產 QA 通過：無錯誤、重疊面或漂浮件；部分木件為平鋪材質使用的重疊 UV 與平面端蓋多邊形，不能直接當獨立烘焙 UV。尚未做第二級 LOD、碰撞或 Unity 6000.3.28f1 匯入驗證。
- 三視圖中的瓦片破損、布邊和茶具造型比目前模型更豐富；本件目前可作中距離茶棚，近景品質仍需美術審看。
